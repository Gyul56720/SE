# brief — 나열이 아니라 **보고서**

"오늘 주식 시장 보고해줘" 에 값을 늘어놓으면, 읽는 사람은 그 수들이 검사를 받았는지
알 수 없다. 여기서 나가는 것은 **되짚을 수 있는 수**뿐이다.

```
출처 선언 ──> 받기 ──> 스키마 검사 ──> 셈(코드) ──> 관문 ──> 보고서
   │                       │                          │
   │                    안 맞으면                  안 맞으면
   │                    저장 안 함                  화면에서 뺌
   └── brief/source.py 에 한 줄. 코드가 아니다
```

## 왜 이 모양인가 — law/ 를 그대로 옮겼다

`law/METHOD.md` 의 결론은 **쟁점은 생성물이 아니라 도출물**이라는 것이었다. 여기서도
같다 — **수는 생성물이 아니라 도출물이다.**

| law | brief |
|---|---|
| 조문 원장 (`law/corpus/`) | 받은 원장 (`brief/ledger/`) |
| L001 인용한 조문이 실재하는가 | **B002 이 수의 근거가 원장에 실재하는가** |
| 쟁점 = 코드가 계산 (`issue.derive`) | 지표 = 코드가 계산 (`derive.RULES`) |
| L005 근거 없이 단정하는가 (soft) | B005 근거 없이 단정하는가 (soft) |
| 생성자는 관문을 모른다 | 셈하는 자리는 관문을 모른다 |

## 관문

| | | |
|---|---|---|
| B001 | 근거가 붙어 있는가 | hard |
| B002 | 그 근거가 원장에 **실재하는가** | hard |
| B003 | 원장이 낡지 않았는가 | hard |
| B004 | **다시 셈해도 같은 값인가** | hard |
| B005 | 근거 없이 단정하는가 | soft |

**B004 가 요점이다.** 나머지 넷은 꼬리표를 보지만 B004 는 값을 본다 — 관문이 원장의
줄에서 규칙을 **직접 다시 돌려** 견준다. 셈하는 자리가 조용히 틀리면 여기서 걸린다.
`tests/test_brief.py` 가 값을 일부러 바꿔치기해 놓고 잡히는지 본다(`law/mutate.py` 의
RED/GREEN 과 같은 자리).

### B003 은 줄이 아니라 원장 전체에 걸린다

**실측 — 이 검사가 잡았다.** 처음에는 위반의 `where` 만 모아 그 이름의 수를 뺐다.
그런데 B003 의 `where` 는 출처 이름이라 어느 수의 이름과도 안 맞았고, 그래서 **낡은
원장인데 종가가 그대로 화면에 나왔다.** "관문에 걸렸습니다" 라고 적으면서 수는 그대로
보여 주는 꼴이다 — 읽는 사람은 수를 먼저 읽는다. `gate.막힌것()` 이 그 자리다.

## 쓰는 법

```bash
python3 brief/report.py --출처목록                      # 등록된 것 (호출 0회)
python3 brief/report.py --탐색 --url '<아무 API>'       # **등록 안 된 것을 그 자리에서**
python3 brief/report.py --url '<아무 API>' 이름         # 받아서 재고 관문까지
python3 brief/report.py 주식 --것 코스피,나스닥,다우
python3 brief/report.py 주식 --것 코스피 --저장 brief/ledger/주식.json
python3 brief/report.py 주식 --원장 brief/ledger/주식.json   # 안 받고 그것으로
python3 brief/report.py 주식 --것 코스피 --진단          # 받되 보고서는 안 낸다
python3 tests/test_brief.py                             # 배선 검사 (네트워크 불필요)
python3 tests/test_brief_adhoc.py                       # 즉석 출처 · 줄 찾기 · B004 재계산
```

끝값: `0` 보고서를 냈다 · `1` 관문 hard 위반 · `3` **미검증 — 못 냈다.**

## 등록 안 한 출처도 **그 자리에서** 붙는다

출처를 미리 등록해 두는 것 **자체가 하드코딩**이다 — 내가 예상한 도메인만 되기 때문이다.
티켓값을 물으면 표에 없다. 그래서 두 걸음으로 붙인다:

```bash
python3 brief/report.py --탐색 --url '<주소>'      # 무엇이 오는지만 (저장도 보고도 안 함)
python3 brief/report.py --url '<주소>' 티켓값       # 받아서 재고 관문까지
```

`--탐색`이 **도착한 것에서 스키마를 읽어 준다** — 짐작이 아니라 관측이다:

```
줄 4개 · 칸 4개  (꼴=json)
  칸        공연, 일자, 최저가, 잔여석
  **수인 칸** 최저가, 잔여석
  key 후보  공연, 일자, ...
  이대로 저장할 수 있다 (쓸 줄 4개 · 버릴 줄 0개 · key=공연)
```

그러면 등록도 안 한 출처에서 보고서가 나온다 — **관문까지 그대로 붙은 채로**:

```
칸               개수         최소         중앙         평균         최대     표준편차
최저가           4.00    45,000.00   104,500.00   102,000.00   154,000.00    46,583.26
잔여석           4.00         3.00        26.00        33.00        77.00        33.30

## 관문
  관문 B001~B005: 위반 없음
## 이 보고서가 안 보는 것
  · **칸의 뜻** -- 이름이 무엇을 가리키는지는 출처가 정하지 여기서 모른다
```

### 그런데 규율은 안 풀린다

밖(사람이든 모델이든)이 정하는 것은 **어디를 볼 것인가**뿐이다. 수는 여전히 아무도
못 만든다:

| 지어내면 | 어떻게 되나 |
|---|---|
| 주소를 | fetch 가 실패 → **미검증, 수 0개** |
| 스키마를 | 도착한 것과 안 맞음 → `inspect` 가 거절 |
| 칸을 안 적으면 | 도착한 것에서 읽음 → 짐작이 아니라 관측 |
| **값을** | **B004 가 원장에서 다시 세서 잡는다** |

`law/METHOD.md` 의 분업 그대로다 — LLM 은 조문에서 요건을 뽑고(대조 가능한 일), 쟁점은
코드가 도출한다. 여기서 **출처 제안이 그 '요건 뽑기' 자리**다.

### 줄은 스스로 찾는다

공개 API 가 주는 꼴이 제각각이라, `find_rows` 가 세 가지를 **꼴로만** 판정한다 —
뜻을 짐작하지 않는다.

| 온 꼴 | |
|---|---|
| `[{...}, {...}]` | 그대로 줄이다 |
| `{"time":[...], "tmax":[...]}` | **칸 지향 → 전치** (Open-Meteo 꼴) |
| `{"data":{"items":[...]}}` | 내려가서 **제일 많은 줄**을 집는다 |

**실측 — 이 검사가 잡았다.** 처음에는 `{"items":[{...},{...}]}` 의 `items` 를 칸으로
보고 전치했다. 줄 셋이 각각 `{"items": {...}}` 하나짜리로 나왔고, 칸이 통째로 사라져
수인 칸을 하나도 못 찾았다. **칸은 스칼라의 목록**이라는 것을 코드에 못 박았다 —
dict 나 list 가 든 목록은 칸이 아니라 줄 목록이다.

길이가 다른 칸이 섞여 있으면 **전치하지 않는다.** 짧은 쪽에 맞춰 자르면 줄이 조용히
사라지고, 긴 쪽에 맞춰 채우면 없는 값이 생긴다.

### 셈도 범용이다

`일간등락 = (종가-시가)/시가` 같은 것은 주식만 아는 셈이라 주식에만 쓰인다. 등록 안 된
출처에는 **칸이 수이기만 하면 도는 것**을 쓴다 — 개수·최소·중앙·평균·최대·표준편차.
티켓값이든 기온이든 논문 편수든 뜻이 있고, **B004 가 이것도 다시 센다.**

## 자주 쓸 것만 표에 등록한다

```python
등록(Source(
    이름="환율", 설명="통화쌍 종가 (Stooq. 열쇠 없음)",
    url="https://stooq.com/q/l/?s={심볼}&f=sd2t2ohlcv&h&e=csv",
    꼴="csv", 칸=("Symbol","Date","Open","High","Low","Close"),
    수칸=("Open","High","Low","Close"), key="Symbol",
    별칭={"달러": "usdkrw"}, 셈=("일간등락","폭","종가위치"), 신선=3,
))
```

등록하면 별칭(`코스피` → `^kospi`)과 도메인 셈(`일간등락`)이 붙는다. 등록 안 해도 도는데
왜 등록하나 — **자주 쓰는 것에 이름과 뜻을 붙여 두려고**다. 물음마다 코드를 짜면 어느
보고서가 검사를 받았는지 아무도 모르게 된다. **가져오기 · 검사 · 셈 · 관문은 어느 길로
오든 한 벌이고, 표에는 별칭과 셈만 는다.** `tests/test_brief.py` 가 등록된 출처마다
"key 가 칸 안에 있는가 · 셈이 필요한 칸을 이 출처가 받아 오는가" 를 검사한다 — 표가
스스로 앞뒤가 안 맞으면 그 자리에서 걸린다.

셈을 늘리는 것도 `derive.RULES` 에 한 줄이다. 거기 등록되면 관문이 자동으로 그것을
다시 셈해서 대조한다.

## 못 받으면 **수를 하나도 안 적는다**

```
**미검증** -- 받지 못해 보고서를 낼 수 없다.
  출처: 주식 (지수·종목 종가 (Stooq. 열쇠 없음))
  까닭: 못 받았다: URLError: <urlopen error Tunnel connection failed: 403 Forbidden>
  받은 것이 없으므로 **수를 하나도 적지 않는다.** 기억에서 채우면 그것은 보고가 아니라 창작이다.
```

이것이 실제 화면이다(에이전트 컨테이너에서 egress 정책이 stooq 를 막는다). 공개 채널
에이전트가 낸 사고 둘이 정확히 이 자리의 양쪽이었다 — 하나는 **도구를 안 써 보고**
"불가능하다" 였고, 다른 하나는 **데이터 없이** 숫자를 내놓는 것이다. 둘째가 더 나쁘다.

## 나열과 추론은 다르다 -- `infer.py`

```
"코스피 +1.44%"                       <- 나열. 원장을 다시 말한 것이다
"평균 +0.09%, 표준편차 1.02"           <- 이것도 나열이다. 원장의 요약일 뿐
"이 배합은 과거 259일 중 13번(5%).
 명제 11개 보정 후 p=0.59 -- **평범**"  <- 추론. 기준선이 있고 판정이 있다
```

`law` 는 원고/피고 쪽을 각각 돌려 **결론이 갈리는 자리**를 계산하고 뒤집어 본다.
`lol` 은 승률을 **기준선과 견준다**. `mathdrift` 는 유도가 이어지는가를 sympy 가
판정한다. 셋 다 같은 꼴이고 -- **명제 · 기준선 · 기계 판정 · 못 하겠으면 못 하겠다고
한다** -- 여기서도 그것만 한다.

```bash
python3 brief/report.py --시계열 코스피,코스닥,나스닥,S&P500
```

**추론에는 시계열이 있어야 한다.** 오늘 값 네 개로는 "평소와 다른가" 를 물을 수 없다 --
견줄 평소가 원장에 없다. 그래서 `--시계열` 은 일별 내력을 받아 날짜로 맞춘다(안이음:
모든 쪽에 있는 날만. 바깥이음은 빈 칸을 만들고 빈 칸은 결국 채워지거나 버려진다).

### 판정 셋 -- **`못잼` 이 제일 자주 나온다**

| | |
|---|---|
| `이례` | 기준선 아래서 이만한 일이 일어나기 어렵다 |
| `평범` | 기준선으로 설명된다 |
| **`못잼`** | 이 원장 크기로는 **어느 쪽인지 정할 수가 없다** |

셋째가 요점이다. 표본 n 으로 **도달 가능한 최소 p** 는 연속 명제가 `2/(n+1)`,
이진이 `1/(n+1)` 이다. 명제를 m 개 세워 Holm 으로 조이면 `m·최소p` 가 문턱을 못 넘는
수가 있고, 그때는 무슨 값이 나와도 이례라고 말할 수 **없다.** 그것을 모르고 "상위 3%!"
라고 하면 스무 개를 훑어보고 제일 놀라운 것을 고른 것과 구별되지 않는다.

실측(합성 내력 260걸음 · 명제 11개): 연속 명제는 최소 p 0.085 라 **전부 못잼**, 이진
명제는 0.042 라 갈렸다. 하나만 물으면(m=1) 같은 원장에서 연속도 갈린다 -- **미리
하나를 정해 묻는 것이 스무 개를 훑는 것보다 강하다.**

### 정규분포를 가정하지 않는다

수익률은 꼬리가 두껍다. z 를 정규분포로 읽으면 이례를 과장하고, 그 과장이 정확히
시황이 하는 일이다. 여기서는 **경험분위**만 쓴다 -- 과거 표본 중 몇 개가 오늘보다
작았나. 분포를 안 가정하므로 틀릴 자리가 하나 줄어든다.

### 자가 한 번 뒤집혔다 -- 이진에 순위검정

**실측 2026-09-09.** 방향 일치(0/1)와 배합(0/1)을 연속과 같은 순위검정으로 쟀더니,
오늘 값 1 이 과거 표본의 **최댓값이라 언제나 최상위 분위**가 되어 일치율이 66% 든
5% 든 똑같이 최소 p 를 냈다. **자가 무엇을 재든 같은 답을 주면 그것은 자가 아니다**
(`mathdrift` 의 낱말 겹침 자가 두 번 뒤집힌 그 자리다).

고쳤다 -- 이진에서 물어야 할 것은 "오늘 일어난 일이 과거에 얼마나 잦았나" 이고 그
비율이 그대로 p 다. 한 번도 없었다고 p=0 이라 하지 않는다(라플라스 `(k+1)/(n+1)`).
`tests/test_brief_infer.py` 가 옛 방식이 90% 짜리와 1% 짜리에 **똑같은 p** 를 주는
것을 회귀 못으로 붙들고 있다.

## 해석은 하지 않는다

"왜 올랐는가" 는 이 파이프라인의 관할이 아니다(`law/METHOD.md` 1-7 의 **외적 정당화**).
`law/gate.py` 가 "인용한 조문이 실재하는가" 만 보고 "법리가 타당한가" 는 안 보는 것과
같은 선이다. 보고서 끝에 **안 보는 것**을 매번 적는 이유다.

## 네트워크는 이 컨테이너에서 못 돌려 봤다

에이전트 세션의 egress 정책이 stooq.com 을 막는다(실측 2026-09-09, `403 Forbidden`).
`law/METHOD.md` 가 arxiv 에 대해 적어 둔 것과 같은 처지다. **파싱·검사·셈·관문은
네트워크 없이 검사했고**(`tests/test_brief.py`), HTTP 왕복만 VM 에서 `--진단` 으로
확인해야 한다. 그 명령은 보고서를 안 내므로 원장을 더럽힐 수 없다.
