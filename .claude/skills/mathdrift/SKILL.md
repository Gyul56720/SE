# MATHDRIFT — 수학적 지평을 소설처럼

전체 설명은 `mathdrift/README.md`. 여기는 **어떻게 돌리는가**만 적는다.

소설의 DRIFT 와 같은 구조다 — 줄거리 없이 첫 문장에서 이어 쓰듯, 씨앗 식 하나에서
연산자로 이어 넓힌다. 다른 것은 오가는 것이 산문이 아니라 **식**이라는 것뿐이다.

## 절대 어기지 않는 것

1. **식을 직접 지어내 원장에 넣지 마라.** 이 세션에서 수식을 써서 "이런 게 나올 수 있다"고
   보여 주는 것은 금지다. 파이프라인이 만든 것이 아니면 계보가 거짓이 되고, 발산율도
   거짓이 된다. 소설 쪽에서 산문을 직접 짓지 않는 것과 같은 이유다.
2. **Gemini 키가 없으면 사실대로 "못 돌린다" 고 답한다.** Claude 로 대신하지 않는다.
3. **발산에 게이트를 걸지 마라.** 이 파이프라인은 아무것도 거르지 않는다. 자유도가
   전부다. 세 번 데었다 — 이름으로 재다가, 산문으로 받다가, 심판을 프롬프트에 실었다가.
   전부 발산을 죽였다. 검증(`recall`)은 따로 있고 **사용자가 시켰을 때만** 돈다.
4. **낱말로 재지 마라.** 낱말 겹침 자는 두 번 뒤집혔다(부모 말을 그대로 단 것이 최고점,
   진짜 이주가 바닥). 식은 `diff` 로 **기호 단위**로 본다. "확산이 낮다/높다" 같은 말을
   판정처럼 전하지 마라 — 눈금이지 판정이 아니다.
5. **돌고 있는 런을 함부로 죽이지 마라.** `status` 로 먼저 확인하고, 사용자가 멈추라고
   했을 때만 `stop`.
6. **`pkill -f` 를 쓰지 마라.** 명령줄에 그 패턴이 들어 있으면 자기 셸까지 죽는다(실측).
   `stop` 이 PID 를 골라 죽인다.

## 명령

```bash
M=/home/ubuntu/SE/scripts/mathdrift.sh

$M status          # 먼저 이것부터. 살아 있는지 · 공간 몇 개 · 최근 로그
$M start [개수]     # 새 원장 (기본 50). 쓰던 것은 .bak 으로 옮겨 둔다
$M go    [개수]     # 이어 넓힌다 (기본 100). 계보가 이어진다
$M show            # 원장 -- 공간마다 식 한 줄
$M diff  S10       # **연산자가 식에 무엇을 했나** -- 바뀐 토큰만 (호출 0회)
$M card  S10       # 공간 하나를 칸째로, 부모와 나란히
$M lineage S10     # 씨앗까지의 사슬
$M recall          # ①재현 -- 코드 칸을 채운 것만, 호출 0회. 시키면 한다
$M check           # 지금 무엇을 쓸 수 있나 (호출 0회)
$M watch           # 로그 실시간
$M stop            # 멈춘다. 원장은 남는다
```

묶음 크기는 `BATCH=8 $M go` 처럼 바꾼다 (기본 5). RPM 이 병목이라 이것이 곧 시간이다 —
실측 50개에 10호출 33초.

## 사용자가 이렇게 말하면

| 말 | 할 일 |
|---|---|
| "수식 넓혀줘" / "시작해" | `$M status` 로 먼저 보고 → 없으면 `$M start`, 있으면 이어 갈지 물어본다 |
| "이어서 N개" | `$M go N` |
| "뭐가 나왔어" / "보여줘" | `$M show`. 길면 앞뒤만 |
| "S10 은 뭘 한 거야" / "이 식이 부모랑 뭐가 달라" | `$M diff S10` — **이것이 읽는 법이다.** 낱말 겹침 숫자를 전하지 마라 |
| "S10 자세히" | `$M card S10` |
| "어디서 왔어" | `$M lineage S10` |
| "검증해" / "Strassen 되돌아와?" | `$M recall`. **시키기 전에는 돌리지 않는다** |
| "어디까지 왔어" | `$M status` |
| "멈춰" | `$M stop` |
| "한국어가 섞여 나온다" | 프롬프트가 약한 것. `mathdrift/spread.py` 의 `prompt()` 규칙을 본다 — **거르지 말고** 프롬프트를 고친다 |
| "식이 부모랑 똑같다" | `diff` 가 "바뀐 것이 없다" 고 말한다. 연산자 설명(`mathdrift/ops.py`)이 약한 것 |
| "다 비슷비슷하다" | 급발진 몫(`ops.JUMP_SHARE`)을 올린다. 거리 2 이주가 더 자주 뽑힌다 |

## 보고할 때

`status`·`show` 의 숫자를 그대로 전한다 — 공간 수, 호출 수, 연산자 쓰임새. 추측하지 마라.
**어떤 식이 나왔는지는 `diff` 로 읽고 전한다** — "S10 은 쌍대로 `\inf` 를 `\sup` 으로
바꿨다" 처럼. "확산 몫" 같은 낱말 눈금은 판정으로 전하지 않는다.

런이 백그라운드로 도는 동안 이 세션은 끝나도 된다. 다음에 `$M status` 로 이어받는다.

## 아직 없는 것

①재현(`recall`)만 있다. 나머지 축(비자명성 · 압축 · 실행 가능)은 없다 — ①의 판정 분포를
보고 짠다. 그리고 **식끼리 기호로 견주는 법**이 아직 없다. 그것이 생기기 전까지는
아무것도 안 센다.
