# coin — 시황을 **짓지 않고 잰다**

전체 설명은 `coin/README.md`, 설계는 `coin/DESIGN.md`. 여기는 **어떻게 돌리는가**만.

## 절대 어기지 않는 것

1. **이 세션에서 시황을 직접 쓰지 마라.** 부탁받은 것이 바로 그것이라도 그렇다.
   지어낸 시황은 원장 대조를 안 받았고, 그러면 이 파이프라인이 막으려는 그것 —
   **기저율 빠진 수익률 · 표본 없는 확률 · 지어낸 %** — 이 그대로 나간다.
   수는 `coin/event.py` 가 재고 `coin/gate.py` 가 판정한다.
   (`CLAUDE.md` 의 소설 규칙, `jaso` 의 자소서 규칙과 같은 자리다.)
2. **확률을 네가 매기지 마라.** 시나리오 순위는 `coin/scenario.py` 가 표본 비율로
   낸다. "가능성이 높아 보인다" 는 이 파이프라인에서 **하면 안 되는 말**이다.
3. **투자 권유를 하지 마라.** 사라·팔아라·목표가·손절가. 관문 C012 가 기각한다.
   이것은 측정 보고이지 조언이 아니다.
4. **Gemini 키가 없으면 사실대로 "못 돌린다" 고 답한다.** Claude 로 대신하지 않는다.
   다만 `--상황만`·`event.py`·`gate.py`·`scenario.py` 는 키 없이 돈다.
5. **기저율 없는 수익률을 전하지 마라.** "규제 뉴스 뒤 +2.9%" 는 참이면서 뜻이 없다 —
   아무 날이나 골라도 +1.6% 다. 초과를 같이 안 적으면 그 수는 사람을 속인다.
6. **거래량·자금조달률·미결제약정을 "고래" 나 "세력" 이라고 부르지 마라.** 그것은
   포지션이지 지갑이 아니다. 지갑을 본 것은 `flow.py` 의 `대형이체` 줄이 있을 때뿐이고,
   관문 C015 가 그 자리를 본다.
7. **종합 점수를 만들지 마라.** 무게를 정하는 순간 그 무게가 순위를 전부 정한다.
   `screen.py` 는 초과 하나로만 줄을 세운다.

## 한 명령 — `run.py`

```bash
C=/home/ubuntu/SE          # 이 세션이면 /home/user/SE

python3 $C/coin/run.py --물음 "오늘 암호화폐 시장 어때?"      # 시장 브리핑
python3 $C/coin/run.py --물음 "곧 오를 코인 알려줘"          # 모든 코인 훑기 순위
python3 $C/coin/run.py --물음 "리플 전망은?"                # 그 코인 닮은 과거·시나리오
python3 $C/coin/run.py --물음 "SOL -12.4% 왜 이래?" --바퀴 3
python3 $C/coin/run.py --물음 "..." --상황만      # 모델 없이 무엇이 잡혔는지만
python3 $C/coin/run.py --채우기                   # 원장 채우기 (망 필요, 오래 걸림)
```

끝값: `0` 냈다 · `1` **어긋난 자리가 남아 안 냈다** · `2` 암호화폐 물음이 아니다 ·
`3` 못 돌렸다(원장이 비었다 · 키가 없다 · 망이 막혔다)

`1` 이 나오면 그 답을 대신 지어서 메우지 마라. 화면에 어디가 어긋났는지 적혀 있다.

## 원장을 채우는 것은 오래 걸린다

`--채우기` 는 GDELT 에서 몇 년치 뉴스를 여러 나라 말로 캐고 가격을 받는다. 몇십 분
걸린다. **`CLAUDE.md` 의 백그라운드 규칙대로** 띄우고, `pgrep -af` 로 확인하고,
확인된 뒤에만 PID 와 로그 경로를 알려라.

```bash
mkdir -p /home/ubuntu/SE/logs
setsid nohup python3 /home/ubuntu/SE/coin/run.py --채우기 \
    > /home/ubuntu/SE/logs/coin_fill.log 2>&1 < /dev/null &
disown
pgrep -af "coin/run.py"        # ps -p $! 는 거짓 음성을 낸다
```

## 24시간 계속 모으기 — `/dig` 가 받는다

```bash
bash $C/scripts/coin.sh watch 24      # 얕은 5분(RSS) · 깊은 1시간(GDELT·흐름)
bash $C/scripts/coin.sh status
bash $C/scripts/coin.sh stop          # pkill -f 를 쓰지 않는다 (자기 셸까지 죽는다)
```

RSS 는 지금 걸려 있는 것만 준다. 하루 한 번 받으면 나머지가 통째로 빠지고 **빠졌는지
아무도 모른다.** `watch` 를 띄운 뒤에는 **로그에 줄이 쌓이는지** 봐라 — 프로세스가
살아 있는 것과 일을 하는 것은 다르다.

## 무엇이 잡혔는지 먼저 본다

```bash
python3 $C/coin/news.py --탐침       # 어느 출처가 실제로 답하나 (나라별)
python3 $C/coin/news.py --덮임       # 나라·말·해마다 몇 건인가
python3 $C/coin/ledger.py --보기     # 잰것 · 미검증 · BH 통과
python3 $C/coin/gate.py --규칙       # 관문이 무엇을 보는가 (C001~C015)
python3 $C/coin/flow.py --탐침       # 포지션·온체인·심리 자료가 답하나
python3 $C/coin/screen.py --지평 7   # 지금 어느 종목이 어떤 자리인가
python3 $C/coin/regime.py --자산 BTC # 장세 (문턱 아니라 자기 역사의 백분위)
```

## 원장이 비었을 때 무엇을 말할 것인가

"못 쟀다" 고 말한다. 배경지식으로 메우지 않는다. **미검증은 통과가 아니다.**
