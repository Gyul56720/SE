# jaso — 자기소개서를 **짓지 않고 대조한다**

전체 설명은 `jaso/README.md`, 설계는 `jaso/DESIGN.md`. 여기는 **어떻게 돌리는가**만.

## 절대 어기지 않는 것

1. **이 세션에서 자소서 문장을 직접 지어내지 마라.** 부탁받은 것이 바로 그것이라도
   그렇다. 지어낸 자소서는 원장 대조를 안 받았고, 그러면 이 저장소가 막으려는 그것 —
   **지어낸 수 · 승격된 역할 · 어느 회사에나 들어가는 문단** — 이 그대로 나간다.
   산문은 `jaso/write.py` 가 Gemini 로 만들고 `jaso/gate.py` 가 판정한다.
   (`CLAUDE.md` 의 소설 규칙과 같은 자리다.)
2. **원장을 지어내지 마라.** 경험 원장은 **사람의 답에서만** 채워진다. 공고문·검색
   결과·짐작으로 항목을 만들지 마라 — `jaso/run.py` 가 애초에 못 만들게 되어 있다.
3. **남의 합격 자소서를 재료로 쓰지 마라.** 표절이고, 한국 채용 실무의 주력인 표절
   검사 DB 가 정확히 그것이라 **가장 확실히 걸리는 길**이다. 밖에서 받는 것은
   문항(공고문)과 작법(공개 가이드)뿐이다.
4. **Gemini 키가 없으면 사실대로 "못 돌린다" 고 답한다.** Claude 로 대신하지 않는다.
   다만 `--사실만`·`ask`·`gate` 는 키 없이 돈다.
5. **탐지 회피 손질을 하지 마라.** 동의어 치환·문장 흔들기. 사실은 안 바꾸면서 저작자만
   속이고, 걸리면 '지어냈다' 가 아니라 '숨겼다' 가 된다.

## 한 명령 — `run.py`

```bash
J=/home/ubuntu/SE          # 이 세션이면 /home/user/SE

python3 $J/jaso/run.py --이름 <작업이름> --회사 <회사> --직무 <직무> \
    --문항 "<문항 원문 (1000자)>" --문항 "<둘째 문항 (800자)>"
```

**끝값이 다음에 무엇을 할지다.**

    0  자소서까지 냈다        2  **사람 차례** -- 물음이 나갔다
    1  관문 hard 가 남았다    3  못 갔다 (문항이 없다 · 키가 없다 · 망이 막혔다)

`2` 가 나오면 **화면의 물음을 사용자에게 그대로 전하고 멈춘다.** 대신 답하지 마라.
답을 받으면:

```bash
python3 $J/jaso/run.py --이름 <작업이름> --답글 "1) … 2) … 3) …"
```

또 `2` 면 또 전한다. 두세 바퀴면 닫힌다. 재료가 차면 그때부터 끝까지 자동이다 —
여러 벌 생성 · 관문 · 고르기 · 작성 근거 기록.

잘못 들어간 항목을 뺄 때: `--빼기 X2`

## 포트폴리오

**문항이 다른 자소서다.** 원장이 차 있으면 바로 된다.

```bash
python3 $J/jaso/folio.py --표 $J/jaso/작업/<이름>/원장.json --사실만   # 키 없이 돈다
python3 $J/jaso/folio.py --표 …/원장.json --낼곳 포트폴리오.md          # 산문 (Gemini)
```

원장이 비어 있으면 `run.py` 로 **먼저 물어서 채운다.** 포트폴리오도 재료는 같다.

## 걸음마다 따로

```bash
python3 $J/jaso/fetch.py --질의 "2026 상반기 자기소개서 문항" --몇 8   # 문항 수집(망)
python3 $J/jaso/learn.py --질의 "자기소개서 피해야 할 표현"            # 작법 배우기(망)
python3 $J/jaso/ask.py --표 원장.json --문항 "<원문>"                  # 무엇을 물을까
python3 $J/jaso/gate.py 자소서.md --표 원장.json -v                    # 심판
python3 $J/jaso/trace.py 자소서.md --표 원장.json                      # 작성 근거 기록
python3 $J/jaso/mutate.py 자소서.md --표 원장.json                     # 관문이 진짜 잡나
python3 $J/jaso/ledger.py --표 원장.json --앵커                        # 원장이 성한가
```

## 이미 쓴 자소서를 봐 달라고 할 때

`gate.py` 에 걸면 된다. **다만 원장이 없으면 사실 관문이 전부 미검증**이라, 거기서
나오는 '통과' 는 통과가 아니라 아무도 안 본 것이다. 그렇게 말해 주고, 원장을 채우려면
`run.py` 로 물으면 된다고 알려라.

## AI 판별을 물으면

`jaso/README.md` 의 'AI 판별 프로그램에 대한 대비' 절을 근거로 답한다. 요점만:

- 판별기는 **틀린다**(오탐). "통과한다" 는 겨눌 수 없는 과녁이다 — 점수를 약속하지 마라.
- D001~D005 는 **판별 점수가 아니라 글이 얼마나 일반적인가**를 잰다. 전부 soft.
- 진짜 대비는 `trace.py` 의 **작성 근거 기록**과, 원장에 있는 것만 써서 **면접에서
  되물어도 답할 수 있게** 해 두는 것이다.

## 사용자가 급하다고 할 때

물음을 건너뛰자고 하면 **무엇을 잃는지 한 줄로 말하고 그래도 원하면 따른다** —
원장 없이 쓰면 J001~J004 와 P001 이 전부 미검증이고, 나오는 글은 일반 LLM 출력과
같아진다. 대신 `--몇물음 3` 으로 급한 것만 물을 수 있다(급한 순으로 정렬돼 있다).
