# DRIFT — 자유 연속 집필

전체 설명은 `novel/DRIFT.md`. 여기는 **어떻게 돌리는가**만 적는다.

## 절대 어기지 않는 것

1. **산문을 직접 지어내지 마라.** 이 세션에서 소설 문장을 써서 보여주는 것은 금지다.
   토큰 낭비이고, 파이프라인이 만든 것이 아니므로 결과를 오해하게 만든다. 문체를 바꾸고
   싶으면 `novel/style.py` 의 페르소나를 고쳐서 Gemini 가 그렇게 쓰게 한다.
2. **Gemini 키가 없으면 사실대로 "못 돌린다" 고 답한다.** Claude 로 대신하지 않는다.
3. **돌고 있는 런을 함부로 죽이지 마라.** `drift.sh status` 로 먼저 확인하고, 사용자가
   멈추라고 했을 때만 `drift.sh stop`.
4. **`pkill -f` 를 쓰지 마라.** 명령줄에 그 패턴이 들어 있으면 자기 셸까지 죽는다(실측).
   `drift.sh stop` 이 PID 를 골라 죽인다.

## 명령

```bash
D=/home/ubuntu/SE/scripts/drift.sh

$D status          # 먼저 이것부터. 살아 있는지 · 어디까지 왔는지
$D start [글자수]   # 새 원고 (기본 8000). 쓰던 것은 .bak 으로 옮겨 둔다
$D go   [글자수]    # 이어 쓴다 (기본 50000). 세계·인물·사건 번호가 이어진다
$D read            # 원고를 읽는다
$D save <파일>      # 파일로 뽑는다 (VM 안에)
$D send [이름]      # 원고를 Discord 로 보낸다 -- VM 밖으로 빼는 유일한 길
$D world           # 세계가 어떻게 자랐나 (★ 는 주요 인물)
$D card            # 지금 회차의 각본 -- 질문 · 비트 · 쾌감 · 갈고리
$D 첫장 [파일]      # 첫 회차를 잰다. 실제 1화를 주면 나란히 놓는다
$D watch           # 로그 실시간
$D stop            # 멈춘다. 원고는 남는다
```

## **`GENRE` 없이 시작하지 마라**

`start` 는 `GENRE` 가 없으면 **갈래 꾸러미를 통째로 안 싣는다.** 원고는 멀쩡히
나오므로 아무도 안 알아챈다 -- 실측 2026-09-09, 사용자가 "첫 문장은 이제 안 쓰는데
왜 또 나오지" 로 알아챘다. 그 한 줄 뒤에 이만큼이 꺼져 있었다:

    축 덮개      대사 몫 · 문장 길이 · '-다' 몫 · 이름 수가 표본 폭으로 돌아간다
                 (실제 웹소설 1화에서 낸 갈래 밴드가 한 줄도 안 나간다)
    화법 조건    "발화는 접지 않는다" -- 이게 빠지면 원고가 통째로 간접화법이 되고
                 대사 몫이 0, 모든 문장이 '-다' 로 끝난다
    도착지       serial.plan -- 어디로 가는지가 없으면 당김이 없다
    여는 좌표    갈래 축에서 첫 자리를 뽑는 것. 없으면 **코드에 박힌 기본 씨앗**으로
                 열린다(flow.FIRST) -- 새 원고마다 같은 세계가 돌아온다

**그래서 시작할 때 갈래를 붙인다:**

```bash
GENRE=lanobe $D start 200000              # 라이트노벨 -- 액션 · 전투 · 격
HOURS=24 HEAT=0.6 GENRE=lanobe $D start 200000   # 24시간 · 성인 수위
```

갈래는 `ropan · lanobe · romance · job · youth`. 시작하면 화면에 `갈래: lanobe` 와
`[여는 좌표]` 가 찍힌다 -- **그 둘이 안 보이면 헛도는 것이다.**

`go`(이어 쓰기)에도 붙여야 한다. 원고에 갈래가 박혀 있어도 매 런마다 인자로
덮어쓰므로, 안 주면 갈래가 벗겨진 채 이어 쓴다.

## 첫 문장

**웬만하면 지정하지 마라.** `FIRST` 를 주면 여는 좌표 뽑기가 꺼지고, 그 문장의
세계(지명 · 말씨)가 원고 전체를 끌고 간다. 갈래만 주면 화자가 그 자리에서 짓는다.

```bash
FIRST="그를 처음 만난 건, 크리스마스 이브의 아이슬란드였다." GENRE=lanobe $D start
```

여러 편을 따로 쓰려면 `BOOK=/path/다른책.json` 을 앞에 붙인다.

## 사용자가 이렇게 말하면

| 말 | 할 일 |
|---|---|
| "소설 써줘" / "시작해" | `$D status` 로 먼저 보고 → 없으면 **`GENRE=<갈래> $D start`**, 있으면 이어 쓸지 물어본다. 갈래를 안 정했으면 물어본다 -- 빈 채로 시작하지 마라 |
| "이어서 N만 자" | **`GENRE=<갈래> $D go <N*10000>`** -- 갈래를 빼면 벗겨진 채 이어 쓴다 |
| "첫 문장이 예전 그대로다" / "이거 아까 쓴 건데" | 갈래 없이 시작한 런이다. `$D status` 로 확인하고 `GENRE=… $D start` 로 다시 연다 |
| "지금까지 쓴 거 보여줘" | `$D read` (길면 `$D save` 후 일부만) |
| "어디까지 왔어" | `$D status` |
| "멈춰" | `$D stop` |
| "파일로 받고 싶다" / "다운로드" / "밖으로 못 빼겠다" | `$D send` — Discord 에 파일로 올라간다 |
| "인물이 누구누구야" / "세계 어떻게 됐어" | `$D world` |
| "문장이 단조롭다" / "대사가 딱딱하다" | **먼저 갈래가 실렸는지 본다**(위). 그 다음 `novel/genre.py` 의 갈래 저울(축)과 `novel/targets.json` 을 본다 — 재는 폭이 곧 시키는 폭이다. `novel/style.py` 의 페르소나는 **기본 경로(axes)에서 무동작**이라 거기부터 고치면 헛수고다(`DRIFT_PROMPT=legacy` 여야 실린다). 프롬프트에 부탁만 더 적는 것으로는 안 바뀐다(실측) |
| "첫 회차가 심심하다" / "1화가 안 붙잡는다" | `$D 첫장` 으로 재고, 실제 1화와 견준다(`novel/first_ref.json` 에 표본이 쌓인다). 밴드는 잰 것에서만 낸다 |
| "농도가 얕아진다" | `novel/diffusion.py` 의 기준을 본다 |
| "사건이 밋밋하다" | `novel/shock.py` 의 축(WHO/HOW/MARK/SCALE/TONE)에 항목을 더한다 |

## 보고할 때

`status` 의 숫자를 그대로 전한다 — 덩어리 수, 글자 수, 사건 횟수, 세계 크기. 추측하지
마라. 진행 상황을 물으면 로그와 파일을 실제로 읽고 답한다.

런이 백그라운드로 도는 동안 이 세션은 끝나도 된다. 다음에 `$D status` 로 이어받는다.
