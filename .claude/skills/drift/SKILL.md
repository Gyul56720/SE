# DRIFT — 자유 연속 집필

전체 설명은 `novel/DRIFT.md`. 여기는 **어떻게 돌리는가**만 적는다.

## 절대 어기지 않는 것

1. **산문을 직접 지어내지 마라.** 이 세션에서 소설 문장을 써서 보여주는 것은 금지다.
   토큰 낭비이고, 파이프라인이 만든 것이 아니므로 결과를 오해하게 만든다. 문체를 바꾸고
   싶으면 `novel/style.py` 의 페르소나를 고쳐서 Gemini 가 그렇게 쓰게 한다.
2. **Gemini 키가 없으면 사실대로 "못 돌린다" 고 답한다.** Claude 로 대신하지 않는다.
3. **돌고 있는 런을 함부로 죽이지 마라.** `drift.sh status` 로 먼저 확인하고, 사용자가
   멈추라고 했을 때만 `drift.sh stop`.
4. **`pkill -f` 를 쓰지 마라.** 명령줄에 그 패턴이 들어 있으면 자기 셸까지 죽는다(실측).
   `drift.sh stop` 이 PID 를 골라 죽인다.

## 명령

```bash
D=/home/ubuntu/SE/scripts/drift.sh

$D status          # 먼저 이것부터. 살아 있는지 · 어디까지 왔는지
$D start [글자수]   # 새 원고 (기본 8000). 쓰던 것은 .bak 으로 옮겨 둔다
$D go   [글자수]    # 이어 쓴다 (기본 50000). 세계·인물·사건 번호가 이어진다
$D read            # 원고를 읽는다
$D save <파일>      # 파일로 뽑는다
$D world           # 세계가 어떻게 자랐나 (★ 는 주요 인물)
$D watch           # 로그 실시간
$D stop            # 멈춘다. 원고는 남는다
```

첫 문장을 지정해서 시작하려면:

```bash
FIRST="그를 처음 만난 건, 크리스마스 이브의 아이슬란드였다." $D start
```

여러 편을 따로 쓰려면 `BOOK=/path/다른책.json` 을 앞에 붙인다.

## 사용자가 이렇게 말하면

| 말 | 할 일 |
|---|---|
| "소설 써줘" / "시작해" | `$D status` 로 먼저 보고 → 없으면 `$D start`, 있으면 이어 쓸지 물어본다 |
| "이어서 N만 자" | `$D go <N*10000>` |
| "지금까지 쓴 거 보여줘" | `$D read` (길면 `$D save` 후 일부만) |
| "어디까지 왔어" | `$D status` |
| "멈춰" | `$D stop` |
| "인물이 누구누구야" / "세계 어떻게 됐어" | `$D world` |
| "문장이 단조롭다" / "대사가 딱딱하다" | `novel/rhythm.py` 의 자와 `novel/style.py` 의 페르소나를 고친다 — 프롬프트에 부탁만 더 적는 것으로는 안 바뀐다(실측) |
| "농도가 얕아진다" | `novel/diffusion.py` 의 기준을 본다 |
| "사건이 밋밋하다" | `novel/shock.py` 의 축(WHO/HOW/MARK/SCALE/TONE)에 항목을 더한다 |

## 보고할 때

`status` 의 숫자를 그대로 전한다 — 덩어리 수, 글자 수, 사건 횟수, 세계 크기. 추측하지
마라. 진행 상황을 물으면 로그와 파일을 실제로 읽고 답한다.

런이 백그라운드로 도는 동안 이 세션은 끝나도 된다. 다음에 `$D status` 로 이어받는다.
