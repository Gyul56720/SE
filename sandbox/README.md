# sandbox -- 실험은 깨끗한 판에서. 저장소는 실험대가 아니다

```
명령 ──> 판(HEAD 워크트리 | 지금 트리 사본) ──> 고삐(시간·CPU·메모리) ──> 산출물만 밖으로
                                                  │
                                     환경: 비밀 변수 없음 (기본)
```

## 왜 있나

run_shell 은 진짜 저장소 안에서 돈다. 그래서 "라노벨 상황극" 요청 하나가
`scripts/drift.sh` 를 20줄 촌극으로 덮었다(실측 2026-09-10, `4cd4473`). 실험이
저장소를 만지면 실수가 그대로 배포판이 된다.

수법은 `scripts/precheck.sh` 가 이미 하던 것(HEAD 를 임시 워크트리로)을 모듈로 뺀
것이다. `HARNESS_PLAN.md` 1단계.

## 세 겹

| 겹 | 무엇 | 왜 |
|---|---|---|
| 판 | HEAD 워크트리(기본) · `--지금트리`(작업 트리 사본, .gitignore 는 안 따라감) | 안에서 뭘 쓰고 지우든 저장소에 안 닿는다. 기본이 HEAD 인 것은 precheck 와 같은 이유 -- 남이 받아 가는 것은 커밋된 나무뿐이다 |
| 고삐 | 벽시계(기본 180초, 넘으면 그룹째 kill) · RLIMIT_CPU · RLIMIT_AS | 실험이 봇의 VM 을 통째로 먹지 못하게 |
| 환경 | 비밀 변수 삭제(기본) · `--키포함` 으로만 유지 · `--망차단`(unshare) | 격리 판의 기본값은 '없음'. **망을 못 끊는 환경이면 끊은 척하고 돌리지 않는다**(끝값 3) |

## 쓰기

```bash
python3 sandbox/run.py -- python3 gatekeeper.py          # HEAD 판에서
python3 sandbox/run.py --지금트리 -- bash scripts/tests.sh -k dig
python3 sandbox/run.py --가져와 out/r.txt -- bash -c 'mkdir out && echo 답 > out/r.txt'
python3 sandbox/run.py --망차단 -- python3 실험.py        # unshare 안 되면 안 돌린다
```

끝값: `0` 명령 통과 · `1` 명령 실패(시간 초과 포함) · `3` 판 자체를 못 깔았다.
결과 dict 의 `돌았나` 가 False 면 명령이 한 줄도 안 돈 것이다 -- 끝값과 갈라 읽어라.

디스코드에서는 `!실험 게이트` · `!실험 검사 <말>` (dispatch.py 경유, 관리 채널만).
에이전트에게는 `run_experiment` 도구로 열려 있다 -- 실험·검증은 run_shell 이 아니라
그쪽을 쓰게 한다.

## 산출물

`--가져와 <상대경로>` 로 명시한 것만 `sandbox/out/<런>/` 으로 나온다.

- 경로는 워크트리 안으로만 해석된다(절대경로 · `..` · 링크 탈출 전부 ValueError,
  G014 와 같은 규율). **돌기 전에 검사한다** -- 다 돌고 나서 거절하면 낭비다.
- 한 개 5MB 상한. `sandbox/out/` 은 .gitignore 에 있다 -- 실험은 일회용이고,
  남길 것은 에이전트가 골라서 저장소 자리로 옮겨 커밋한다(그 커밋은 게이트를 탄다).

## 안 하는 것

- **run_shell 을 뺏지 않는다.** 그 권한은 사용자가 명시 요청한 것이다. 여기는 실험이
  갈 다른 길일 뿐이다.
- **완전한 격리라고 주장하지 않는다.** 같은 사용자 권한으로 도는 프로세스다 --
  `secret_filter` 가 자기 한계를 적어 둔 것과 같은 자리. 진짜 격리는 별도 사용자/
  컨테이너의 일이다. 여기서 막는 것은 "실수로 저장소를 덮는" 경로와 "한 줄로 새는" 경로다.
