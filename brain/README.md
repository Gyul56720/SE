# brain — 물음이 무엇일지 모른다. **검사 꼴만 안다.**

```
물음 ──(모델)──> 작업표 ──(코드 R001~R005)──> 성하면 그 자리로 보낸다
                    │
               못 세우면 ──> 관할 밖이라 말한다 (실패가 아니다)
```

## 한 번 잘못 짰다 — 그 기록을 남긴다

처음에는 판정기를 **도메인별로** 등록했다: `법.조문대조` · `모델.승률` · `논리.진리표`…
그러면 **내가 예상한 물음만 된다.** `brief/source.py` 에 출처를 미리 등록해 둔 것과
똑같은 하드코딩을 한 층 위에서 되풀이한 것이다. 스포츠·영어·논문·법·의학은 사용자가
든 **예시**였지 목록이 아니었다.

## 닮은 것은 도메인이 아니라 **검사하는 꼴**이었다

```
law   L001 인용한 조문이 원장에 실재하는가   │
brief B002 이 수의 근거가 원장에 있는가      │  같은 것 ── 대조

brief B004 다시 셈해도 같은가                │  ── 재계산

lol   기준선(동전던지기)을 이기는가          │
brief 과거 분포에서 이례인가                 │  같은 것 ── 기준선

law   logic 진리표: 지문에서 따라 나오는가   │
math  prove: 유도가 이어지는가               │  같은 것 ── 연역

law   J005 그 요건이 갈리면 결론이 갈리는가  │
brief I004 한 걸음 빼면 판정이 바뀌는가      │  같은 것 ── 뒤집기
```

**다섯이다.** 그리고 다섯 다 도메인을 모른다. 촉매든 산불이든 배송 지연율이든 티켓값이든,
검사할 수 있으면 이 중 하나로 가고 아니면 관할 밖이다. 셋째 길은 없다.

| 꼴 | 묻는 것 | 판정 |
|---|---|---|
| **대조** | 이 주장이 원장의 어느 줄과 글자 그대로 맞는가 | 맞음 / 어긋남 / 미검증 |
| **재계산** | 주장한 수를 원장에서 다시 세면 같은가 | 같음 / 다름 / 못셈 |
| **기준선** | 이 관측이 기준선 아래서 놀라운가 | 이례 / 평범 / **못잼** |
| **연역** | 전제에서 따라 나오는가 | 참 / 거짓 / **모름** |
| **뒤집기** | 근거 하나를 빼면 결론이 바뀌는가 | 굳음 / 약함 / 못잼 |

**모든 꼴에 '모름' 갈래가 있다.** 참/거짓 둘뿐인 꼴은 두지 않는다 — 못 잰 것을 한쪽에
밀어 넣으면 그 순간 거짓말이 된다.

## 무엇이 닫혀 있고 무엇이 열려 있나

| | |
|---|---|
| **닫힘** | 검사 **꼴** 다섯. 판정하는 코드. 요청 시점에 못 늘린다 |
| **열림** | 무엇을 대조할지 · 무엇을 다시 셀지 · 무엇을 기준선으로 둘지 |

`--url` 과 같은 배치다. 거기서도 출처는 열려 있고 `inspect` 는 닫혀 있었다.
**검사기 자체가 열리면 검사기를 검사할 것이 없어진다** — 그 하나는 닫아 둔다.

## 쓰는 법

```bash
python3 brain/route.py --꼴                      # 검사 꼴 다섯 (호출 0회)
python3 brain/route.py --프롬프트 "<아무 물음>"   # 모델에게 줄 것 (호출 0회)
python3 brain/route.py --표 작업표.json          # 쪼갠 것을 검사하고 어디로 갈지 낸다
python3 tests/test_brain.py                      # 배선 검사
```

끝값: `0` 돌려도 된다 · `1` 작업표에 hard 위반 · `3` **통째로 관할 밖**

## 모델이 지어낼 수 있는 것과 없는 것

| | |
|---|---|
| 지어낼 수 있다 | 어느 꼴로 갈지 · 무엇을 대조할지 · 무엇을 기준선으로 둘지 |
| **지어낼 수 없다** | 꼴 자체(R001) · 재료가 있는 척(R002·R003) · 판정(꼴이 낸다) |

물음이 무엇일지 아무도 모르므로 **쪼개는 자리는 열려 있어야 한다.** 대신 쪼갠 결과가
성한지는 코드가 본다. `law/METHOD.md` 의 분업 그대로다 — LLM 은 조문에서 요건을 뽑고,
쟁점은 코드가 도출한다.

## 관문 R001~R005

| | | |
|---|---|---|
| R001 | 검사 꼴이 닫힌 다섯 중 하나인가 | hard |
| R002 | 그 꼴이 요구하는 재료가 다 채워졌는가 | hard |
| R003 | 재료가 빈 값이 아닌가 | hard |
| **R004** | **관할 밖을 적었는가** | hard |
| R005 | 갈 데가 없으면 그렇다고 적었는가 | hard |

**R004 가 제일 중요하다.** 관할 밖 칸이 비어 있으면 위반이다 — 어떤 물음도 통째로 기계
판정되지 않는다. 원인·전망·가치·처방은 늘 남는다. 안 적었다는 것은 다 판정했다고 믿는
것이고, 그 믿음이 판정 안 받은 답에 판정받은 옷을 입히는 자리다.

모든 보고서가 끝에 '안 보는 것' 을 적는 것과 같은 규율인데, 여기서는 **시작할 때** 적게
한다.

## 관할 밖은 실패가 아니다

`law/METHOD.md` 1-7(Alexy)의 선이다 — 기계가 판정하는 것은 **내적 정당화**뿐이고, 전제가
옳은가는 관할이 아니다.

| 갈래 | |
|---|---|
| 인과 | 왜 그렇게 되었는가. 관측 원장으로는 상관까지다 |
| 전망 | 앞으로 어떻게 되는가 |
| 가치 | 무엇이 좋은가 · 어느 학설이 옳은가 |
| **처방** | 이 사람이 무엇을 해야 하는가. 원장은 무엇이 **있는지**를 정하지 이 사람에게 무엇이 **맞는지**를 안 정한다 |
| 원장없음 | 밖에 대조할 것이 아예 없는 물음 |

**도메인이 아니라 물음의 종류로 적는다.** 도메인으로 적으면 그것도 예시 목록이 된다.

관할 밖이라고 답을 못 하는 것이 아니다. **판정 없이 답한다고 말하고 답하면 된다.**
하면 안 되는 것은 판정 안 받은 답에 판정받은 옷을 입히는 것 — 없는 출처, 근거 없는
수치, "연구에 따르면 78%가".

`처방` 갈래가 의학·법에서 특히 급하다. 조회(약전·조문 원문)와 자문(이 약을 먹어도 되나 ·
제가 이길까요)은 다른 일이다. 앞은 원장이 정하고 뒤는 안 정한다. **뒤에 판정기를 붙인
척하면 그 옷이 정확히 사람을 다치게 한다** — 그래서 안 만든다. 못 만드는 것이 아니라
만들면 안 되는 것이다.

## 여기서 판정까지 하지 않는다

판정은 이미 네 자리에 있다(`brief/` · `law/` · `lol/` · `mathdrift/`). 여기서 또 하면
**두 벌이 생기고 두 벌은 언젠가 갈라진다** — `lol/score.py` 가 예측을 다시 만들지 않는
것과 같은 이유다. 여기서는 어느 자리로 가야 하는지까지만 낸다.
