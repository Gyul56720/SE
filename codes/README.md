# 3GPP NR LDPC 기저행렬 -- 출처와 대조

TS 38.212 §5.3.2 Table 5.3.2-2(BG1) · 5.3.2-3(BG2) 의 값이다. **표준 문서를 직접
못 받았다**(egress 차단). 대신 **서로 독립인 두 구현**에서 꺼내 맞대 봤다.

    nr_bg1.csv / nr_bg2.csv                py3gpp 0.6.0   (PyPI)
    nr_bg1_sionna.csv / nr_bg2_sionna.csv  sionna 2.1.0   (NVIDIA, PyPI)

    두 출처가 **값까지 같다** (실측, 줄 단위 비교)
    BG1  316 개 원소 · 46 x 68 · Kb=22 · K_max 8448 · 부호율 1/3
    BG2  197 개 원소 · 42 x 52 · Kb=10 · K_max 3840 · 부호율 1/5

원소 수 316 · 197 은 표준이 말하는 값과 맞는다.

**이것은 "두 곳이 같더라" 이지 "표준과 같더라" 가 아니다.** 둘이 같은 곳에서 베꼈을
수 있다. 표준 문서를 받을 수 있게 되면 그때 한 번 더 맞댄다.
