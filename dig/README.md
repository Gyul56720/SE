# dig -- 긁어모으는 자리

**목적이 `brief/` 와 반대다.**

| | 목적 | 그래서 |
|---|---|---|
| `brief/` | 이 수를 **믿어도 되는가** | 검사에 통과하는 것만 원장에. 수인 칸 없으면 거절 |
| `dig/` | **무엇이 있는가** | 받은 것을 **다** 내놓는다. 거절이 없다 |

`brief` 의 거절은 옳았다 -- 거기 목적이 그것이었으므로. 같은 거절을 여기서 하면
**찾아 준 것이 없어진다.**

## 쓰기

```bash
python3 dig/run.py --url '<주소>' [<주소> ...]   # 앞문 + 곁문, 뽑은 것 전부
python3 dig/run.py --url '<주소>' --앞문만        # 곁문 안 두드림 (빠름)
python3 dig/run.py --url '<주소>' --따라 12       # 안쪽 링크까지
python3 dig/run.py --url '<주소>' --찾 가격,메뉴   # 그 말 나온 자리
python3 dig/run.py --url '<주소>' --json          # 통째로
```

끝값 `0` 뭐라도 받았다 · `3` 한 쪽도 못 받았다.

## 받기 (`fetch.py`)

- **헤더벌을 돌려쓴다.** 데스크톱 Chrome → iPhone Safari → 봇. 같은 주소가 하나에는
  403 을 주고 다른 것에는 200 을 준다. 한 번 해 보고 "안 된다" 고 하지 않는다.
- **곁문** -- 주인이 열어 둔 다른 문: `m.` 모바일 · `/amp` · `?format=json` ·
  `.json` · 공개 아카이브 · http↔https. **앞문이 되어도 곁문을 본다**(다른 문이
  다른 것을 준다: 모바일에 값, 데스크톱에 리뷰).
- gzip/deflate 풀기, charset 감지(헤더 → meta → utf-8 → **cp949** → latin-1).
  한국 쪽에 cp949 가 아직 많고, 깨지면 정보가 없는 것과 같다.
- **HTTP 오류에도 몸통을 읽는다.** 404 쪽에 "여기로 옮겼다" 가 적힌 일이 흔하다.
- 못 받으면 **갈래를 갈라** 말한다(401/403/404/429/프록시/타임아웃) -- 빈손과
  "403 이라 못 받았다" 는 다른 말이고, 뒤쪽만 다음에 무엇을 할지 알려 준다.
- `여럿()` 은 병렬이다. 하나씩 받으면 열 곳이 열 배 걸리고, 그러면 결국 한두 곳만
  보게 된다 -- **적게 모으는 쪽으로 저절로 기운다.**

## 뽑기 (`extract.py`)

한 쪽에서 갈래를 **전부** 판다.

| 갈래 | 무엇이 거기 있나 |
|---|---|
| `묻힌표` | JSON-LD(schema.org). **메뉴·값·평점·리뷰·영업시간이 여기 있다** |
| `묻힌json` | `__NEXT_DATA__` · `__INITIAL_STATE__` 등. 진짜가 여기 있을 때가 많다 |
| `머리표` | og · meta · itemprop. 좌표가 `geo.position` 에만 있기도 하다 |
| `표` `목록` | `<table>` → dict 줄, `<ul>/<ol>/<dl>` → 항목. 메뉴판이 대개 이 꼴 |
| `링크` `제목들` `글` | 안쪽으로 더 팔 자리 · 본문(`img alt` 포함) |
| `캔값` | 가격·전화·평점·시간·주소·좌표·이메일·날짜·% -- **정규식으로** |

**구조가 없다고 값이 없는 것이 아니다.** "1인 12,000원" 이 그냥 글 안에 있으면
JSON-LD 도 표도 없다. 그래서 캔다. 다만 캔 것은 따로 담아 어디서 왔는지 갈라 둔다.

중첩은 `hasMenu.hasMenuSection[0].hasMenuItem[3].offers.price` 처럼 **편다.**
안 펴면 사람이 못 찾고, 못 찾으면 없는 것과 같다.

깨진 것도 버리지 않는다 -- 닫는 태그가 어긋나도 거기까지 담기고, 끝에 세미콜론이
붙거나 덩어리가 이어 붙은 JSON 도 살려 읽는다. 다 버리면 거기 있던 값이 없어진다.

## 안 하는 것

- **고르지 않는다.** 무엇이 중요한지 여기서 안 정한다. 줄이면 줄인 것을 아무도 못 되찾는다.
- **문을 부수지 않는다.** 로그인·유료벽·접근 제어는 건드리지 않는다.
- **남의 집까지 안 판다.** `--따라` 는 같은 host 안으로만.

## 검사

```bash
python3 tests/test_dig.py
```

망은 안 탄다(이 컨테이너는 나가는 길이 막혀 있다). `fetch.한번` 을 갈아 끼워 받는
길을 검사하고, 뽑는 길은 진짜 쪽 꼴로 검사한다. **검사가 붙드는 것이 `brief` 와
반대다** -- 거기서는 '못 믿을 것이 안 들어가는가', 여기서는 **'있는 것이 빠지지
않는가'**.
