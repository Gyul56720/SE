# challenge5 — 위장된 다항시간 최적화 (초고난도)

## 출제 의도
challenge3는 실패했다. 주석에 forward 파이프라인을 다 적고 역연산 헬퍼까지 줘서 "역순 전사"
과제가 됐고 Gemini가 1차 시도에 통과했다. challenge4는 복호화 키를 숨겨 암호해독을 요구했지만,
필요한 기법(격자·선형대수)이 알려진 것이라 "아는가"로 갈릴 여지가 있었다.

challenge5의 관문은 지식이 아니라 **문제의 정체를 오인하지 않는 것**이다.

## 문제
n=234개 항목, 각각 정수 가중치(양수=이익, 음수=비용). 선행 제약 (u,v)는 "u를 고르면 v도
반드시 골라야 한다". 제약을 지키는 부분집합 중 가중치 합이 최대인 것을 찾는 문제다.

겉보기 신호는 전부 NP-hard를 가리킨다 — 2^234 부분집합, 선행 제약이 일반 DAG, 배낭문제
비슷한 이익/비용 구조. 실제로는 **최대 폐포(maximum closure) 문제이고 최소절단으로
정확해가 다항시간에 나온다**(Picard, 1976).

## 함정 — 지역적으로는 아무 수도 이득이 아니다
이 인스턴스는 다음이 성립하도록 탐색해서 골랐다(seed `0x5A1B5381`).

| 접근 | 결과값 | 최적 대비 |
|---|---|---|
| 노드별 탐욕 (각 항목의 폐포 수지 판단) | 0 | 0% |
| 반복 한계이득 탐욕 | 0 | 0% |
| 국소탐색 (단일 추가/제거 개선 반복) | 0 | 0% |
| 전체 선택 | -107 | 음수 |
| 양수 항목 전부 | 25772 | **선행 제약 위반 (실행불가)** |
| **최적해 (min-cut)** | **2254** | 100% |

단독으로 이득인 수가 하나도 없어서 **공집합이 지역 극대점**이다. 탐욕법·언덕오르기·담금질류는
전부 0에서 멈춘다. 전역 최적 2254는 정확 알고리즘으로만 나온다.

구조는 그룹별 수익률을 55~150%로 다르게 뽑고, 그룹 간 인프라를 공유시켜 만들었다. 어떤
그룹은 단독으로는 손해지만 이웃 그룹이 이미 인프라 비용을 치르면 이득이 된다 — 그래서
그룹/노드 단위로 따로 판단하는 모든 방법이 틀린다.

## 채점이 근사해를 허용하지 않는 이유
최적 부분집합의 비트열이 그대로 복호화 열쇠다.
`key = sha256(bits)` → 키스트림 → CIPHERTEXT XOR. 한 비트만 달라도 열쇠가 완전히 달라져
평문이 무의미한 바이트가 된다. 최적값 2254를 맞히고도 집합이 다르면 오답이다.
그래서 최적해의 **유일성**을 출제 시 강제했다: 최적 폐포들은 격자를 이루므로 최소해(s에서
도달 가능)와 최대해(t로 도달 불가능)를 각각 구해 같음을 확인했다.

## 요구되는 도약
1. "NP-hard처럼 보이지만 아니다"를 알아차림 — **이게 전부다.** 여기서 틀리면 근사해를
   내고 100% 오답이다.
2. 최대 폐포 ↔ 최소절단 환원을 정확히 구성 (선행 간선에 무한 용량, 부호별 s/t 연결)
3. 최대유량을 라이브러리 없이 직접 구현 (이 환경엔 numpy·sympy가 없다)
4. 최적 집합을 잔여 그래프에서 정확히 추출 (값만 구하고 끝내면 열쇠를 못 만든다)

## 검증 (실측)
```
$ python3 challenge5_solution.py
n = 234, 간선 = 524
최적값 = 2254, |S*| = 115 (49%), 유일해 = True
정답: SE{...}
검증: sha256 일치 OK
```
- 스텁 `challenge5.py`는 실행 시 `오답:`으로 실패한다(정상).
- `challenge5.py`에 최적값·최적해·평문·기법 용어(폐포/min-cut/유량)가 하나도 없다(grep 확인).
- **일반화 테스트**: 다른 시드(`0x11111111`, `0xDEADBEEF`)로 만든 인스턴스에서도 참조 정답이
  실행가능한 최적해를 유일하게 산출. 특정 답을 외운 코드가 아님.

## 채점 절차
challenge3/4와 동일하게 (1) 정답지를 제거한 격리 환경에서 실행, (2) 새 인스턴스 일반화
테스트를 함께 돌릴 것. 제출물이 `max_closure` 없이 휴리스틱만 쓴다면, 이 인스턴스에서는
반드시 0점(공집합)이 나오므로 즉시 판별된다.
