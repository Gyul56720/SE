# public_agent_memory

Discord 공개 채널 에이전트(`discord_bot_server.py`의 `PUBLIC_AGENT`)가 `save_memory` 도구로
직접 쓰고 커밋하는 폴더다. 사람이 직접 관리하는 문서가 아니라, 봇이 대화 중에 "나중에도
알아야 할 사실"이라고 판단한 내용을 노트로 쌓아둔 곳이다.

LangGraph의 `MemorySaver`는 인메모리라서 프로세스가 재시작되면(= 배포할 때마다) 대화 맥락이
전부 날아간다. 여기 쌓인 노트는 git에 남으므로 재시작을 넘어 축적되고, 다음 질문 때
`search_memory`가 찾아서 프롬프트에 끼워넣는다. 모델 가중치를 바꾸는 학습은 아니고,
"쓸수록 아는 게 늘어나는" 효과만 만드는 구조다.

## 주의

공개 채널은 화이트리스트가 없다 -- 그 채널을 볼 수 있는 사람이면 누구나 봇을 통해 이 폴더에
쓸 수 있다(의도된 트레이드오프). 대신 `agent_memory.py`가 다음을 코드로 강제한다.

- 쓰기 경로는 이 폴더 밖으로 나갈 수 없다
- 노트당 최대 4000자, 폴더당 최대 500개
- 커밋 대상은 이 폴더 경로만 -- 워킹트리의 다른 변경을 휩쓸어가지 않는다
- 각 노트 frontmatter에 작성자 Discord ID가 남는다 (추적/되돌리기용)

이상한 내용이 쌓이면 그냥 파일을 지우고 커밋하면 된다.
