# 예시 본문 — **여기 있는 것은 저장소에 안 올라간다**

```bash
python3 jaso/keep.py --질의 "합격 자기소개서 예시" --몇 20    # VM 에서
python3 jaso/keep.py --목록
python3 jaso/bench.py --표 원장.json --문항 "..." --예시 $(python3 jaso/keep.py --내보내기) --맨
```

`jaso/corpus/보기/` 는 `.gitignore` 에 잡혀 있고, `keep.py` 의 **K001** 이 쓰기 전에
`git check-ignore` 로 그것을 확인한다. 규칙이 없으면 **한 자도 안 쓴다** — 한 번
커밋되면 `git rm` 을 해도 히스토리에 남기 때문이다.

| | |
|---|---|
| 한다 | `bench --예시` 로 "그렇게 만들어줘" 를 **재는 것** · `mine` 으로 형식 캐기 |
| **안 한다** | 자소서 생성 재료로 그냥 쓰는 것 · `echo.py` 로 겹침을 안 재고 넘기는 것 |

**관문은 이 글과 대조하지 않는다** — 그 사람의 원장과 대조한다. 그래서 여기서 온
표현이 생성물에 남아도 관문은 초록불을 낸다. 그것을 잡는 자는 `echo.py` 뿐이다.

`README.md` 만 저장소에 있고 `*.txt` 는 없다.
