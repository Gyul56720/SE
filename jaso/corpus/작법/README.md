```bash
python3 jaso/learn.py --질의 "자기소개서 피해야 할 표현" --몇 8   # VM 에서
python3 jaso/learn.py --배운것
```

| | |
|---|---|
| `jaso/ledger` | **사실.** 사람만 채운다(`intake.py`) |
| 여기 | **글 쓰는 법.** 밖에서 온다. 관문의 사전을 늘린다 |

**남의 합격 자소서 본문은 안 받는다.** 도덕론이 아니라 기능이 무너지기 때문이다 —
원장에 넣으면 J001~J004 가 남의 이력을 대조하고, 한국 채용 실무의 주력인 **표절 검사**
DB 가 정확히 '인터넷에 도는 합격 자소서' 다. 그것을 재료로 쓰는 것이 가장 확실히
걸리는 길이다.

배운 낱말은 C001~C003 을 지나야 붙는다. 그중 **C003 이 성한 표본을 걸면 안 받는다** —
사전을 늘리다가 관문을 못 쓰게 만드는 것을 막는 자리다.

`*.json` 은 저장소에 안 담긴다(`.gitignore`).
