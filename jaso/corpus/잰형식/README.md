# 잰 형식 — **본문은 여기 없다**

```bash
python3 jaso/mine.py --질의 "합격 자소서 예시" --몇 12   # VM 에서
python3 jaso/mine.py --분포
python3 jaso/mine.py --문법후보
```

담기는 것은 **잰 수와 출처뿐**이다 — 문단 수 · 문장 길이 · 첫 문장 갈래 · 수 밀도 ·
이음말 밀도 · 상투구 수 · 본문 해시(중복 제거용). `M001` 이 본문이 섞이면 그 줄을
안 받는다.

**문법은 문장이 아니라 구조다.** 세고 나면 본문이 필요 없고, 본문을 안 남기면 남의
글이 결과물에 섞일 통로 자체가 없어진다.

## 이 수가 무엇이 아닌지

**"이 형식이면 합격률이 높다" 가 아니다.** 불합격 쪽 표본이 통째로 없다 — 합격자만
올리기 때문이다. 불합격 자소서도 같은 분포일 수 있고, 그러면 이 수는 아무것도 안
가린다. 여기서 나온 형식은 **문법 후보**이고, 순위는 `jaso/bench.py` 가 관문으로 낸다.

`*.json` 은 저장소에 안 담긴다(`.gitignore`). 본문이 없으므로 담아도 되지만, 받은
기계마다 다르게 쌓이는 것이라 기본은 안 담는다.
