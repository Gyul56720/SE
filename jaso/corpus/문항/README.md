# 문항 원장 — 받은 것이 여기 쌓인다

```bash
python3 jaso/fetch.py --질의 "2026 상반기 자기소개서 문항"   # VM 에서
python3 jaso/corpus.py --갈래
```

**여기 있는 `*.json` 은 저장소에 안 담긴다**(`.gitignore`). 남의 채용 공고문이고,
받은 사람의 기계에만 있으면 되는 것이다. 담기면 그 공고가 내려간 뒤에도 저장소에
남고, 그것은 원장이 아니라 사본이다.

**출처 없는 문항은 원장이 안 받는다.** 출처 없는 문항은 지어낸 문항과 구별이 안 되고,
지어낸 문항으로 만든 질문은 있지도 않은 공고에 맞춰 사람의 시간을 쓰게 한다.
