# 논문 — 경량화 신경망 기반 와이어라인 SerDes 등화기의 FPGA 실시간 구현

`serdes_nn_eq.html` 이 본문이다. 발행본: https://claude.ai/artifact/RYnjHwwdLHJhrjrriqihKL

## 이 파일은 조각(fragment)이다

Artifact 플랫폼이 `<!doctype>` · `<html>` · `<head>` · `<body>` 를 발행할 때 씌우므로
본문에는 그것이 없다. 브라우저에서 그냥 열어도 대개 읽히지만, 완전한 문서로 쓰려면
겉을 한 겹 둘러야 한다.

## 고칠 때 지킬 것

**숫자를 기억으로 고치지 마라.** 부록 A 가 이 논문의 절반인데, 그 목록의 A.5 가
"한 씨로 단언했다" 이고 A.4 가 "구별 안 됨을 같음으로 옮겨 적었다" 이다. 본문 숫자를
손으로 고치는 것은 그 두 항목을 다시 저지르는 가장 빠른 길이다. 코드를 돌려서 고쳐라.

**못 잰 것을 채우지 마라.** 8.1 절(전력)과 9 절(타당성 위협)이 비어 있는 자리를
일부러 비워 둔 곳이다. 대리값을 넣으려면 대리값이라고 적어야 한다.
