Multiplier-Free Sample-Indexed Lookup Equalization
for Nonlinear Wireline SerDes Receivers

Design study, NRZ wireline link model, Lattice iCE40 HX8K target
Abstract—Receiver-side nonlinearity in high-loss wireline links cannot be undone by linear equalization, and this observation is routinely used to motivate neural-network (NN) equalizers. We show that the motivation is incomplete. If the front-end nonlinearity is memoryless, its inverse is also memoryless and is therefore exactly a 2B-entry lookup table over the ADC code, costing no multipliers; measured on a 25 dB skin-effect channel with tanh compression, this 128-entry table reduces BER by 20.9× over an NLMS FFE+DFE baseline and outperforms a 96-multiplier MLP by 2.02×, after which the MLP adds nothing (0.94×). A NN earns its multipliers only when the nonlinearity has memory. We create that regime by band-limiting after compression, and identify a narrow operating window (3-dB bandwidth ≈ 0.35/T) in which an MLP beats the memoryless table on 8/8 seeds. Within that window we prove and measure a decision-domain ceiling: a linear DFE, a decision-indexed ROM, and a multiplier-free Volterra expansion over ±1 decisions all saturate near 3.1× regardless of parameter count (8 to 1351 parameters), because past decisions discard amplitude. Moving the index from decisions to quantized samples removes the ceiling: a 256-entry, 1-bit-per-entry table placed after an 11-tap FFE achieves 7.98× with zero back-end multipliers, exceeding a 96-multiplier MLP (5.80×) that does not fit the target device. Place-and-routed on iCE40 HX8K, the proposed equalizer costs 3 037 LC and 41.4 MHz against 2 999 LC and 34.7 MHz for the linear baseline — +1.3 % area, 1.19× clock, 8× lower BER. We then look for the boundary of the multiplier-free approach. Extending the model with slew-rate limiting, AC-coupling droop, far-end crosstalk, supply-gain modulation, sampling jitter and a via-stub channel resonance, we find that the binding variable is not the memory of the nonlinearity — ten octaves of added memory move the comparison by 15 % — but its severity: once both arms are given the zero-multiplier memoryless inverse, the table holds to a compression index κ ≈ 1.6 and a 12-multiplier network wins at κ=2.0 on 8/8 seeds. Three multiplier-free attempts to extend the table past that point — more cells, a leaky-accumulator memory field, and a joint amplitude/decision index evaluated with ideal feedback — all fail, and we report them. We give the full signal model, training algorithms, fixed-point definitions, and RTL.
Index Terms—Wireline SerDes, decision-feedback equalization, nonlinear equalization, lookup-table detection, Volterra series, quantization, FPGA implementation, crosstalk, timing jitter, channel modeling.

I. Introduction

In a high-loss wireline channel the pulse response spreads over many unit intervals and the eye closes through intersymbol interference (ISI). The standard remedy is a cascade of a continuous-time linear equalizer (CTLE), a feed-forward equalizer (FFE), and a decision-feedback equalizer (DFE). For a linear channel with additive Gaussian noise this cascade is asymptotically optimal in the MMSE sense, so any nonlinear detector can at best tie it.

Real receivers are not linear. Gain compression in the analog front end, buffer saturation, and driver nonlinearity all warp the signal after ISI has spread it. Such a warp has no linear inverse, and this is the standard argument for a neural-network equalizer.

The argument has a gap. “A linear FFE/DFE cannot invert it” and “a neural network is required” are different claims, and between them lies the entire class of nonlinear but non-neural correctors. In this paper we close that gap and find that it dominates the design space we studied.

Our contributions are:

  • A proposition and measurement showing that a memoryless front-end nonlinearity admits an exact 2B-entry lookup inverse over the ADC code, with zero multipliers, which outperforms an MLP of 96 multipliers by 2.02× and renders it redundant (Sec. V).
  • Identification of the regime in which a NN does earn its cost — nonlinearity with memory, created by post-compression band-limiting — and measurement of how narrow that window is (Sec. VI).
  • A decision-domain ceiling: an information argument plus measurement showing that a linear DFE, a full decision-indexed ROM, and a multiplier-free ±1 Volterra expansion all saturate near 3.1× irrespective of parameter count (Sec. VII). We prove that any polynomial in ±1 decision variables is realizable with sign-controlled additions only.
  • A sample-indexed lookup equalizer that removes the ceiling at zero back-end multiplier cost, with a hardware-realizable shift-and-clamp quantizer, its training rule, complexity analysis, RTL, and place-and-route results (Sec. VIII–X).

II. System Model

A. Channel

NRZ symbols b[n] ∈ {−1, +1} at rate 1/T are oversampled by M samples per symbol. The channel magnitude follows a skin-effect law,

|Hch(f)| = 10−(LdB/20) √(f/fN), fN = 1/(2T)(1)

with LdB the Nyquist loss. Phase is not free: a linear-phase reconstruction produces a symmetric cursor set, which removes the very post-cursor asymmetry a DFE exists to cancel. We therefore build the minimum-phase response from the real cepstrum. With N-point DFTs and c = IDFT{ln|H|},

m[k] = c[0], 2c[k]0<k<N/2, c[N/2], 0(2)
h = IDFT{ exp( DFT{m} ) }(3)

Connector and via-stub reflections are applied multiplicatively,

H(f) = Hch(f) · ( 1 + Σk Γk e−j2πfτk )(4)

which places a notch wherever f τ = 1/2, of depth 20 log10(1−|Γ|). Unlike skin-effect loss, a notch removes one frequency and cannot be filled by the smooth boost of a CTLE. In the time domain it appears as an isolated cursor at lag τ/T.

B. Noise and receiver nonlinearity

Additive Gaussian noise is referenced to the main cursor of a lossless link, so that the loss-free, unequalized link satisfies a closed form used later for calibration:

r(t) = (x ∗ h)(t) + w(t), σ = 10−SNRdB/20(5)

Front-end compression is applied after noise and before equalization, which is where a VGA/CTLE stage sits:

g(u) = tanh(a u)a, a = κRMS(u)(6)

where κ is the compression strength. Two properties of (6) matter. First, it is memoryless: g acts on one sample. Second, applying it at the transmitter would do nothing at all — NRZ has only two levels, so a memoryless map is a pure gain change and the slicer output is unchanged. Nonlinearity acquires meaning only after ISI has spread the levels, which is why it is placed at the receiver.

C. Post-compression band-limiting

A real receiver filters again after the compressing stage — CTLE loading, ADC input network, package. We model this with a Hann low-pass q of 3-dB bandwidth β/T:

v[n] = Σm q[m] · g( r[n−m] )(7)

Equation (7) is the crux of this paper. When q = δ, v[n] is a function of r[n] alone and the nonlinearity remains memoryless. When q has support greater than one, v[n] mixes several compressed values and no memoryless map can recover r[n]. The parameter β therefore moves the impairment continuously between two qualitatively different classes.

D. Quantization and gain control

Sampling at the pulse-response peak phase, a B-bit ADC with full scale ρσv yields

y[n] = Δ · clip( round(v[n]/Δ), −2B−1, 2B−1−1 )(8)

with Δ = ρ σv/2B−1, σv estimated over the training preamble. A digital AGC then normalizes by the measured main-cursor gain γ = E[y b] taken over the preamble only.

E. Calibration

With LdB = 0, κ = 0 and no equalizer, the model must reproduce BER = Q(10SNR/20). Over 4×105 bits the measured values agree to 0.49 %, 3.03 % and 1.30 % at 6, 8 and 10 dB, all inside the 3σ counting error. An SNR without such a definition is an arbitrary number.

III. Baseline Equalizers

A. NLMS feed-forward equalizer

The FFE is adapted by normalized LMS over the preamble. With tap vector w ∈ ℝL, input window y[n] = (y[n], …, y[n−L+1])T and reference delay D = ⌊L/2⌋,

e[n] = wTy[n] − b[n−D](9)
w ← w − μL P e[n] y[n], P = E[y2](10)

The division by L is not cosmetic. The LMS stability bound is μ < 2/(L σy2), so normalizing by power alone diverges as taps are added; with power-only normalization a 29-tap FFE diverged to tap magnitudes of 1.08×106 in our runs, which would have been misread as “more taps do not help.” We use μ = 0.2 throughout.

B. Decision feedback with arbitrary tap placement

The slicer feeds back its own decisions — substituting true bits removes error propagation and inflates BER by orders of magnitude. For tap positions p1…pK (not necessarily contiguous) and coefficients ck,

d̂[n] = sgn( yf[n] − Σk=1K ck d̂[n−pk] )(11)

Because d̂ ∈ {−1,+1}, every product in (11) is a sign selection: a DFE tap contains no multiplier, only an add/subtract. This is the single most important cost asymmetry in the paper and it recurs in Sec. VII.

Free tap placement matters more than tap count. For Γ = 0.35 at τ = 11T, the residual cursor after an 11-tap FFE is ≤ 0.055 at lags 1–10 and +0.358 at lag 11. A single floating tap at 11 is worth 8.2× in BER over a tap at 10 or 12; a pair of adjacent taps removes that cliff entirely (Table I). Locating the reflection by correlation needs only 200 symbols (12/12 seeds), so tracking a drifting reflection is an operational matter, not a design constraint.

C. Word length

Coefficients and ADC are quantized jointly, since they are not chosen independently in practice. Sweeping channel loss with each point re-normalized to a BER of 10−3, 7 bits is flat to 20 dB; at 25 dB the 6-bit setting averages +26.6 % but spreads over [+6.5, +69.6] % across seeds, which is why it is not usable. Above 30 dB no width in the swept range satisfies both a small mean and a small spread. The ADC optimum is ρ = 2.5σ at every resolution, with a clipping fraction of 0.43 % rather than zero — a well-set ADC deliberately clips a little. The joint operating point used throughout is 7-bit coefficients, 7-bit ADC, which costs +2.2 % BER relative to floating point.

IV. Neural-Network Equalizer

A. Architecture and training

The NN equalizer is a single-hidden-layer MLP over a centred tapped-delay line of the ADC samples. With window half-width A, L = 2A+1, hidden width H:

x[n] = ( y[n−A], …, y[n+A] )T(12)
z = W1Tx + b1, h = φ(z), u = w2Th + b2(13)
d̂[n] = sgn(u[n])(14)

Training minimizes the MSE to b[n] with Adam over the first 30 % of the record; BER is counted on the remainder only. The multiplier count is LH + H.

The activation is chosen by BER, not by approximation error. Hardware cannot evaluate tanh directly, so we compare tanh against hardtanh(z) = clip(z,−1,1) — two comparisons, no table — and a three-segment piecewise-linear fit pwl3. At 12 multipliers hardtanh wins on 7 of 8 seeds (sign test p ≈ 0.04). Notably pwl3 approximates tanh far better yet is worst in BER at every size (1.4–1.9×), because the network adapts to whatever nonlinearity it is given: a better approximation is not a better equalizer.

B. Quantization

Per-tensor scaling destroys the network. A trained W1 of shape 21×16 has max 2.4003 and median 0.1133 — a spread of 21× — so a 4-bit tensor-wide step of max/7 rounds all but 138 of 369 weights to zero. Per-output-channel scaling,

sj = maxi |Wij|, Ŵij = sjS clip( round( S Wij/sj ), −S−1, S )(15)

with S = 2Bw−1−1, keeps 282 of 369 alive at 4 bits. Linear equalizer taps span one decade and tolerate tensor scaling; NN weights do not. Quantization-aware training with a straight-through estimator and a grid frozen at the float solution was implemented but did not establish a gain at this scale: the winning width moved between variants and the seed spread exceeded the differences. What is established is post-training quantization with per-channel scaling.

The dominant lightweighting axis in the swept space is network size, not width:

Twelve multipliers buy 41 % of the available gain; a further 15× in multipliers buys 1.5× more. By comparison, 8→6 bit saves 14.8 % area for 31 % worse BER — a far smaller handle.

C. Fixed point

The integer reference that the RTL must match is

zq = ( XqW1q + b1q 2F ) >> F(16)
hq = clip( zq, −2F, 2F ),  uq = hqw2q + b2q2F(17)

where F is the fractional width and >> is an arithmetic shift. Sweeping total width and F independently separates two effects that are usually conflated. Performance is set by the integer headroom, not the fractional resolution: width 8/F = 6 and width 10/F = 8 — both with one integer bit — are equally bad (1.84× and 1.86× float), while any format with two integer bits and F ≥ 4 matches float (0.98–1.00×). The minimum is therefore Q2.4 in 7 bits, which is the same width the linear FFE needs. Choosing Q3.6/10-bit instead, as we did initially, costs 1.9× the area for identical BER.

Accumulator widths are sized so that no truncation occurs: with Wx, Ww the sample and weight widths,

Wz = Wx+Ww+⌈log2(L+1)⌉, Wh = F+2(18)
Wu = Wh+Ww+⌈log2(H+1)⌉(19)

V. The Memoryless Inverse

We now supply the control that the usual motivation omits.

Proposition 1. Let the receiver impairment be y[n] = QB(g(r[n])) with g memoryless and strictly monotone and QB a B-bit quantizer. Then the MMSE memoryless corrector is exactly the table
T[c] = E[ r[n] | y[n] = c ], c ∈ {0,…,2B−1}(20)
and no memoryless corrector of any complexity can do better.

Proof. A memoryless corrector is a map from the observation alphabet to ℝ. The observation alphabet is the set of 2B ADC codes, hence any such map is a table of 2B entries. Among all such maps the conditional mean minimizes mean-square error. □

The consequence is a hardware statement: inverting a memoryless nonlinearity costs one ROM read and no multiplier. For B = 7 that is 128 entries. When the compression law is known the table can also be written in closed form,

Tinv(z) = 1a artanh( clip(a z, −1+ε, 1−ε) )(21)

which is an upper bound on any data-driven memoryless corrector, since it assumes exact knowledge of a. The clipping in (21) is physical, not numerical: artanh diverges as |az|→1, and that divergence is the statement that information destroyed in saturation cannot be recovered — inverting there only amplifies noise.

Table III settles the question for this impairment. The 128-entry table beats the 96-multiplier network by 2.02× and the 12-multiplier network by 3.9×, adding no multipliers. More decisively, once the table is applied the network contributes nothing (0.94×; 3.3×106 bits would be needed to separate the two). The residual impairment after memoryless correction is linear, and a linear equalizer handles it.

The precise claim is therefore not “a neural network solves what a linear equalizer cannot,” but rather: a linear FFE/DFE cannot invert a memoryless warp, and a network does so more expensively and less well than a table.

VI. Nonlinearity With Memory

Proposition 1 depends on the impairment being a function of a single sample. Equation (7) breaks that condition: after band-limiting, v[n] depends on g(r[n]), g(r[n−1]), … jointly, so the map r[n] ↦ v[n] is not injective and (20) is no longer sufficient. This is where a nonlinear detector with memory becomes necessary.

At β = 0.25 the mean ratio of 2.28× is produced by a single seed at 11.90× while the network wins only 1 of 8 — not an established result. All experiments in Sec. VII–X are conducted at β = 0.35.

VII. The Decision-Domain Ceiling

Within the window, what can be achieved without adding multipliers? The cost structure measured on the target device is:

A. Decision-indexed ROM

A linear DFE computes a linear function of the past L decisions. Replacing it by an arbitrary function of the same inputs is one table of 2L entries and still contains no multiplier. With index

ι[n] = Σk=0L−1 2k · 1[ d̂[n−1−k] > 0 ](22)
T[i] = E[ yf[n] − b[n] | ι[n]=i ](23)
d̂[n] = sgn( yf[n] − T[ι[n]] )(24)

The table is trained on the preamble with known bits — the standard situation — but indexed at run time by the receiver's own decisions, so error propagation behaves exactly as in a DFE. Cells with fewer than a threshold of training samples fall back to the linear DFE value; otherwise rare patterns memorize noise.

This structure strictly generalizes the DFE, so a control is available: on a linear channel the optimal post-cursor canceller is linear and the ROM must not win. It does not — 6.5060e−04 versus 6.5595e−04, winning 3 of 8 seeds, requiring 3.6×108 bits to separate. Inside the window it reaches 3.08×, but depth does not help beyond 8–10 and then hurts (2.13× at depth 12), because 4096 cells over 9×104 training symbols is 22 samples per cell. The ceiling of a table is set by training data, not by area.

B. Volterra over ±1 decisions

Proposition 2. Let d1…dL ∈ {−1,+1}. Every monomial ∏k∈S dk takes values in {−1,+1}, and its value is determined by the parity (XOR) of the sign bits of {dk}k∈S. Consequently any polynomial
f(d) = w0 + Σ|S|≤D wS ∏k∈S dk(25)
is realizable with sign-controlled additions only, using no multipliers, with Σj≤D C(L,j) coefficients.

Proposition 2 gives exactly the parameter sharing a table lacks: the full ROM is the degree-L case with 2L coefficients, while truncating to degree D reduces this to O(LD) at unchanged multiplier cost. Coefficients are fit by least squares on the preamble design matrix of monomials; for evaluation we expand them back into a 2L table, the two realizations being equivalent in hardware (one adder tree of |S| terms, or one ROM read).

It does not work.

C. Diagnosis

Three structurally different correctors — linear, degree-truncated polynomial, and full table — saturate at the same value while their parameter counts span 8 to 1351. An MLP with roughly 193 parameters reaches 5.80×. The common property of the saturating three is their observation.

Proposition 3. Let On be the observation available to a detector. The minimum achievable error probability given On is that of the MAP rule sgn E[b[n] | On], and a lookup table indexed by a finite quantization of On converges to it as the training record grows. Hence detectors that differ only in On are ordered by the information On carries about b[n].

Decisions d̂[n−1],…,d̂[n−L] are one-bit functions of past observations. They carry no information about the amplitude of the current sample, and it is precisely amplitude that (7) mixes. The limit is the observation, not the parameter count — which is why adding 1343 parameters moves the result by 0.23× while changing the observation moves it by more than 2×.

A corollary, also measured: composing two individually correct correctors can be worse than either. Inverse table followed by decision ROM gives 2.11× against 3.08× for the ROM alone (7/8 seeds worse), because artanh amplifies noise in the saturated tail and the ROM then averages a noisier signal.

VIII. Proposed: Sample-Indexed Lookup Equalizer

Proposition 3 prescribes the fix: move the index from decisions to samples. It does not prescribe multipliers — a coarsely quantized sample is an address.

A. Architecture

The FFE is retained, because the table cannot perform linear equalization (Sec. X). Its accumulator a[n] is quantized by an arithmetic shift and a clamp, and W consecutive codes form the address:

c[n] = clip( (a[n] >> s) + 2Q−1, 0, 2Q−1 )(26)
ι[n] = Σk=0W−1 c[n−k] · 2Qk(27)
T[i] = E[ b[n] | ι[n]=i ],  d̂[n] = sgn( T[ι[n]] )(28)

By Proposition 3, (28) is the empirical MAP detector on the quantized W-sample observation. Because only the sign of T is used, the stored table is one bit per entry: 2QW bits, i.e. 256 bits at Q=4, W=2. The back end contains no multiplier and no adder — a shift, a clamp, a concatenation and a ROM read. There is also no decision feedback: past codes are retained, not past decisions, so there is no error propagation and no feedback loop to constrain pipelining.

The quantizer must be hardware-realizable. Stretching by a training percentile requires a multiply; (26) uses a power-of-two step chosen once from the preamble RMS. Measured, the restriction is not a cost at all: 7.98× for the shift quantizer against 7.80× for the percentile version.

Algorithm 1: Training the sample-indexed table
  1. Adapt FFE taps w by NLMS (9)–(10) on the preamble.
  2. Estimate σ = RMS(a[n]) over the preamble; set
    s = round( log2( ρσ / 2Q−1 ) ).
  3. Zero accumulators: S[i] ← 0, N[i] ← 0 for all i.
  4. For each preamble index n: form c[n] by (26) and ι[n] by (27); S[ι] ← S[ι] + b[n]; N[ι] ← N[ι] + 1.
  5. For each cell i: T[i] ← 1 if N[i] ≥ Nmin and S[i] ≥ 0; T[i] ← 0 if N[i] ≥ Nmin and S[i] < 0; else default.
  6. Write T into the ROM through the coefficient port.

Step 5 is a single pass of counting; no gradient, no iteration, and the convergence criterion is simply how many samples each cell has received. Complexity is O(Npre) time and O(2QW) memory.

def build_table(a, b, n_tr, W=2, Q=4, rho=2.5, n_min=4):
    """a: FFE accumulator; b: +-1 bits; n_tr: preamble."""
    rms  = np.sqrt(np.mean(a[:n_tr] ** 2)) or 1.0
    step = 2.0 ** np.round(
        np.log2(rho*rms / (1 << (Q-1))))     # eq.(26)
    code = np.clip(np.floor(a / step) + (1 << (Q - 1)),
                   0, (1 << Q) - 1).astype(np.int64)

    idx = np.zeros(len(a), dtype=np.int64)   # eq.(27)
    for k in range(W):
        past = np.concatenate(
            [np.zeros(k, np.int64), code[:len(a) - k]])
        idx += past << (Q * k)

    cells = 1 << (Q * W)
    s = np.zeros(cells);  n = np.zeros(cells)
    np.add.at(s, idx[:n_tr], b[:n_tr])  # preamble only
    np.add.at(n, idx[:n_tr], 1.0)
    T = np.where(n >= n_min, s / np.maximum(n, 1.0), 0.0)
    return np.where(T[idx] >= 0, 1.0, -1.0), T, step

B. Complexity

Let Lf be the FFE length. Per symbol the proposed equalizer costs Lf multiplies (FFE), one shift, two comparisons, one concatenation and one ROM access. The DFE it replaces costs K add/subtracts in a serial chain; the MLP it replaces costs LH+H multiplies in two serial layers. Memory is 2QW bits against K Wc bits for the DFE and (LH+2H+1)Ww for the MLP.

The exponential memory in QW is the binding constraint, and it binds through data rather than area: the number of cells that receive enough training samples grows far more slowly than the number of cells. At Q=4, W=2 (256 cells) 217 are populated and the gain is 7.98×; at W=3 (4096 cells) only 1531 are populated and the gain collapses to 2.01×. Enlarging the observation window without enlarging the preamble is counter-productive.

IX. RTL and Implementation

Listing 2 gives the synthesizable core. The FFE products are formed at exact width, the accumulator is sized by (18), and the quantizer is a shift with saturation. The coefficient and table write ports keep the adaptation engine out of the datapath; exporting coefficients to top-level pins instead would exhaust the device I/O long before its logic.

module ffe_tbl #(parameter L=11, W=7, DW=7, FW=18,
                 SH=6, QB=4, WIN=2, TA=8, NT=256)(
  input  wire clk, rst_n,
  input  wire signed [DW-1:0] x,
  input  wire cw_we,  input wire [3:0]    cw_addr,
  input  wire signed [W-1:0]  cw_data,
  input  wire tw_we,  input wire [TA-1:0] tw_addr,
  input  wire tw_data,
  output reg  d);

  reg signed [DW-1:0] sr   [0:L-1];
  reg signed [W-1:0]  coef [0:L-1];
  reg                 tbl  [0:NT-1];   // 1 bit / entry

  wire signed [W+DW-1:0] prod [0:L-1];
  wire signed [FW-1:0]   ext  [0:L-1];
  genvar i;
  generate for (i=0;i<L;i=i+1) begin : taps
    assign prod[i] = coef[i] * sr[i];
    assign ext[i]  = {{(FW-W-DW){prod[i][W+DW-1]}},
                      prod[i]};
  end endgenerate

  integer k;  reg signed [FW-1:0] accf;
  always @* begin
    accf = 0;
    for (k=0;k<L;k=k+1) accf = accf + ext[k];
  end

  // eq.(26): arithmetic shift + clamp, no multiply
  wire signed [FW-1:0] sh = accf >>> SH;
  localparam HI =  (1<<(QB-1)) - 1;
  localparam LO = -(1<<(QB-1));
  wire [QB-1:0] qcode = (sh > HI) ? {QB{1'b1}} :
                        (sh < LO) ? {QB{1'b0}} :
              (sh[QB-1:0] + {1'b1,{(QB-1){1'b0}}});

  reg [QB-1:0] qreg;                   // pipeline reg
  reg [QB-1:0] pcode [0:WIN-2];
  reg [TA-1:0] addr;
  always @* begin                              // eq.(27)
    addr = {{(TA-QB){1'b0}}, qreg};
    for (k=0;k<WIN-1;k=k+1)
      addr = addr | ({{(TA-QB){1'b0}}, pcode[k]}
                     << (QB*(k+1)));
  end

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      for (k=0;k<L;k=k+1) begin
        sr[k] <= 0;  coef[k] <= 0;
      end
      for (k=0;k<WIN-1;k=k+1) pcode[k] <= 0;
      for (k=0;k<NT;k=k+1)    tbl[k]   <= 1'b0;
      qreg <= 0;  d <= 1'b0;
    end else begin
      if (cw_we) coef[cw_addr] <= cw_data;
      if (tw_we) tbl[tw_addr]  <= tw_data;
      sr[0] <= x;
      for (k=1;k<L;k=k+1) sr[k] <= sr[k-1];
      qreg     <= qcode;
      pcode[0] <= qreg;
      for (k=1;k<WIN-1;k=k+1) pcode[k] <= pcode[k-1];
      d <= tbl[addr];                          // eq.(28)
    end
  end
endmodule

Because the structure has no feedback, the single register on qreg splits the critical path into multiply→adder tree→shift/clamp and ROM read, raising Fmax from 26.62 to 41.38 MHz at lower area. Latency rises by one cycle; throughput is unchanged, since the equalizer emits one decision per symbol. The same cut cannot be applied inside a DFE loop, where inserting a register delays the feedback itself.

X. Results

A. Bit error rate

Two facts bound the claim. The 256-cell table exceeds the 96-multiplier MLP (5.80×, Table VI) using no back-end multipliers. And without the FFE the table fails outright (0.26–0.63×): it cannot perform linear equalization, so “multiplier-free” describes only the stage that replaces the DFE or the network, not the receiver.

The required control is that on a linear channel, where the optimal equalizer is linear, the table must not win:

On a linear channel the table ties or loses badly — it observes two samples and cannot match the span of an 11+8-tap linear equalizer. This is the expected and required behaviour.

B. Area and timing

All designs were synthesized with Yosys and placed and routed with nextpnr on a Lattice iCE40 HX8K (7680 logic cells), targeting 50 MHz; no timing-failure override was used. The device has no hard multipliers, so all products map to LUTs.

Against the linear baseline the proposed equalizer costs +1.3 % area, runs 1.19× faster, and lowers BER by 8×. Against an area-matched network it is 30 % larger and 14 % slower but 3.1× better in BER; the network configuration that would reach 5.80× requires roughly 19 000 LC and does not fit the device.

Two scaling laws were measured. First, the table stage is linear in cell count at ≈3.2 LC per cell (810 LC at 256 cells, 3283 at 1024, 12698 at 4096). The stored data is only 256 bits; the area is the address decode and the write port. A 256-cell table is therefore comparable in area to an 8-tap DFE (762 LC): multiplier-free is not free. Second, since gain falls with cell count beyond 256 (Table VII) while area rises linearly, this axis offers nothing to trade.

Multiplier width follows an approximately quadratic law in the neural path: widening Q2.4/7-bit to Q2.5/8-bit costs 1.272× the area against a quadratic prediction of 1.306×, and 8→10 bit costs 1.494× against 1.563×. With three points we report consistency with quadratic scaling rather than fitting an exponent.

C. Pipelining

One register stage raises Fmax by 53–70 % across all three designs at no area cost (−1.4 % to +2.2 %), and every pipelined variant emits the identical decision sequence one cycle later. It does not, however, reorder the designs: the linear baseline improves by the same proportion, because only the DFE feedback loop resists cutting and that loop is not the critical path. None of the three reaches the 50 MHz target; the best is 4 % short.

XI. Where the Lookup Equalizer Fails

The previous edition of this work closed with an admission: the address space 2QW must eventually grow out of reach, “but we did not construct such a case, and therefore we have not demonstrated a regime that requires a neural equalizer.” This section constructs the case. The outcome is not the one we predicted, and we report the prediction and its refutation together, because the refutation is the result.

A. Extended impairment set

Five impairments are added to the model of Sec. II. Slew-rate limiting, the finite current of an amplifier driving a capacitive load, is a nonlinear recursion whose memory grows as the limit tightens:

v[n] = v[n−1] + clip( u[n] − v[n−1], −S, +S )(29)

AC-coupling droop is a first-order high-pass whose memory is set directly by a time constant, and whose interaction with a following compressor is the mechanism we intended to exploit: the amount by which a sample is compressed comes to depend on a slow baseline:

b[n] = a b[n−1] + (1−a)u[n],  v[n] = u[n] − b[n],  a = e−1/τ(30)

Far-end crosstalk adds an independent PRBS aggressor through the same channel with a differentiating coupling; supply noise modulates the front-end gain multiplicatively, y[n](1 + m sin 2πn/MP); and residual timing error displaces the sampling instants, the samples being taken by linear interpolation:

t[n] = φ + nM + M ( σrjg[n] + Asj sin 2πn/Psj )(31)

Finally the channel itself is re-parameterized. A single √f term is the shape of conductor loss alone; a printed-circuit link also carries dielectric loss proportional to f, and the most conspicuous feature of a measured S21 is neither — it is the resonance of an unused via stub, which shorts the line at its quarter-wave frequency:

|H(f)| = 10−(αc√(f/fN) + αd(f/fN))/20 · | 2 / (2 + j s tan 2πfτs) |(32)

Minimum phase is imposed as in (2). Two checks pin the parameterization: with αd=0 and s=0, (32) reproduces the channel of Sec. II to 4×10−17; and the notch falls at 1/(4τs), measured at 1.00 fN for τs=0.5 T and 0.50 fN for τs=1.0 T. At equal 20 dB Nyquist loss the two mechanisms are not interchangeable: the main cursor is 0.238 under conductor loss and 0.358 under dielectric loss.

B. Long memory does not break the table

The droop of (30) reaches 18.8 UI — an order of magnitude beyond the W=2 window — and the prediction was that the table would collapse there. It does not. Holding every other parameter at the operating point of Sec. X and changing one variable at a time:

Ten octaves of added memory move the ratio by 15 %. Nonlinearity severity moves it by a factor of three, monotonically and on 8/8 seeds. The hypothesis that motivated this section — memory length as the binding variable — is not supported. Sweeping τ over 5–150 UI at a harsher operating point reproduces the same flatness: the NN/table ratio stays within 1.21–2.66× with no trend in τ.

C. The real mechanism, and a defect in the comparison

Why should compression severity favour a network? It should not — by Proposition 1 a memoryless warp is exactly invertible by an ADC-code table at zero multipliers, and severity is precisely what that table absorbs. Inspecting the configuration revealed that the table path did not have one. The compressed signal was being fed directly to the NLMS front end, so as κ grew it was the linear adapter that degraded, not the table. Installing the memoryless inverse of Sec. V — which the paper already advocates, and which costs nothing — ahead of both structures repairs it:

At κ=2.0 the table improves by 5.2× from a stage that costs no multipliers, and the apparent superiority of the network at κ=1.6 disappears. Neither structure is being measured until both are given the front end that Proposition 1 prescribes. An architecture comparison is only as good as the weaker arm’s configuration, and for three editions the weaker arm was ours.

D. The crossover, measured fairly

With the memoryless inverse installed on both sides, the boundary is sharp and it is in κ, not in memory:

The zero-multiplier arm holds to κ ≈ 1.6 and loses at κ=2.0 on every seed. This is the regime that requires a network, and it is a regime of severity, not of memory. Adding droop to this sweep does not shift the boundary in a reproducible direction: the ratios become non-monotone in κ (0.81, 0.88, 1.44, 0.78), and we draw no conclusion from them.

E. Three attempts to rescue the table, all failed

Enlarge it. At every training budget a larger address space is worse, and the constraint is data rather than area: with 1.92×105 training symbols a 32 768-cell table populates 11 339 cells (35 %) against 256/256 for the small one, and its BER is six times worse. Preamble length is fixed by the standard, so this axis is closed to the designer.

Summarize the past into one address field. A leaky accumulator m[n] = m[n−1] + (x[n]−m[n−1])>>k costs one shift and two adds and looks back 2k samples; appending its code to the address should buy memory for a few bits instead of a few octaves. Measured, every configuration was worse than spending the same bits on one more raw sample (4.20e−3 and 5.38e−3 against 2.87e−3 for a 1024-cell two-sample table). An address bit is worth what it carries, and a neighbouring sample carried more than a slow mean.

Index on amplitude and past decisions jointly. Decisions are free (Sec. VI) and each costs one address bit, so a hybrid index is the natural union of the two structures of this paper — and, evaluated with ideal past decisions, it is an upper bound on any table-plus-DFE. It helps and it is not enough: 2.62e−3 at 2048 cells against 3.63e−3 for the plain table and 9.2e−4 for the network on the same data. The ceiling of Proposition 3 is relaxed by the amplitude field but not removed.

F. Crosstalk, supply noise and timing error

These three are not equalizable by any of the structures considered — they are, respectively, another transmitter’s data, a time-varying gain and a displacement of the observation. The question they answer is whether the ordering survives them.

The ordering is preserved throughout; no impairment reverses a conclusion of Sec. X. Two specific expectations were wrong. We expected a static table to be hurt more by a time-varying gain than a slicer is, because a stored cell acquires a different meaning at each phase of the modulation; measured over 4×105 bits and 4 seeds at ±50 %, the penalty is 2.43× for the table against 2.66× for the linear slicer — no asymmetry. And because m < 1 cannot change a sign, the absolute penalty from supply noise is small for every structure. Timing error is non-monotone in this regime (RJ 0.05 UI improves on RJ 0) because our interpolating sampler low-passes the waveform slightly; on a linear channel the same sweep degrades monotonically (7.1e−5 to 6.4e−4 at 0.12 UI), so the non-monotonicity is an artifact of the impairment, not of the structures.

G. What the crossover costs

The network that wins at κ=2.0 is the same NN 5→2 of Table IX: 12 multipliers, 2336 LC, 47.87 MHz. It is smaller and faster than FFE 11 + table (3037 LC, 41.38 MHz). Where a network is genuinely required, it need not be a large one — and the multiplier-free thesis of this paper does not survive by an area argument at that point, it simply ceases to apply. Networks large enough to exploit a long observation, by contrast, are unbuildable on this device:

H. What is still missing

The channel of (32) is a physical parameterization, not a measurement. Obtaining Touchstone data requires network access that the environment in which this work was produced does not have, and we state this rather than presenting a model as data. The gap is not cosmetic: with a via stub placed so that its notch falls inside the band (τs=0.6 T, notch at 0.72 fN, −50 dB) every structure operates between 5 % and 14 % BER, a regime of information loss in which the equalizer choice is nearly irrelevant. With the notch moved just above the band (τs=0.35 T) the conclusions of Sec. X reappear intact: the table is best on the linear-plus-memoryless channel (4.97e−4 against 1.05e−3 for the network, 0/6 network wins), and the network is best once a long-memory nonlinearity is added (3.62e−3 against 6.65e−3, 6/6). Whether a measured channel lands nearer the first case or the second is the single largest open question in this work.

XII. Discussion and Limitations

The impairment model determines the conclusion. This is the principal threat to validity. Section V shows that a memoryless warp is best undone by a 128-entry table; Section VIII shows that a memory-2 warp is best undone by a 256-entry table. Both conclusions are statements about the structure of the impairment. Sec. XI constructs the case in which the zero-multiplier arm loses, and locates it in the severity of the nonlinearity (κ ≈ 2) rather than in its memory: ten octaves of added memory move the comparison by 15 %, while severity moves it by a factor of three. The address-space argument that motivated this paper is therefore correct in form and wrong about which variable binds first.

Channel and device scope. The channel remains synthetic. Sec. XI-A adds the two loss mechanisms separately, a via-stub resonance, crosstalk, supply noise and sampling jitter, and Sec. XI-F shows the ordering survives all of them — but a physical parameterization is still not a measurement, and measured S-parameters remain the largest gap. The target device has no DSP blocks, so all multipliers map to LUTs and the relative cost of a multiplier is at its most unfavourable; on a DSP-bearing FPGA or an ASIC the area comparison would shift in favour of the multiplier-based designs.

NRZ only. Two results depend on binary decisions: DFE taps are multiplier-free because d̂ ∈ {±1}, and the table stores one bit per cell. Under PAM4 neither holds, the decision alphabet grows, and the address space of any sample-indexed table grows with it.

Timing recovery. Sec. XI-F adds residual random and sinusoidal sampling jitter (31) and finds the ordering unchanged to 0.15 UI rms, but no CDR loop is simulated: the model applies jitter that a loop has already failed to track and cannot reproduce loop bandwidth, pattern-dependent jitter, or the interaction between a nonlinear detector and the phase detector that feeds it. That interaction is untested.

Rare-event behaviour. The operating BERs here are 10−2–10−3. Counting to a compliance floor of 10−12 would require 3×1012 bits — 242 core-days at the measured 1.4×105 bit/s — so statistical extrapolation is unavoidable, and the usual Gaussian-tail argument does not transfer cleanly to a nonlinear decision boundary. A table has a specific exposure here: under-populated cells emit a default, and nothing guarantees that default is correct for rare excursions. This is untested and is the most likely place for the present results to fail.

Adaptation protocol. Standards prescribe how equalizer coefficients are negotiated, typically as increment/decrement handshakes over a back channel. Neither a weight matrix nor a populated table speaks that language. The table is arguably closer — it is filled by one counting pass over the preamble, so its convergence criterion reduces to samples-per-cell — but mapping either onto a standard link-training sequence is unaddressed here.

XIII. Conclusion

The common motivation for neural equalization in wireline receivers — that linear equalizers cannot invert front-end nonlinearity — is true but insufficient. For a memoryless nonlinearity the optimal memoryless corrector is a 2B-entry table with no multipliers, and measured on our model it outperforms a 96-multiplier MLP by 2.02×, after which the network is redundant.

Where nonlinearity does have memory, we showed that all structures observing only past decisions — linear DFE, decision-indexed ROM, and multiplier-free Volterra expansions — saturate near 3.1× irrespective of parameter count, because decisions discard the amplitude that the impairment mixes. Changing the observation rather than the parameter budget removes the ceiling: a 256-entry, one-bit-per-entry table indexed by two quantized FFE output samples achieves 7.98× with zero back-end multipliers, exceeding a 96-multiplier network that does not fit the target device, at +1.3 % area and 1.19× the clock of the linear baseline.

The organizing principle is that impairments decompose and each class has a matched corrector with a characteristic hardware cost: memoryless warp → code table (0 multipliers); linear pre-cursor ISI → FFE (1 multiplier per tap); linear post-cursor ISI → DFE (0); decision-dependent nonlinearity → decision table (0); sample-dependent nonlinearity with memory → sample table (0) up to the address space it can populate, and only beyond that a parametric network. A general-purpose MLP is expensive precisely because it does not exploit this decomposition, spending multipliers on work that costs none in the matched structure.
