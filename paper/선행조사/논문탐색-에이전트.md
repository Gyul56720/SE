# 선행조사 -- 논문 탐색·분석 에이전트

짓기 전에 적는다(CLAUDE.md: "짓기 전에 조사한다 -- 순서를 뒤집지 않는다").
이 저장소는 같은 방식으로 **다섯 번** 졌다: 고르고 · 짓고 · 재고 · 원고까지 쓰고,
**그러고 나서** 이미 있는 것을 알았다.

## 1. 이 저장소에 이미 있는 것

| 있는 것 | 하는 일 | 못 하는 일 |
|---|---|---|
| `dig/paper.py` | arXiv 한 편을 **읽을 글자로** 내린다(HTML → ar5iv → abs → PDF → TeX). 수식은 LaTeX 원문, 표는 구조, 그림은 캡션+포인터 | **arXiv 만.** 절(section) 구분이 없다 -- 서론·배경을 따로 못 꺼낸다. **레퍼런스를 안 판다** |
| `dig/harvest.py --논문` | arXiv 를 최신순으로 훑어 위 도구로 내리고 색인 | 최신만 본다. **과거로 거슬러 올라가는 길이 없다** |
| `research/run.py` | 목표 → 추상 질의 여럿 → 수집 → 코드화 → 결론(3~5 바퀴) | 편들을 **견주지** 않는다. "이 다섯 편의 공통 한계" 를 못 뽑는다 |
| `codify/` | 논문의 수식·알고리즘을 코드로 | 탐색이 아니다 |

**즉 '한 편을 읽는 것' 은 있고 '여러 편을 흐름으로 잇는 것' 이 없다.**

## 2. 바깥의 선행연구 -- 가장 가까운 것들

| 도구 | 하는 일 | 우리와 다른 점 |
|---|---|---|
| **Connected Papers** | 공인용(co-citation)·서지결합으로 이웃 지도 | 웹 앱, 무료판 월 5장. 대화형 탐색이 목적 [출처:조각] |
| **ResearchRabbit** | 씨앗 논문에서 유사·인용을 넓혀 수집 | 무료판 검색 무제한, 씨앗 50편 상한 [출처:조각] |
| **Elicit** | 초록·본문을 **모델로** 읽어 질의에 맞는 것을 찾음 | 인용 그래프가 아니라 의미 검색. 모델 비용이 든다 [출처:조각] |
| **Litmaps** | 시간축 위의 인용 지도 | 위와 같은 갈래 [출처:조각] |
| **OpenAlex** | 2.4억 편 + 25억 인용 링크. **열쇠 없이** 무료, 일 10만 건. 한 편마다 제목·저자·초록·OA 여부·**참고문헌 목록**·피인용수 | 도구가 아니라 **바탕 데이터**다. 우리가 쓸 재료 [출처:조각] |

**결론: 인용 그래프 탐색은 이미 잘 팔리는 물건이다.** 우리가 지을 것은 *새로운 연구*가
아니라 **통합**이다 -- 그렇게 적는다. 새것인 척하지 않는다.

우리 것이 다른 자리는 셋뿐이고, 셋 다 "더 똑똑해서" 가 아니라 "여기에 붙어 있어서" 다.

1. **결과가 보고서다.** 저 도구들은 화면이다. 우리 것은 `house/` 와 같은 꼴의 PDF +
   원장 줄을 낸다 -- 면접/포트폴리오에 그대로 쓰는 것이 목적이므로 화면이 아니라 글이
   필요하다.
2. **확인수준을 같이 적는다.** 이 저장소의 규율이다(`paper/출처.jsonl`: 전문·초록·목록·
   조각). 유료 논문은 초록까지만 읽고 **초록까지만 읽었다고 적는다.** 저 도구들은 그
   구분을 안 한다.
3. **모델을 안 쓴다(기본값).** 절차가 정해져 있으므로 코드로 충분하다. 지금 이 저장소의
   병목이 분당 한도인데, 탐색까지 LLM 으로 하면 그 병목을 키운다.

## 3. 영상이 말한 절차 (사용자가 준 것)

    제목 -> 초록 -> **서론 · 배경** -> (본문은 필요할 때만) -> **레퍼런스로 과거 거슬러**
    한 주제에 **다섯 편 이상** -> 공통 패턴(무엇이 문제였나 · 왜 새 접근이 필요한가)

핵심 두 가지가 우리에게 **없다**: 절 단위로 서론·배경만 꺼내기, 그리고 레퍼런스를 타고
과거로 가기. 이 둘이 이번에 지을 것의 전부다.

## 4. 아직 못 본 것 (정직하게)

- OpenAlex 의 **IEEE 수록 범위**를 수로 확인하지 못했다. 검색 결과가 그 숫자를 안 줬다.
  -> 지을 때 **실제로 질의해 보고 그 수를 적는다.** 추정으로 쓰지 않는다.
- Semantic Scholar API(S2)와 OpenAlex 중 참고문헌 품질이 어느 쪽이 나은지 안 봤다.
  -> 둘 다 붙일 수 있게 문을 갈라 두고, 처음엔 OpenAlex 만 쓴다.
- ResearchGate 는 긁을 수 있는 API 가 없다. 영상은 거기서 CC-BY 논문을 찾았는데,
  우리는 OpenAlex 의 `open_access.oa_url` + 라이선스 칸으로 같은 일을 한다.
- IEEE Xplore 본문은 구독이 있어야 한다. **못 읽는 것은 못 읽는다고 적는다.**
