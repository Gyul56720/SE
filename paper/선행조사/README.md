# 선행조사 -- 짓기 **전에** 쓴다

`paper/<이름>.html` 마다 여기에 `<이름>.md` 가 있어야 한다(G024). 네 마디를 채운다.

```markdown
## 가장 가까운 선행연구
- <제목>, <학회/저널> <연도>, arXiv:XXXX.XXXXX -- 이들이 이미 한 것: …

## 우리가 그것과 다른 점
- …

## 찾아본 질의
- <검색어 1>
- <검색어 2>
- <검색어 3>

## 아직 못 지운 가능성
- <아직 안 본 분야/학회> 쪽에 같은 것이 있을 수 있다
```

마지막 마디가 제일 중요하다. 이 저장소가 다섯 번 진 것은 전부 **"없다고 생각했다"** 에서
났다. 없다고 말하는 대신 **어디를 아직 못 봤는지** 적는다.
