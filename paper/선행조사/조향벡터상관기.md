# 비이상 조향 벡터 상관기 IP -- 선행조사

조사일 2026-09-18. 검색 조각 수준(전문 미확인).

## 검사한 가설

**H**: "범퍼 왜곡(자동차 레이더)이나 구면파(XL-MIMO 근거리장) 때문에 조향 벡터가 이상적
꼴이 아니면 FFT 를 못 쓰고 명시적 상관을 해야 한다. 그 상관기를 HLS 로 짓고
테이블 압축을 재는 것이 우리 IP 다."

## 결과 -- 정면으로 죽었다

### [죽음 1] HLS 로 DoA 추정기를 짓는 것 -- 이미 IEEE 에 있다

**"An Efficient High-level Synthesis Implementation of the MUSIC DoA Algorithm for FPGA"**
IEEE (doc 10508912) `[출처:조각]`
  · HLS 구현, 4안테나 ULA, 1도 해상도
  · **지연 5.0 us**, Virtex FPGA 두 종
  · EVD 는 반복 Jacobi 로
  · "competitive performance in comparison to previous literature, with **high accuracy and
     low resource consumption**"

그리고 혼자가 아니다:
  · "High-level synthesis assisted, low-latency, area- and power-optimized FPGA
     implementation of MUSIC algorithm for DOA estimation" (ScienceDirect)
  · "Towards Low Latency and Resource-Efficient FPGA Implementations of the MUSIC
     Algorithm for DOA Estimation" (IEEE Journals, doc 9445729)
  · "An Efficient FPGA Implementation for **2-D MUSIC** Algorithm"
  · "Hardware Accelerator Design for MUSIC-DOA Estimation with Bilateral Jacobi
     Optimization" (Electronics 15(10):1982, **2026-05**)
  · "High Level Synthesis FPGA Implementation of the **Jacobi Algorithm** to Solve the
     Eigen Problem"
  · "High-level synthesis design of scalable ultrafast ultrasound **beamformer** with
     single FPGA" (arXiv:2208.03429)

-> **"HLS 로 각도 추정 가속기를 짓는다" 는 그 자체로 논문 주제가 못 된다.**

### [죽음 2] OMP 하드웨어 -- 40년치 문헌이 쌓여 있다

근거리장 P-SOMP 의 뼈대가 OMP 인데, OMP 의 FPGA 구현은 포화 상태다. `[출처:조각]`
  · "OMP is the **most widely used** reconstruction algorithm on hardware implementation"
  · IEEE Journals · IET CDS · ScienceDirect · arXiv 에 다수
  · **45 nm CMOS 로 제작**까지: 기존 CS-fusion VLSI 대비 전력 26% 낮고 면적효율 22% 개선
  · 128 길이 신호, M=32, K=5/8 을 **13.2 / 21 us** 에 복원

### [죽음 3] 조향 벡터 테이블 압축 -- 이미 있다

  · 특허 US12422538 "**Efficient direction of arrival estimation using low rank
    approximation**" `[출처:조각]`
  · "Joint Block Low Rank and Sparse Matrix Recovery in Array **Self-Calibration**
    Off-Grid DoA Estimation" (arXiv:1903.07158)
  · "Low Rank Matrix Recovery for Joint Array Self-Calibration and Sparse Model DoA
    Estimation" (arXiv:1712.05890)
  · "A low rank approximation based DOA mechanism... **comparable performance to full DBF**
    with relatively low computational load"

-> 내가 "측정 가능한 질문" 이라 한 테이블 압축이 **이미 연구된 것**이다.

### [부분 생존] XL-MIMO 근거리장 전용 가속기

근거리장 검출/빔트레이닝의 FPGA·VLSI 가속기는 이번에도 못 찾았다. 다만:
  · MUSIC 2-D FPGA 구현이 이미 있고, 근거리장의 (각도 x 거리) 2차원 탐색과 구조가 같다
  · 시스템 프로토타입은 있다 (arXiv:2510.02793, PXIe-7903 FPGA 4개, 256 채널)
  · 알고리즘 쪽은 계층 코드북 · 공간처프(오버헤드 99% 감소) · 희소 DFT · 파수영역 등
    **이미 오버헤드를 크게 줄여 놓았다** -> 가속기의 필요성 자체가 약해진다

## 아직 못 지운 가능성

1. **근거리장 (각도 x 거리) 2차원 상관의 하드웨어**를 정면으로 다룬 논문은 여전히 못 찾았다.
   다만 2-D MUSIC FPGA 가 있으므로 구조적으로 새롭지 않다.
2. **테이블 압축의 '하드웨어 비용 대 정확도' 곡선**을 잰 것은 못 봤다. 저차원 근사 논문들은
   알고리즘 성능만 본 듯하다 -- 그러나 이건 또 '조합의 틈' 이다.
3. 전문을 하나도 못 봤다(전부 차단).

## 판정 -- 그리고 여덟 번째 패턴

**이 IP 로 논문을 쓰자고 권하지 않는다.**

그리고 더 중요한 것: **이번이 여덟 번째다.** 지금까지 찾은 "빈틈" 이 전부 차 있었고,
차 있던 방식이 매번 같다 -- **"알고리즘 X 를 하드웨어로 구현한다" 는 범주 자체가 고갈돼
있다.** 신호처리 + FPGA/VLSI 는 40년간 수천 명이 갈아 온 밭이다.

그러므로 **다음 시도를 아홉 번째로 만들지 말고 범주를 바꿔야 한다.** 남은 길은 셋뿐이다:
  (가) **접근권** -- 나만 잴 수 있는 것 (특정 장비·특정 데이터·특정 현장)
  (나) **진짜 교차** -- 자명하지 않은 분야 결합
  (다) **반증/재현** -- 널리 믿는 것을 정밀하게 재서 뒤집기

세 길 모두 "빈 주제를 찾는" 것이 아니라 **"내가 가진 것에서 출발하는" 것**이다.
