Z2. The Daily and Weekly Loop

A two-member team has an unusual property: one member works when the other does not. That makes the shape of the day the main scheduling decision, and getting it right is worth more than working longer.

Table 501. Four slots, and what each is for

The evening command, and the morning one
# 저녁 -- 밤새 돌린다 (setsid/nohup/disown; 확인은 pgrep)
bash edu/agent/run.sh 12

# 아침 -- 무엇이 있었나
bash edu/agent/status.sh
python3 edu/agent/mutscore.py            # 주 1회면 충분하다

# 밤새 빨간불이 났다면: 최소 사례와 제안된 편집이 원장에 있다
grep '빨간불' edu/agent/ledger/regress.jsonl | tail -5
The failure mode of this loop is that the afternoon slot disappears. It is the only slot with no immediate consequence — skip it and tonight's run still happens, this week's deliverable still moves — so it is the one that gets spent on whatever is urgent. Three weeks later the agent is finding nothing, not because the design is clean but because the oracle stopped growing while the design kept growing. The measurable symptom is a flat mutation score against a rising line count, and it is worth plotting: if the design grew 30 % and the mutant count did not, the suite is covering a smaller fraction of it than it was.

The Friday items are the ones that make a release possible without a release scramble. Both are cheap weekly and expensive in a batch, which is the general shape of everything in this chapter.
Worked example 90. What a night is actually worth
Given. The agent runs 12 hours. Each block's regression takes about 0.02 s of simulation per 600 stimuli, and a full mutation pass over five blocks takes about a minute.
Method. Count what the night can cover, then note what limits it — which is not the machine.
Regression rounds per hour (order)105
Distinct seeds consumed in 12 hours≈106
Mutation passes possible in one nighthundreds
Engineer-hours consumed0
What actually limits the valuethe stimulus distribution and the golden model
Marginal value of the 500th mutation passzero
Marginal value of one new checkerlarge and permanent
How this is got wrong. By measuring the night in rounds. A million rounds of the same distribution explore the same region a thousand times — Part X8's coupon-collector arithmetic says the return flattens far below that. The honest use of the night is variety, not volume: rotate the constraint sets, replay every previous minimal reproducer as a growing regression, and run the mutation pass. A loop that only turns the seed stops learning within the first hour and then keeps the machine warm until morning.

Record the verdict on every escape, permanently. An escape you have judged to be an equivalent mutant will reappear in every run forever, and re-deciding it each week is both wasted time and an invitation to stop reading the list. Keep a file of judged escapes with the reason — ‘extra loop iteration reads an out-of-range bit, which is x, so the branch is never taken’ — and have the report mark them as known. What must not happen is suppressing them silently: a suppressed escape whose reasoning was wrong is a permanent blind spot, and the file is the thing that lets a reviewer, or you in six months, check the reasoning.
Problem. The agent applied a patch overnight and the regression is green. Do you trust it?
Solution. Trust the evidence and check the reason, which are different things. The evidence is strong: the edit passed the original seed, passed a seed never used during the search (the overfitting gate), and passed the self-check confirming the comparison still bites. That rules out the classic automated-repair failure of special-casing the failing input. What it does not establish is that the edit is the change a human would have made. An edit that makes the symptom go away by tightening a condition can be correct on every stimulus the suite has and wrong in a case the suite does not reach — and if the suite reached that case, the bug would have been caught before the patch. So: read the diff, and ask what the original defect was. If you can state the defect in one sentence, keep the patch. If you cannot, the patch is masking something and the right response is to extend the stimulus until the failure is understood. Five minutes per patch, and it is the five minutes that keeps the arrangement honest.
