T7. 위상 고정 루프 — 출력이 시간인 되먹임 시스템

다른 모든 블록은 클럭을 주어진 것으로 다룬다. 이 블록은 그것을 만들고, 마주한 맞바꿈에는 좋은 쪽이 없다. 한 잡음원을 누르는 대역폭이 다른 잡음원을 들인다.

PLL 은 이 책에서 출력이 시간인 유일한 블록이다. 지금까지의 모든 장은 클럭을 지터가 얹힌 입력으로 다뤘다. 여기서는 그 지터를 만들어 내고, 설계 물음은 고리에 정반대로 반응하는 두 원천에서 그것을 어떻게 최대한 적게 만들어 낼 것인가다.

T7.1 고리가 실제로 제어하는 것

유도 — 위상 검출기에서 2 차 시스템까지
이렇게 된다왜냐하면
1위상-주파수 검출기는 기준과 분주된 출력 사이의 위상 오차에 비례하는 신호를 낸다.주파수가 아니라 위상이다 — 주파수는 그 미분이고, PLL 이 위상을 잠그는 부수 효과로 주파수를 잠그는 까닭이며 고리에 본래부터 적분기가 있는 까닭이다.
2전하펌프가 그 오차를 ±ICP 의 전류로 바꿔 오차 펄스가 지속되는 동안 흘린다.평균 전류는 ICP·Δφ/2π 다 — ICP/2π A/rad 의 선형 위상-전류 이득이다.
3필터가 그 전류를 C 에 적분하고, VCO 가 전압을 이득 KVCO 로 위상에 적분한다.고리에 적분기가 둘이다. 맨 축전기만으로는 고리가 무조건 불안정한 까닭이고, 영점(직렬 R)이 선택 사항이 아닌 까닭이다.
4개루프 이득: G(s) = (ICP/2π)·(1/sC)(1+sRC)·(KVCO/s)·(1/N).원점에 극 둘, 1/RC 에 영점 하나. 그 영점이 위상 여유를 댄다.
5닫으면 ωn = √(ICPKVCO/(2πNC)) 과 ζ = (R/2)√(ICPKVCOC/(2πN)) 을 갖는 표준 2 차 시스템이다.이 장의 나머지는 전부 그 두 수를 어디에 둘 것인가에 대한 논의다.
6예로 든 설계(f0 = 2.5 GHz, fref = 25 MHz, N = 100, ICP = 1 µA, KVCO = 5 MHz/V)에서 ζ = 0.9 로 fL = 1 MHz 를 겨누면 C = 41 pF, R = 12.6 kΩ 이다.1 % 까지 정착하는 데 대략 4/(ζωn) = 1.27 µs 걸린다 — 시스템 아키텍트가 실제로 묻는 수가 그것이다.
불쾌함이 들어오는 자리가 분주기다. 고리 안의 모든 잡음원 — 기준, PFD, 전하펌프, 분주기 — 이 출력에서 전력으로 N² 배가 되고, N = 100 이면 40 dB 다. 100 배를 곱하는 PLL 의 대역 안 위상 잡음 바닥이 출발점이었던 수정보다 훨씬 나쁜 까닭이고, 아주 낮은 지터가 필요한 설계가 편한 기준이 아니라 가능한 한 높은 기준 주파수(더 작은 N)를 쓰는 까닭이다.

T7.2 좋은 쪽이 없는 맞바꿈: 루프 대역폭

고리가 누르는 잡음과 통과시키는 잡음

고리는 자기 안의 모든 것(기준, PFD, 전하펌프, 분주기)에 대해 저역통과이고, VCO 에 대해서는 고역통과다. 루프 대역폭 안에서는 되먹임이 출력을 기준에 따라가게 만들므로 VCO 자신의 잡음이 고쳐진다. 그 밖에서는 고리가 너무 느려서 아무것도 못 고치고 VCO 가 자유롭게 돈다.

그래서 고리를 넓히면 VCO 잡음을 더 누르고 기준 경로 잡음을 더 들인다. 좁히면 반대다. 늘 최적이 있고, 고리 안에서 최적이 있는 설계 변수는 그것뿐이다.

어디에 쓰나모든 클럭 발생기, 모든 SerDes 송수신 PLL, 데이터 변환기의 클럭, 그리고 지터 예산을 맞춰야 하는 SoC 의 칩 내부 클럭.
언제 쓰나일찍 고정한다. 루프 대역폭이 VCO 규격과 기준 선택을 묶으므로, 나중에 바꾸면 둘 다 바뀐다.
어떻게 쓰나모양 지운 밀도를 적분하고 쓸어 본다. 최적은 보통 대역 안 바닥과 VCO 의 자유 발진 잡음이 만나는 자리이고, 그것은 적분 없이 위상 잡음 그림에서 바로 읽을 수 있다.
실제 코드는 이렇게 생겼다
# Phase noise measurement, and the integration that turns it into jitter.
# The instrument gives L(f) in dBc/Hz; the number the customer wants is rms jitter.
#   sigma_t = sqrt( 2 * integral( 10^(L(f)/10) df ) ) / (2*pi*f0)
# THE INTEGRATION LIMITS ARE PART OF THE SPECIFICATION.
#   PCIe: 10 kHz - 20 MHz (with the protocol's own filter applied)
#   JESD204B: 100 Hz - 20 MHz
#   Ethernet: often 12 kHz - 20 MHz
# A jitter number quoted without its limits is not comparable to any other one.
여기서 틀린다. 'DC' 부터 적분하는 것은 뜻이 없다 — VCO 의 1/f3 영역 적분은 발산하고, 그래서 모든 규격이 아래쪽 한계를 정해 둔다. 서로 다른 한계로 '서브 피코초 지터' 를 말하는 두 업체는 견줄 수 있는 주장을 하고 있는 것이 아니고, 좁은 한계 쪽이 대개 나쁜 부품이다.

T7.3 스퍼: 잡음이 아닌 오차

기준스퍼 (reference spur) — 기준 주파수(와 그 고조파)만큼 떨어진 자리에 나타나는 이산 톤. 비교율로 제어 전압을 주기적으로 교란하는 무엇이든 그 원인이 된다 — 전하펌프의 up/down 불일치, 필터 축전기의 누설, 또는 기준에서 VCO 로의 결합.
표 96. 스퍼가 어디서 오나, 그리고 무엇이 실제로 없애나
원인기구듣는 해법안 듣는 해법
CP 전류 불일치올림 전류와 내림 전류가 달라서 고리가 0 이 아닌 위상 오차에 앉아야 하고, 그래서 펌프가 주기마다 동작한다Iup 을 Idn 에 맞추는 복제 바이어스ICP 를 낮추는 것 — 스퍼와 고리 이득이 같이 비례한다
필터 누설축전기와 스위치의 누설이 갱신 사이에 제어 마디를 비운다필터 마디에 두꺼운 산화막 소자. 더 큰 C고리 이득을 더 주는 것 — 교란이 입력 쪽에 있다
전원 / 기판 결합기준 에지가 VCO 로 곧바로 결합한다물리적 분리, VCO 전용 레귤레이터, 차동 튜닝고리 안의 무엇이든 — 고리는 이 경로를 아예 못 본다
분수분주 양자화분주기가 정수 사이를 오가므로 위상 오차가 구조적으로 주기적이다그것을 모양 지우는 ΔΣ 변조, 그리고 충분한 고리 필터링더 느린 기준
분수분주 (fractional-N) 와 그것이 일부러 만드는 잡음

정수 N 고리는 기준의 배수만 낼 수 있다. 평균 N.f 로 나누는 것 — N 과 N+1 사이를 오가는 것 — 은 어떤 주파수든 내지만, 그 값으로 분수의 되풀이율에 몰린 스펙트럼을 갖는 주기적 위상 오차를 낸다. ΔΣ 변조기가 그 수열을 무작위화하고 모양 지워서 오차를 고주파 잡음으로 만들고, 루프 필터가 그것을 깎는다.

맞바꿈이 분명하다. 분수분주는 주파수 해상도를 사고 그 값을 루프 대역폭 밖의 잡음으로 치르는데, 그 영역이 바로 넓은 고리가 거르지 못하는 영역이다. 분수분주 설계가 정수분주보다 좁은 고리를 쓰는 경향이 있는 까닭이고, 그러면 다시 VCO 자신의 잡음이 더 중요해진다 — 이 장의 중심 맞바꿈이 되풀이해 나타난다.

어디에 쓰나가진 수정의 배수가 아닌 주파수가 필요한 모든 시스템: 무선 LO, 기준 하나에서 여러 라인 속도를 내는 SerDes, 오디오 클럭, 확산 스펙트럼 클럭킹.
언제 쓰나필요한 출력 주파수 격자가 기준보다 촘촘할 때. 시스템 구조상 수정을 고를 수 있다면 언제나 정수분주를 택하라 — 늘 더 조용하다.
어떻게 쓰나변조기 차수를 고르고(2–3 차가 보통), 유리수 분수 자리의 유휴 톤을 확인하고, 모양 지운 잡음이 루프 대역폭에서 충분히 밖에 있어 필터의 내리막이 그것을 잡았는지 검증한다.
실제 코드는 이렇게 생겼다
// Behavioural PLL for system simulation -- real-valued, event driven.
// It models what the DIGITAL side needs (frequency, lock time, jitter injection)
// and nothing else. Replacing this with a transistor model in an SoC simulation is
// how a regression that used to take 10 minutes starts taking a week.
module pll_behav #(parameter real FREF=25.0e6, parameter int N=100,
                   parameter real LOCK_US=2.0, parameter real JIT_RMS=0.8e-12)
                  (input logic ref_clk, rst_n, output logic out_clk, output logic locked);
    real period = 1.0/(FREF*N);
    initial begin out_clk = 0; locked = 0; end
    always #(1s*period/2) out_clk = ~out_clk;             // ideal edges
    initial begin @(posedge rst_n); #(LOCK_US*1us); locked = 1; end
endmodule
// SDC: the output is a GENERATED clock -- declaring it as a second create_clock
// makes STA treat the two domains as unrelated and silently stops checking paths.
// create_generated_clock -name pll_out -source [get_ports ref_clk] \
//     -multiply_by 100 [get_pins u_pll/out_clk]
여기서 틀린다. PLL 출력을 create_clock 으로 선언하고 create_generated_clock 으로 선언하지 않는 것은 흔하고 비싼 SDC 잘못이다. 그러면 도구가 기준과 출력 사이의 위상 관계를 모르게 되어 둘 사이의 모든 건넘을 비동기로 다루고, 보고서는 여전히 깨끗해 보이는 채로 당신이 신경 쓰는 경로를 보고하기를 그만둔다.

T7.4 실제로 무엇이 깨지나

표 97. 고리 방정식에는 안 나타나는 실패들
실패증상근본 원인무엇이 찾아내나
전원 푸싱출력 주파수가 VDD 를 따라 움직인다. 지터가 디지털 활동과 상관을 갖는다KVCO,supply 가 0 이 아니다 — VCO 가 의도한 것보다 여러 뜻에서 전압 제어 발진기다시뮬레이션에서 전원을 쓸어 df/dV 를 재고, PDN 의 리플(T13)에 견주어 예산 잡는다
VCO 끌림가까이 있는 센 신호의 오프셋 자리에 스퍼가 뜬다다른 발진기나 고출력 단에서 기판이나 전원을 통해 주입 동기가 걸린다두 톤 벤치 측정. 플로어플랜 검토
거짓 락고조파나 엉뚱한 에지에 잠긴다. 리셋하면 가끔 된다주파수 능력이 없는 위상 검출기, 또는 불법 상태에서 출발하는 분주기코너와 초기 조건에 걸친 시동 쓸기 — 공칭 한 번이 아니다
락 검출이 거짓말한다고리가 정착하기 전에 '락' 이 뜬다검출기가 규격이 요구하는 것보다 넓은 창 안에서 위상을 견준다검출기의 창을 실제 정착 시간과 견준다. 시스템이 둘 다 기다리게 만든다
실제로 난 일
디지털이 무거운 SoC 를 기습하는 것이 전원 푸싱이다. 전원 민감도가 1 %/V 인 VCO 가 활동에 따라 30 mV 리플이 있는 레일 위에 앉아 있으면, 디지털 부하가 스위칭하는 그 속도로 주파수가 변조된다 — 그 속도는 상수가 아니고, 고객이 돌리는 바로 그 워크로드와 상관을 갖는다. 실험실에서는 '소프트웨어에 따라 달라지는 지터' 로 나타난다. 해법은 VCO 전용 레귤레이터이고, 그것은 플로어플랜과 전원 개수를 바꾸므로 처음부터 설계에 넣어야 한다.

T7.5 월요일에 무엇을 할 것인가

표 98. 이 장의 개념이 실제로 쓰이는 자리
개념쓰이는 블록무엇을 정하나
고리이득 · 감쇠비 · 루프대역폭루프 필터 설계C 와 R, 따라서 정착 시간과 면적
위상잡음 · 적분지터VCO 규격을 정하기 전의 지터 예산VCO 잡음과 대역 안 바닥 중 어느 쪽에 써야 하나
기준스퍼스펙트럼 규제 준수와 수신기 감도 저하전하펌프 위상과 필터 마디의 누설 예산
분수분주 · 델타시그마변조주파수 계획수정을 골라서 분수분주를 아예 피할 수 있는가
전원푸싱플로어플랜과 PDNVCO 에 전용 레귤레이터가 필요한가 — 되돌리기 어려운 결정이다

들고 갈 수: 예로 든 이 설계의 루프 필터는 C = 41 pF, R = 12.6 kΩ 이고 정착은 1.27 µs 다. 지터 최적은 루프 대역폭 2 MHz 에 앉고 충분히 얕아서 대역폭은 차라리 정착과 스퍼 요구로 골라야 한다. 그리고 분주기는 대역 안의 모든 잡음원에 40 dB 를 곱한다 — 시스템이 댈 수 있는 가장 높은 기준 주파수를 쓰라는 가장 강한 논거다.

다음 장은 이 클럭을 일하게 한다. 직렬 링크에서, 같은 지터를 이미 눈을 거의 닫아 놓은 채널에 견주어 예산 잡아야 한다.

특허로 가는 길 — 이 주제에서 발명이 일어나는 자리
PLL 특허는 고리 방정식에 관한 것이 거의 아니다 — 그것은 1930 년대 제어 이론이다. 특허는 고리가 무엇을 보게 허락할 것인가 에 관한 것이다: 양자화 잡음이 중요한 대역에서 밀려나도록 모양 지운 분수 분주기. up/down 불일치를 트리밍이 아니라 복제로 상쇄하는 전하펌프. 아날로그 필터를 누산기로 갈음해서 공정을 따라 줄어드는 디지털 고리. 그리고 분주기를 변조해 복사 에너지를 규제 주파수에서 옮기는 확산 스펙트럼 방식. 전부 바뀌지 않은 고리 둘레의 배치다.
