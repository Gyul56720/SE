T12. 정합 — 똑같은 소자 둘은 똑같지 않다

칩 위에서 정확한 것은 비 하나뿐이고, 그것조차 분포다. 정밀한 것은 전부 그 폭을 아는 데 얹혀 있다.

똑같이 그려 나란히 같은 방향으로 놓은 트랜지스터 둘도 서로 다르다. 도핑 원자는 낱낱이고 아무렇게나 떨어진다. 게이트 가장자리는 완벽하게 곧지 않다. 산화막 두께는 원자 하나씩 달라진다. 그래서 생기는 변수의 차는 확률변수이고, 정밀 아날로그 설계는 그 표준편차를 알고 그 꼬리를 예산에 넣는 규율이다.

T12.1 펠그롬 법칙, 그리고 왜 제곱근인가

펠그롬 법칙 (Pelgrom's law)

나란히 놓여 똑같이 그려진 두 소자에 대해, 변수 차의 표준편차는 면적의 제곱근으로 줄어든다. σ(ΔVth) = AVT/√(W·L) 이고 AVT 의 단위는 mV·µm 이다 — 파운드리가 재서 내놓는 공정별 상수다(몇 mV·µm 이고, 마디마다 천천히 좋아진다).

제곱근은 경험적으로 곡선을 맞춘 것이 아니다. 불일치는 서로 독립인 미시 사건(도핑 자리, 가장자리 거칠기)을 세는 통계에서 오고, 독립 사건 N 개를 센 것의 상대 요동은 1/√N 로 줄어든다. 면적이 그 셈이다.

어디에 쓰나설계 안의 모든 전류 거울, 차동쌍, 비교기, 커패시터 어레이, SRAM 셀. 수율 모형에서도 쓴다 — Vmin(T4) 이 그 꼬리인 분포가 이것이다.
언제 쓰나정밀한 것을 그리기 전에. 요구되는 σ 가 최소 면적을 정하고, 최소 면적이 종종 블록 전체의 크기와 그 기생 용량을, 따라서 속도를 정한다.
어떻게 쓰나규격에서 거꾸로 풀어라. 3σ 에서 오프셋 5 mV 가 허용되면 σ(ΔVth) ≤ 1.67 mV 이므로 W·L ≥ (AVT/1.67 mV)² 다. AVT = 5 mV·µm 이면 8.96 µm² 이고 — 소자 하나당이다.
실제 코드는 이렇게 생겼다
* Mismatch in a PDK is a MODEL PARAMETER, not something you add by hand.
* The foundry supplies statistical models; you enable them and run Monte Carlo:
.lib 'models/pdk.lib' mc              $ NOT the 'tt' corner -- the statistical deck
.mc 200 op                            $ 200 samples
.measure op ios param='abs(i(vd2)-i(vd1))'
* AND THEN: the corners and the mismatch are DIFFERENT analyses.
*   corner  = global shift  (all devices move together)
*   mismatch = local spread (devices move independently)
* Running 'tt + mismatch' and calling it worst case misses the combination that
* actually fails: slow corner AND an unlucky pair.
여기서 틀린다. AVT 는 나란히 놓인 두 소자 사이의 차에 적용된다. 그것을 소자 하나의 절댓값에 쓰거나 다이의 반대편에 있는 소자들에 쓰는 것은 양쪽으로 다 틀렸다. 절대 퍼짐은 더 크고(전역 공정 변동이 들어 있다), 다이를 가로지르는 소자 사이의 상관은 아예 다른 모형이다.

T12.3 아무렇게나가 아닌 불일치

계통 불일치 (systematic mismatch) — 어느 다이에서나 똑같은 차이. 웨이퍼를 가로지르는 산화막 두께의 기울기, 가까운 전력 소자에서 오는 온도 기울기, 패키지나 이웃한 웰에서 오는 응력, 또는 그저 쌍의 양쪽이 다른 이웃에 둘러싸인 것. 표본을 여럿 모아도 평균으로 지워지지 않으므로, 몬테카를로를 아무리 돌려도 못 찾는다.

공통 중심 배치 (common-centroid layout) 와 더미

맞춰야 하는 쌍의 소자를 저마다 조각으로 쪼개 서로 엮어서, 두 소자가 같은 질량 중심을 갖게 한다. A B B A 이거나, 2차원 기울기라면 바둑판이다. 그러면 선형 기울기가 두 쪽에 똑같이 걸려 1차까지 지워진다.

더미 소자는 다른 문제를 푼다. 맨 바깥의 진짜 소자는 안쪽 것들과 이웃이 달라서 식각과 응력이 다르다. 더미는 모든 진짜 소자에 똑같은 둘레를 주는데, 전기적으로는 아무 일도 안 하는 면적이 그 값이다.

어디에 쓰나중요한 모든 정합 쌍. 차동쌍, 전류 거울 어레이, 변환기의 커패시터 어레이(T6), 밴드갭 BJT 어레이(T11).
언제 쓰나레이아웃에서. 그리고 그것은 설계자가 지정해야 한다 — 레이아웃 기술자는 넷리스트만 보고 어느 소자가 맞아야 하는지 미루어 낼 수 없다.
어떻게 쓰나회로도에 정합 묶음을 표시하고, 더미를 붙인 공통 중심을 요구하고, 방향을 똑같이 두고(면적 아끼자고 소자를 거울로 뒤집지 마라), 두 쪽을 대칭으로 배선하고, 쌍을 패키지 응력이 가장 큰 자리 — 보통 다이 모서리 — 에서 떼어 놓는다.
실제 코드는 이렇게 생겼다
// The instruction that must reach the layout engineer. A netlist
// does not carry it, so it goes in the constraint file AND the schematic.
//   match_group  : M1 M2      common_centroid = ABBA, dummies = 2 each side
//   orientation  : identical (NO mirroring -- STI stress is not symmetric)
//   routing      : symmetric; equal parasitic on both gates
//   keep_out     : > 50 um from the die seal ring and from any power device
// Verified by an LVS-with-matching check, not by inspection:
//   assert centroid(M1) == centroid(M2) within 0.5 um
여기서 틀린다. 공통 중심은 선형 기울기를 지운다. 2차 기울기 — 가까운 열원이 낳는 것이 그것이다 — 는 안 지워지고, 엮어 놓으면 소자를 곡률 위로 더 넓게 펴서 되레 나빠질 수도 있다. 열 기울기에는 답이 엮기가 아니라 거리와 등온선에 대한 방향이다.
실제로 난 일
SRAM 의 Vmin(T4) 이 설계점 문제가 아니라 수율 문제인 까닭도 불일치다. 천만 개(10 의 7 제곱)짜리 셀 어레이는 가장 나쁜 셀이 돌아야 하는데, 그것이 대략 −5.5σ 사건이다. 표본 천 개짜리 보통 몬테카를로는 그 꼬리를 아예 못 본다 — 108 정도의 표본이 들 것이다. 그래서 양산 흐름은 중요도 표본이나 해석적 꼬리 방법을 쓰고, 메모리를 두고 '몬테카를로 통과, 표본 1000개' 라고 하는 보고서는 자기가 받은 물음에 답하지 않은 것이다.

가지고 갈 잰 결과. 전류 거울 불일치는 면적의 제곱근으로 줄고 — 면적을 네 번 두 배로 하는 동안 14.16 % → 7.17 % → 3.61 % → 1.81 % 다 — 전류의 제곱근으로도 준다. 1 µA 에서 22.1 % 이고 100 µA 에서 2.29 % 다. 두 손잡이 다 값이 제곱이고, 그 사실 하나가 보정이 있는 까닭이다.

다음 장은 소자를 떠나 그것들 전부를 먹이는 회로망 — 전원 공급 회로망 — 을 다룬다. 거기서 '그것은 분포다' 라는 같은 논증이 임피던스와 시간에 관한 물음으로 다시 나타난다.

특허로 가는 길 — 이 주제에서 발명이 일어나는 자리
정합 자체는 특허가 안 된다 — 통계이니까 — 그런데 면적 없이 정확도를 사는 모든 방식은 된다. 동적 소자 정합, 초퍼와 자동 영점 오프셋 상쇄, 디지털 전경·배경 보정, 그리고 기울기를 지우는 레이아웃 기법. 무늬가 또 보인다. σ 가 1/√면적 으로밖에 안 줄므로 면적으로 정확도를 4배 사면 실리콘이 16배 든다 — 그래서 정밀 아날로그에서 상업적으로 재미있는 생각은 거의 전부 그 값을 안 치르는 대안이다.
