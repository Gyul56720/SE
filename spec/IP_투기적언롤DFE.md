# 픽스: `dfe_spec` -- 투기적 언롤 결정귀환등화기 IP

확정일 2026-09-18. **이 문서가 결정이다.** 바꾸려면 여기를 고친다.

## 0. 한 줄

> 56 GBd(112G PAM4)에서 **직접형 DFE 는 되먹임 고리가 안 닫혀 만들 수 없다.**
> 투기적 언롤 + 부분속도로 닫고, 그 대가(슬라이서 2^N / 3·4^N)를 **재서 곡선으로 낸다.**

## 1. 왜 이것인가 -- 통과 조건 다섯

| 기준 | 판정 | 근거 (실측) |
|---|---|---|
| 병목이 숫자로 있나 | O | `afe.dfe1탭예산(56e9)` -> 고리 31.0 ps vs 1 UI 17.86 ps, **여유 -13.14 ps** |
| 알고리즘이 검증된 것인가 | O | 투기적(언롤) DFE. 교과서이자 상용 SerDes 표준 구조 |
| 성능 주장을 방어해야 하나 | **없음** | 언롤은 직접형과 **수학적 항등**(유리수 60/60 일치). BER 을 안 바꾼다 |
| 잴 도구가 있나 | O | yosys 0.33 · nextpnr-ice40 0.6 · verilator 5.020 · iverilog · sky130 -- **전부 설치됨** |
| 자본이 드나 | **₩0** | 아래 4절 |

**"주장이 없는 것"이 이 IP 의 강점이다.** 이 저장소가 다섯 번 앓은 병(유리한 구석에서
나온 표제 숫자)이 구조적으로 못 생긴다 -- 성능을 안 바꾸므로 유리한 구석이 없다.
바뀌는 것은 **타이밍과 면적뿐**이고 둘 다 기계가 낸다.

## 2. IP 계약

```
이름        dfe_spec
변조        NRZ | PAM4 (pam.py 레벨·그레이 그대로)
손잡이      N  언롤 깊이        1 | 2 | 3
            P  부분속도비       1 | 2 | 4        (P-way 병렬)
            T  잔여 직접형 탭   0 .. 7
            W  계수 워드폭      6 .. 10 비트
입력        P-way 표본 (XW 비트), 계수 로드 포트
출력        P-way 판정 (NRZ 1비트 / PAM4 2비트 그레이)
내부        [투기] 2^N (NRZ) / 4^N (PAM4) 갈래를 미리 다 계산  <- 이것이 '표'다
            [먹스] 지난 판정으로 갈래를 고른다                  <- 고리에 남는 것
            [직접] 잔여 T 탭은 직접형 (P UI 의 여유를 쓴다)
```

**LUT 를 옆에 붙이는 것이 아니다. 되먹임 고리 자체를 표로 바꾸는 것이다.**

### 스펙에 못 박아야 비트일치가 나오는 것 둘 (실측으로 나왔다)

```
S1. 되먹임 레지스터 초기값을 직접형과 같게 못 박는다
    -- 안 맞추면 불일치 수열 103/200 (NRZ) · 162/200 (PAM4)
S2. 고정소수점 합산 순서와 반올림 자리를 못 박는다
    -- S1 만 맞추면 10/200 · 17/200 이 남는다. 무한정밀(유리수)에서는 0/60
       => 남은 불일치는 '합산 순서' 다. 고정소수점에서는 설계로 없애야 한다
```

## 3. 무엇과 어떻게 결합하나

```
  pam.py ──(레벨·그레이·심볼/비트오류 분리)──┐
  serdes.py ─(채널·CTLE·FFE·CDR·잡음·BER)──┤
  afe.py ───(1 UI 예산 · 트랜지스터 대응)───┤
                                            ▼
                                   specdfe.py  [새로 짬]
                                   고정소수점 골든
                                            │  비트 단위로 같아야 한다
                                            ▼
                              eqrtl.spec_dfe()  [새로 짬]  ──> Verilog
                                            │
              ┌─────────────────────────────┼──────────────────────┐
              ▼                             ▼                      ▼
      iverilog / verilator           yosys + nextpnr-ice40   yosys + asic.py
      비트일치 (S1·S2)                LC · Fmax               sky130 표준셀 면적
              └──────────── sweep_spec.py [새로 짬] ─────────────────┘
                                            │
                          (N, P, T, W) -> (닫히나, LC, Fmax, um^2, BER)
```

**기존 것을 고치지 않는다.** `eqrtl.dfe()`(직접형, 80줄)는 **비교 기준선으로 그대로 둔다** --
투기형이 그것과 비트까지 같아야 하므로 정답을 아는 검사가 공짜로 생긴다.

**FPGA 보드: 사지 마라 (₩1,000,000 아낀다).**

- 56 GBd DFE 는 **어느 FPGA 에서도 안 돈다.** 그 속도는 트랜시버 하드매크로 영역이다
- LC · Fmax 는 `nextpnr` 가 **보드 없이** 낸다
- ASIC 면적은 sky130 LEF 가 낸다. 112G SerDes 는 어차피 ASIC 이다
- BER 은 `serdes.py` 가 낸다
- 보드로 얻는 것: **수십 MHz 저속 데모 한 개.** 잃는 것: ₩1,000,000 + 브링업 시간

**수업이 "실물 동작"을 요구하면 그때만** iCE40 계열 저가 보드를 산다 -- 이 저장소가 이미
iCE40 HX8K 를 목표로 하고 있어 흐름이 그대로 얹힌다. 십만 원대다(**가격 확인 필요**).

**MATLAB: 필요 없다.** 골든이 이미 Python 이고 닫힌 꼴 `BER = Q(10^(SNR/20))` 으로
**교정까지** 돼 있다(`tests/test_serdes.py`). 수업이 MATLAB 을 요구하면 그때 산다.

## 6. 낼 숫자와 **무효화 조건** (G023)

| 낼 것 | 어떻게 | 무효화 |
|---|---|---|
| 고리 닫힘 여유 ps | `afe.언롤예산(N,P)` | afe.py 기본값(래치12·합산8·배선6·준비5)은 **모형이지 실리콘이 아니다.** 값이 바뀌면 결론이 바뀐다 -- 감도를 같이 낸다 |
| BER vs SNR | `serdes.py`, 제 판정 되먹임, 학습구간 제외 | 직접형과 **같아야** 한다. 다르면 버그다(항등이므로) |
| LC · Fmax | yosys + nextpnr-ice40 | FPGA 는 전부 LUT 다. **이 수로 "표가 싸다"고 말하지 않는다** |
| ASIC 면적 um^2 | yosys + `asic.py` + sky130 LEF | Liberty 없이 일반 게이트 매핑이다 -- 진짜 합성 면적의 근사 |
| **뒤집히는 지점** | N 쓸기 | **PAM4 N=3 이면 슬라이서 192개.** 면적이 이기는 지점을 찾아 표시한다 |

### 예상 (모형, 실측 아님)

```
구조                          고리지연   @56GBd 쓸시간   닫히나   최대보드율
직접형 (지금 eqrtl.dfe)        31.0 ps      17.86 ps      X      32.3 GBd
1탭 언롤 (먹스 3ps)            26.0 ps      17.86 ps      X      38.5 GBd
1탭 언롤 + 반속도(P=2)         26.0 ps      35.71 ps      O      76.9 GBd
1탭 언롤 + 1/4속도(P=4)        26.0 ps      71.43 ps      O     153.8 GBd

래치+배선+준비만 23 ps > 17.86 ps  ->  **언롤만으로는 56 GBd 에 절대 못 닿는다.**
                                       부분속도가 함께 있어야 한다.

언롤 비용   N=1: NRZ 2 / PAM4 12     N=2: 4 / 48     N=3: 8 / 192     N=4: 16 / 768
```

## 7. 순서 -- 이 순서를 지킨다

```
0. paper/선행조사/투기적언롤DFE.md 를 쓰고 **사용자에게 보인다**   <- 짓기 전에 (G024)
1. specdfe.py  고정소수점 골든 + 직접형과의 항등 검사 (S1·S2)
2. eqrtl.spec_dfe()  Verilog 생성
3. 비트일치: iverilog/verilator 로 골든과 한 값씩 맞춘다          <- 여기 전엔 면적을 안 본다
4. yosys + nextpnr  ->  LC · Fmax
5. asic.py + sky130 ->  um^2
6. sweep_spec.py    ->  (N,P,T,W) 쓸기 전체 표. 뒤집히는 지점 표시
7. paper/측정.jsonl 에 무효화 조건과 함께 넣고 나서 원고
```

**3번 전에는 면적을 보고하지 않는다.** 틀린 회로가 제일 작다.

## 8. 아직 안 정해진 것 (설계를 막지 않는다)

- **마감** -- 모르면 단계별로 끊어 낸다. 1~3 단계만으로도 보여줄 것이 있다
- **목적** (수업/포트폴리오 vs 논문) -- 7단계에서만 갈린다. 6단계까지 같다
- **보드 필요 여부** -- 필요 없다는 것이 기본값. 요구되면 십만 원대로 얹는다

## 9. 폐기한 것 -- 다시 꺼내지 않는다

| 갈래 | 왜 |
|---|---|
| 조향 벡터 상관기 / HLS DoA | IEEE 10508912 (HLS MUSIC, 5.0 us) 등에 정면으로 있음 |
| MMSE 검출기 IP | **저장소에 0줄.** SerDes 는 4,842줄. 버릴 이유가 없었다 |
| 혼합정밀 반복정제 | isotropic 에서만 24비트. rho=0.3 에서 이미 깨짐(23.9비트) |
| "LUT 를 넣는다" 자체를 주제로 | `attic/폐기논문/` 에 두 번. ReducedLUT(FPGA'25)가 이미 함 |
