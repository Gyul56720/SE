# 개발할 수 있는 IP -- 전부 (2026-09-18)

**연구가 아니라 개발이다.** 신규성은 안 본다. 기준은 넷:

    완결  여기 환경에서 끝까지 가나 (골든 -> RTL -> 비트일치 -> PPA)
    취업  고속 I/O · 메모리 · 검증 직무에 어필하나
    자산  이미 있는 코드가 있나
    크기  얼마나 걸리나

**환경 제약(실측):** HLS 없음 · 상용 EDA 없음 · fab 없음 · Liberty 없어 STA 불가 ·
sky130 FO4 = 48 ps (최대 1 GHz 급) · 보드 없음(선택 ~10만원대)

# 권고 -- 흩어진 블록 더미보다 **하나의 서브시스템**이 강하다

    채널 --> [AFE(SPICE)] --> ADC --> FFE --> DFE(투기적 언롤) --> 슬라이서 --> PCS --> 링크
                                       ^            ^                          |
                                    LMS 적응     CDR 디지털 루프                 |
                                       |            |                          |
                                    PRBS/아이모니터 (진단)  <---- CSR(APB) ------+

**면접에서 "이 칩의 이 부분을 처음부터 끝까지 안다" 가 된다.** 블록 하나씩은
누구나 만들지만 **사슬 전체를 이은 것은 드물다.**

## 단계

    1단계  A4 PRBS + 아이 모니터        작고 확실. **그림이 나온다**. 채널·BER 자산 그대로
    2단계  A1 RX DSP 등화기 (FFE+DFE+LMS)  주력. specdfe.py 골든이 이미 있다
    3단계  A2 CDR 디지털 루프            지터 전달함수까지
    4단계  G1 CSR 생성기 + A3 PCS        "IP 답게" 만드는 껍데기
    곁들임 A7 의 AFE 조각을 sky130 SPICE 로  -> 속도 한계를 실측으로 보인다
    보관   C1 LDPC 는 두 번째 항목으로 남긴다 (이미 완성도가 높다)

## 안 하는 것과 이유

  · **HLS 로 만드는 IP** -- 도구가 없고 깔 수도 없다(GitHub 403 · apt 없음 · PyPI 없음)
  · **아날로그 레이아웃/추출** -- 도구도 fab 도 없다. SPICE 스키매틱까지만
  · **타이밍 사인오프** -- Liberty 가 없어 STA 가 안 된다. Fmax 는 nextpnr(FPGA)로만
  · **"PHY IP 개발했다" 라는 표현** -- 실리콘도 아날로그도 없다. 면접 한 질문에 무너진다
