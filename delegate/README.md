# delegate -- 위임·병렬. 요약이 아니라 **대조된 인용**을 받는다

```
물음 + 범위(글롭) ──쪼개기──> 파일 묶음 N개 ──동시에──> 탐색기(싼 모델, router 경유)
                                                          │ [{파일, 인용, 왜}]
                                             코드가 대조 ──┤ 인용이 원문에 있나?
                                          채택(줄·해시 붙임) │ 퇴짜(지어낸 것)
                                                          v
                                        router 원장에 채택표시 -> 4단계 심판의 재료
```

## 왜 이 꼴인가

Claude Code 는 넓은 탐색을 싼 서브에이전트에 던지고 결론만 받는다. 그것을 그대로 옮기면
이 저장소에서는 위험하다 -- **요약은 지어낼 수 있고, 지어낸 요약은 화면에서 진짜와 똑같이
생겼다.** brain·verify 가 온 자리가 정확히 그것이다. 그래서 받는 것을 바꿨다: 탐색기는
인용만 내고, 인용은 코드가 파일과 대조한다. 대조를 못 지나면 버리고 퇴짜로 센다.

| | |
|---|---|
| 탐색기가 내는 것 | `[{"파일", "인용"(글자 그대로), "왜"}]` -- 요약 금지 |
| 코드가 하는 것 | 인용이 그 파일에 실재하는가(공백만 다른 것은 봐준다). 있으면 줄 번호·해시 |
| 원장에 남는 것 | 호출마다 `router/ledger.jsonl` + 채택 여부 -- 싼 모델이 값을 하는가를 `router/check.py` 가 잰다 |

병렬은 묶음 단위다. 쿼터·분당 간격·모델 전환은 `orchestrator/llm_pool` 이 진다 --
여기서 한 줄도 다시 짜지 않았다. 묶음 수가 동시 호출 수의 상한이다(기본 4).

## 쓰기

```bash
python3 delegate/run.py --범위 'graph/*.py' --물음 '해시를 어디서 대조하나'
python3 delegate/run.py --범위 'graph/*.py' --범위 'router/*.py' --쪼개기만   # 호출 0회
python3 tests/test_delegate.py
```

디스코드: `!위임 graph/*.py router/*.py :: 해시를 어디서 대조하나` (관리 채널만).
에이전트: `delegate(question, scope)` 도구 -- 프롬프트가 "파일 여럿을 살펴야 하면 네가
cat 하지 말고 delegate 로 던져라" 고 시킨다.

## 안 읽는 것

`.git` · `.env` · `node_modules` · `venv` · `__pycache__` · `sandbox/out` · 이진 파일.
파일 하나는 앞 12,000자까지만 -- 잘렸으면 프롬프트에 잘렸다고 적는다(없는 것과 안 보여 준
것은 다르다).
