# 검증 시나리오 — 항공기 외부 결함 검사 드론 (물리·수학 근거)

**무엇인가.** 우리 제어 정책(3축 PI-SSM)이 **실제 검사 임무의 광학 규격을 만족하는가**를
물리로 따지는 검증. 임의값이 아니라 아래 식으로 짓고, 규격 4개를 PASS/FAIL 로 판정한다.
돌리기: `python3 ctrl/model/inspect3d.py` · 검사: `ctrl/검사.py` · HTML: `ctrl/viz.py`.

## 왜 이 주제에 물리·수학이 들어가나
무인체계 제어 정책은 **응용수학+물리학 그 자체**다 — 동역학(뉴턴), 제어이론(상태공간·안정성),
광학·기하, 수치. 이 시나리오는 그 중 넷을 실제로 계산한다.

## 1. 항공기 (물리 대상)
Boeing 737-800 실측: 길이 39.5 m, 동체 지름 3.76 m(반경 1.88 m). 상부 동체 ±70° 를 검사 영역으로.

## 2. 카메라 광학 (검출의 물리 근거)
```
GSD  = (화소피치 · 거리) / 초점거리 ,   화소피치 = 센서폭 / 화소수
스와스 = 2·거리·tan(FOV/2) = 거리 · 센서폭/초점
최소검출 = K · GSD          (신뢰검출 K=3 화소)
```
카메라: 초점 8 mm · 센서 6.4 mm · 4000 px → 화소피치 1.6 µm.
표준거리 1.5 m 에서 **GSD 0.3 mm · 최소검출 0.9 mm · 스와스 1.2 m.**
**핵심**: GSD 는 카메라~결함 **실제 거리**로 정한다 — 멀수록 커져 작은 결함을 놓친다.
그래서 각 결함의 검출은 그 지점 거리의 GSD 로 판정한다(상수 문턱이 아니다).

## 3. 드론 동역학 (플랜트의 물리)
**캐스케이드 제어.** 실드론은 내부 자세·속도 루프가 빠르다(수백 Hz). 그래서 외부 유도
루프가 보는 플랜트는 `속도지령 → 위치`(단일적분기)다 — 이것이 단일적분기 PI-SSM 을 쓰는
물리적 정당화다. 속도는 v_max = 2 m/s 로 포화(모터·안전 한계).
제어: `h_t = h_{t-1} + e·dt`(상태=오차 적분), `u = Kp·e + Ki·h`(속도 지령).

## 4. 검증 규격 (판정)
| 규격 | 근거 | 결과 |
|---|---|---|
| 표준거리 밴드 [0.8, 2.5] m | d_min=충돌 안전여유, d_max=GSD 상한 | PASS (실측 1.34~2.25) |
| 속도 ≤ v_max 2 m/s | 모터·안전 한계 | PASS (2.0) |
| 결함 전부 검출 | 크기 ≥ 3·GSD(그 지점 거리) | PASS (4/4) |
| 커버리지 ≥ 90% | 패스수 × 스와스 / 대상 둘레 | PASS (100%) |

결함(실제 유형·크기): 균열 2mm · 우박눌림 20mm · 부식 40mm · 리벳풀림 5mm — 전부
표준거리 GSD(0.9mm 최소검출) 위라 검출됨.

## 정직 기록
처음 돌렸을 때 **검증 FAIL** 이었다 — 검출 판정을 3D 거리 대 스와스로 비교하는 기하 오류
(드론은 표준거리만큼 떨어져 있어 3D 거리가 늘 ≥ 표준거리)와, 표면거리 모델이 동체만
맞는데 경로가 날개까지 간 것. 물리를 바로잡아(GSD 를 카메라~결함 실제 거리로, 경로를
동체 ±70° serpentine 으로) PASS 가 됐다. **임의로 통과시키지 않았다.**

## 이 검증이 정책과 잇는 자리
드론을 나는 것이 우리 제어 정책이고, 그 정책의 상태갱신 `h=Ā·h+B̄·o` 는 하드웨어
`ssm/scan_mac` 이 처리한다. 이 시나리오는 **정책이 실제 물리 규격을 만족함**을 보인다.
결함 표식의 근접검출은 데모(실제 비전 모델 아님)임을 명시한다.
