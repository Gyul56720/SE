# 무인체계 제어 정책 — 설계 워크스페이스 (레시피북)

**무엇인가.** 여기는 코드 디렉터리가 아니라 **자연어로 도는 설계 워크스페이스**다.
당신(사용자)은 봇에게 한국어로 말하고, 봇은 **이미 있는 도구들을 엮어** 실제로
설계·측정·검증한다. 당신이 Python 을 짜지 않는다. 봇은 이 문서를 읽어 "무슨 말이
어느 도구로 가는지"를 안다.

**주제.** 갈래 B(Mamba/SSM 선형 어텐션), 서사 ⓑ **무인체계 제어 정책**
(LocoMamba/VLA-Mamba). 코어는 `ssm/` 의 selective-scan 유닛. LIG AI-HW co-design 포트폴리오.

**규율(이 저장소).** *검사하지 않은 초록불이 검사한 빨간불보다 나쁘다.* 짓기 전에 조사하고,
자원부터 재고, 수를 말하기 전에 네 가지(재려던 걸 쟀나·동작점 성한가·독립대조·사소한설명
죽이기)를 지킨다. 과장하지 않는다 — `ctrl/과장방지.md`.

---

## 1. 자연어 → 도구 (레시피)

당신이 이렇게 말하면 ↔ 봇은 이렇게 한다. **봇은 이 표를 근거로 도구를 고른다.**

| 당신의 말 (예) | 봇이 하는 일 | 쓰는 도구 |
|---|---|---|
| "선행조사 해줘 / 남이 한 게 있나" | 검색 → `paper/선행조사/<이름>.md` 로 남기고 요약 | `research/` · WebSearch · survey |
| "블록도 그려줘 / 그림으로 보여줘" | 회로도·데이터패스 그림 생성 | `circuitdraw.py` · Artifact(교안 페이지) |
| "N=16 으로 합성해서 자원 재줘" | scan 유닛을 그 파라미터로 합성, LUT/DSP/BRAM 보고 | `ssm/검사_scan.sh` · `synth.py` · yosys |
| "순차 vs 병렬 파레토 그려줘" | N 을 쓸며 (DSP, LUT, 사이클) 재서 곡선·표 | `ssm/검사_scan.sh` + Artifact 차트 |
| "골든이랑 맞나 검사해줘" | 골든 대조 + 변이 검사(거짓초록 사냥) | `ssm/검사*.sh` · `ssm/model/*` |
| "다섯 직무로 완제품까지 돌려줘" | RTL·DV·SYN·DFT·PD 흐름 | `house/run.py` · `house/designs.py` |
| "end-to-end 오차 재줘" | exp_unit+scan 붙여 실제 시퀀스로 오차 | `ssm/model/*` + 골든 |
| "설명해줘 / 교안으로" | 다이어그램+비유로 설명 페이지 | Artifact(HTML 교안) |
| "이 결정 남겨줘 / 왜 골랐지" | 결정 원장에 근거와 함께 기록·조회 | `ctrl/결정.jsonl` (아래 §3) |
| "포트폴리오 문장으로 정리해줘" | 측정을 방산 서사로 — **과장 게이트 통과분만** | `ctrl/과장방지.md` |

**봇에게(중요).** 위에 없는 말이 와도 이 정신으로 매핑하라: **재는 것은 도구가**,
**짓는 것은 flow 가**, **그림·설명은 Artifact 가**, **근거는 원장이** 맡는다. 값을
지어내지 말고 실제로 돌린 출력을 붙여라.

## 2. 설계 흐름 (한 바퀴)

```
조사(paper/선행조사) → 설계(ctrl/설계.md, 블록도)
   → 자원측정(ssm/검사*.sh: exp·scan) → 결정 기록(ctrl/결정.jsonl)
   → 완제품(house 5직무) → 정리(과장방지 통과분만 포트폴리오로)
```
이미 끝난 것: 선행조사(`paper/선행조사/mamba-ssm-가속기.md`), selective-scan 유닛
측정(`ssm/측정메모.md` — exp=순수LUT, MAC=DSP 6N, 순차 DSP=2). 다음: 제어 래퍼(§ 설계.md).

## 3. 결정 원장 (B) — `ctrl/결정.jsonl`

설계 결정마다 **왜 그렇게 골랐는지 측정 근거와 함께** 한 줄씩 남긴다. 나중에 포트폴리오·
논문으로 그대로 뽑힌다. 한 줄 = 한 JSON:

```json
{"날짜":"2026-09-25","결정":"exp 근사 K=64","근거":"측정: 32 LUT·DSP0·최대오차0.06(ssm/측정메모.md)","무효화":"오차 0.06 이 end-to-end 에서 누적되면 재검토","대안":"K=8(오차0.39)·K=128(58 LUT)"}
```

- `봇에게`: 사용자가 "이 결정 남겨" 라고 하면 위 꼴로 `ctrl/결정.jsonl` 에 **append** 하라.
  `근거` 는 반드시 **측정 파일·수**를 가리키게(주장 아니라 실측). `무효화`(이 결정이
  깨지는 조건)를 비우지 마라 — 못 적으면 그것은 결정이 아니라 광고다(CLAUDE.md).
- 읽기: `python3 ctrl/원장읽기.py` (사람이 보기 좋게 표로). 쓰기는 자연어로 봇이 한다.

## 4. 과장 방지 (D) — `ctrl/과장방지.md`

측정을 방산 서사("결정론적 지연으로 무인체계 제어")로 바꿀 때, 근거 없는 표현을 막는
체크리스트. 봇은 포트폴리오 문장을 내기 전에 그 문서를 적용한다.
