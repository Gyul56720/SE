# LX세미콘(LG계열) — Design Verification 전문가

## JD 핵심 요구사항

- UVM(Universal Verification Methodology)을 활용한 Digital IP 설계 검증
- SystemVerilog을 활용한 Assertion based Verification / Coverage Based Verification
- Display Driver IC / Gate Driver IC / VR/TCON 제품군에 대한 설계 검증
- Real Number Modeling을 통한 AMS 검증
- SystemVerilog 및 UVM 사용 경험자
- C 또는 Python 언어 활용 우수자
- eDP, MIPI_DSI Protocol 업무 경험자

## 매칭되는 포트폴리오 근거

- (직접 대응되는 근거 없음)

## 갭 (채워야 할 것)

- UVM(Universal Verification Methodology)을 활용한 Digital IP 설계 검증 경험 없음
- SystemVerilog 및 Assertion based Verification / Coverage Based Verification 경험 없음
- Display Driver IC / Gate Driver IC / VR/TCON 제품군에 대한 설계 검증 경험 없음
- Real Number Modeling을 통한 AMS 검증 경험 없음
- eDP, MIPI_DSI Protocol 업무 경험자 우대사항 충족 안 됨

## 종합 판단

지원자의 rtl-lab 프로젝트는 Icarus Verilog와 자체 제작 테스트벤치를 사용한 기초적인 RTL 검증을 다루고 있으나, JD에서 요구하는 UVM, SystemVerilog, 상용 검증 방법론(Assertion/Coverage), 그리고 특정 제품군(DDI, TCON 등) 검증 경험이 전무합니다. 포트폴리오의 주요 역량은 MATLAB 기반 신호처리 및 안테나 설계, 그리고 캡스톤 디자인에 집중되어 있어 Design Verification 전문가 직무와의 직접적인 접점이 부족합니다. 따라서 현재 포트폴리오 상태로는 해당 직무 지원 적합도가 매우 낮습니다.
