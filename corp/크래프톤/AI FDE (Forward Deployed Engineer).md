# 크래프톤 — AI FDE (Forward Deployed Engineer)

## JD 핵심 요구사항

- 크래프톤 내 각 사업조직(비즈니스/크리에이티브 등)에 직접 배치되어 AI Native 방식의 실무 업무자동화 프로젝트 기획 및 실행
- LLM API(OpenAI, Anthropic Claude 등)를 활용한 업무 자동화 솔루션 설계·개발·배포
- 코딩 에이전트(Cursor, Claude Code 등)를 활용한 빠른 프로토타이핑 및 구현
- 현업 조직과의 워크플로우 발굴 협업

## 매칭되는 포트폴리오 근거

### 코딩 에이전트(Cursor, Claude Code 등)를 활용한 빠른 프로토타이핑 및 구현
- 근거 프로젝트: career-intelligence 파이프라인
- 왜 맞는가: Claude Code를 오케스트레이터로 사용하여 파이프라인을 구축하고 프로토타이핑을 수행한 경험이 있음.

### LLM API(OpenAI, Anthropic Claude 등)를 활용한 업무 자동화 솔루션 설계·개발·배포
- 근거 프로젝트: career-intelligence 파이프라인
- 왜 맞는가: Gemini API 및 다양한 Python 모듈을 연동하여 정보 수집부터 구조화 리포트 생성까지의 파이프라인을 설계하고 엔드투엔드 운영함.

## 갭 (채워야 할 것)

- 크래프톤 내 각 사업조직에 배치되어 현업 조직과 워크플로우를 발굴하고 협업한 경험
- OpenAI, Anthropic Claude 등의 LLM API를 활용한 실제 업무 자동화 솔루션 개발·배포 경험
- 프로덕션 규모의 시스템 운영 및 팀 협업 경험

## 종합 판단

지원자의 포트폴리오 중 'career-intelligence 파이프라인' 프로젝트는 Claude Code와 LLM API를 활용한 프로토타이핑 및 파이프라인 구축 역량을 보여주어 일부 JD 요구사항과 일치합니다. 그러나 대다수의 포트폴리오가 하드웨어 설계, RTL 검증, 펌웨어 등 반도체 및 임베디드 도메인에 집중되어 있으며, 현업 조직과의 협업이나 프로덕션 규모의 자동화 솔루션 배포 경험은 부족합니다. 따라서 코딩 에이전트 활용 역량은 돋보이나 사업조직 협업 및 실무 자동화 측면의 갭을 보완해야 합니다.
