# 02. RLHF와 RLAIF: 인간·AI 피드백 기반 자가 개선 루프

## 1. 왜 알아야 하는가

SFT(지도 미세 조정)만으로는 인간의 복잡하고 주관적인 선호도(안전성, 유용성, 뉘앙스)를 완벽히 정렬하기 어렵습니다. 왜냐하면 인간의 질적 평가 기준을 미분 가능한 형태의 전통적인 손실 함수로 사전에 공식화하는 것이 수학적으로 불가능하기 때문입니다. RLHF와 RLAIF는 이러한 정렬 한계를 극복하고 모델이 선호도 데이터를 기반으로 지속해서 성능을 극대화하도록 자가 개선 루프를 설계하는 핵심 기술로, 현대의 프로덕션 수준 LLM 구축과 정렬 엔지니어링 면접에서 가장 중요하게 다뤄지는 개념입니다.

## 2. 정의와 구조

### 1. 지도 미세 조정(SFT)의 한계와 정렬의 필요성\nSFT는 고품질의 모범 답안 데이터를 모방하여 모델을 학습시킵니다. 그러나 이 방식은 모델이 자신이 생성한 답변 중 어떤 부분이 더 좋고 나쁜지에 대한 상대적 가치를 인지하지 못하게 만듭니다. 또한 분포 외(Out-of-Distribution) 쿼리가 입력되었을 때 그럴듯한 거짓말(Hallucination)을 하는 경향이 있습니다. 이를 정렬(Alignment)하기 위해 인간 또는 AI의 선호도 피드백을 보상 값으로 변환하여 모델을 강화학습시키는 프레임워크가 고안되었습니다.\n\n### 2. RLHF(Reinforcement Learning from Human Feedback)의 동작 원리\nRLHF는 크게 3단계로 진행됩니다.\n1) **SFT(Supervised Fine-Tuning)**: 기초 모델을 고품질 지시어 데이터셋으로 사전 학습시킵니다.\n2) **리워드 모델(Reward Model, RM) 학습**: 한 프롬프트에 대해 SFT 모델이 생성한 여러 답변($y_1, y_2$) 중 인간이 선호하는 것($y_w \succ y_l$)을 선택하게 하여 비교 데이터셋을 만듭니다. 이를 브래들리-테리(Bradley-Terry) 모델을 기반으로 모델링하여 리워드 네트워크를 학습시킵니다. 손실 함수는 다음과 같습니다:\n$$\mathcal{L}_{\text{RM}} = -\mathbb{E}_{(x, y_w, y_l)} [\log \sigma(r(x, y_w) - r(x, y_l))]$$\n3) **강화학습(PPO 등)을 통한 정책 최적화**: 고정된 리워드 모델을 환경(Environment)으로 삼아, 정책 네트워크인 언어 모델($\pi_\theta$)의 파라미터를 Proximal Policy Optimization(PPO) 알고리즘으로 업데이트합니다. 이때 기존 SFT 모델($\pi_{\text{SFT}}$)로부터 지나치게 멀어지는 것을 방지하기 위해 KL 발산(Kullback-Leibler Divergence) 페널티를 보상 함수에 추가합니다.\n\n### 3. RLAIF(Reinforcement Learning from AI Feedback)로의 확장\n인간 피드백 수집은 비용이 많이 들고 속도가 느리며 확장성(Scalability)이 떨어지는 치명적인 한계가 있습니다. RLAIF는 인간 평가원 대신 거대 언어 모델(LLM)에 구체적인 가이드라인(헌법, Constitution)과 체인 오브 소트(CoT) 프롬프트를 제공하여 선호도 데이터를 생성하게 합니다. 이로써 매우 빠른 주기와 저렴한 비용으로 정렬 성능을 개선하는 자가 자가 학습 루프(Self-Learning Loop)를 형성할 수 있습니다.

## 3. 핵심 사실 (Killing Fact)

$$ \boxed{\ \mathcal{L}_{\text{RL}}(\theta) = \mathbb{E}_{(x, y) \sim \pi_\theta} [r(x, y)] - \beta \mathbb{D}_{\text{KL}}(\pi_\theta(y|x) \parallel \pi_{\text{SFT}}(y|x))\ } $$

이 수식은 RLHF/RLAIF 최적화의 본질을 보여줍니다. 모델이 높은 보상($r(x,y)$)을 얻도록 최적화하면서도, 기존 학습 데이터의 분포 정보인 $\pi_{\text{SFT}}$로부터 이탈하는 것을 막기 위해 KL 발산 규제($\mathbb{D}_{\text{KL}}$)를 가합니다. 이 규제가 없으면 모델은 보상 모델의 맹점을 악용하는 '보상 해킹(Reward Hacking)'에 빠져 무의미하고 기괴한 텍스트를 생성하게 됩니다.

## 4. 핵심 기법

### 기법 A: 브래들리-테리(Bradley-Terry) 기반 페어와이즈 모델링

하나의 프롬프트 $x$에 대해 두 개의 모델 출력 $y_w$와 $y_l$을 쌍으로 묶어 비교하며, $y_w$가 $y_l$보다 선호될 확률을 시그모이드 함수를 사용해 두 출력의 보상 값 차이 $r(x, y_w) - r(x, y_l)$로 계산하여 리워드 모델을 지도 학습시킵니다.

**왜 이렇게 설계했는가:** 인간이나 AI 에이전트는 특정 출력물의 품질을 절대적인 수치(예: 85점)로 일관되게 평가하기 어렵지만, 두 가지 선택지를 제시했을 때 상대적으로 우수한 것을 고르는 작업(A가 B보다 낫다)은 매우 높은 일관성과 신뢰도를 보여주기 때문입니다.

### 기법 B: KL 발산(KL-Divergence) 페널티 주입

PPO 알고리즘의 보상 계산 단계에서, 새로 학습 중인 정책 모델 $\pi_\theta$가 생성한 토큰의 확률 분포와 초기 SFT 모델 $\pi_{\text{SFT}}$의 확률 분포 사이의 차이를 구하여 이를 감점 요소로 리워드 함수에 누적 적용합니다.

**왜 이렇게 설계했는가:** 강화학습 에이전트는 보상 시스템의 미세한 구멍(예: 특정 무의미한 단어나 미사여구를 남발하면 점수가 비정상적으로 높아지는 현상)을 찾아내어 악용하는 성향이 강하므로, 기존 언어 모델의 정상적인 언어 분포 밖으로 탈주하지 못하게 강제 결박해야 하기 때문입니다.

### 기법 C: 헌법적 AI(Constitutional AI) 기반 정렬

AI에게 비판(Critique)과 수정(Revision)을 유도하는 다단계 행동 강령(Constitution) 규칙을 프롬프트 형태로 제공하여, 유해하거나 편향된 답변을 스스로 검증하고 정제된 형태의 피드백 데이터를 대량으로 생성하도록 유도합니다.

**왜 이렇게 설계했는가:** 사전에 정의된 명확한 원칙(Constitution)을 주입함으로써 인간의 주관적 평가 편향을 제어하고 일관된 정렬 데이터를 고속으로 대량 복제할 수 있기 때문입니다.

### 기법 D: DPO(Direct Preference Optimization)

별도의 리워드 모델을 별도로 생성하거나 PPO와 같은 복잡한 액터-크리틱 강화학습 루프를 거치지 않고, 정책 모델의 출력 확률 분포 자체를 수학적으로 치환하여 인간 선호도 데이터로부터 정책 모델을 직접 미세 조정합니다.

**왜 이렇게 설계했는가:** PPO는 메모리 점유율이 극도로 높고 하이퍼파라미터 튜닝이 매우 민감하여 학습이 쉽게 불안정해지는 고질적인 문제가 있으므로, 이 과정을 단순한 이진 교차 엔트로피 손실 함수 최적화로 간소화하여 연산 효율과 학습 안정성을 비약적으로 높이기 위함입니다.

## 5. 자주 하는 오해 / 주의할 점

가장 흔하게 저지르는 실수는 리워드 모델의 점수(Reward Score)가 계속 우상향하는 것만을 보고 강화학습이 완벽히 성공했다고 확신하는 것입니다. 리워드 모델은 단지 가상의 대리인(Proxy)일 뿐이므로, 실제 인간의 언어 정서와 합치하지 않는 '보상 해킹'이 일어나면 리워드 점수는 최고점을 찍는데 모델은 정작 의미 불명의 앵무새 같은 문장을 내뱉게 됩니다. 또한, AI 피드백(RLAIF)을 구성할 때 모델이 '먼저 제시된 답변을 선호하는 경향(Position Bias)'이나 '길고 상세한 답변을 무조건 훌륭하다고 판단하는 경향(Verbosity Bias)'을 사전에 정화해주지 않으면 오정렬된 데이터로 인해 전체 자가 학습 루프가 왜곡되는 심각한 결과를 초래합니다.

## 6. 대표예제 (추론 연습)

### 예제 1

귀사는 자체 LLM을 RLHF 기법으로 정렬하고 있습니다. 학습 과정에서 리워드 점수는 안정적으로 상승하지만, 정성 평가 결과 생성된 문장들이 극도로 정형화되며 'AI 언어 모델로서 저는...'과 같은 고도로 방어적이고 중복된 사과 표현을 모든 질문에 남발하는 부작용이 발견되었습니다. 이 문제의 원인을 진단하고 수정 단계를 제시하십시오.

**풀이:**

1단계 — 문제 진단: 리워드 모델(RM) 학습 데이터셋 내에 '공손하고 정중한 어조의 안전 답변'이 지나치게 높은 선호 점수를 부여받도록 구성되어 있었으며, PPO 학습 시 KL 발산 계수 $\beta$가 충분히 크지 않아 정책 모델이 다양성을 버리고 안전 템플릿 답변만을 골라 출력하는 '보상 해킹(Reward Hacking)'에 수렴한 상태입니다.\n2단계 — 리워드 모델 조정: 유용성(Helpfulness)과 무해성(Harmlessness) 사이의 균형을 맞출 수 있도록 학습 쌍을 수정합니다. 단순히 무해하기만 하고 아무 정보도 주지 않는 답변(예: 거절 답변)에는 패널티 점수를 부과하도록 RM을 다시 학습시킵니다.\n3단계 — 하이퍼파라미터 튜닝: RL 학습 파이프라인에서 KL 발산 페널티의 가중치인 $\beta$값을 상향 조정하여, 정책 모델이 초기 SFT 모델이 가졌던 상식적이고 다양한 답변 분포 범위 내에 강제로 머무르도록 제한합니다.

**답: 보상 해킹을 극복하기 위해 KL 발산 페널티 계수 $\beta$를 높여 기존 SFT 분포 이탈을 막고, 리워드 모델이 단순 거절 및 방어적 표현에 과도하게 높은 보상을 주지 못하도록 RM 데이터셋의 선호 가중치를 전면 재조정해야 합니다.**

### 예제 2

RLAIF 파이프라인을 구축하여 Llama 3 모델을 정렬하고자 합니다. 이를 평가할 상위 AI 평가기(Evaluator)로 GPT-4를 활용했으나, 분석 결과 GPT-4가 답변의 알맹이와 관계없이 단순하게 텍스트의 길이가 더 긴 답변에 지속해서 높은 점수를 부여하는 'Verbosity Bias'가 발생하고 있음이 확인되었습니다. 이 편향을 체계적으로 극복하는 프롬프팅 및 전처리 전략을 설계하십시오.

**풀이:**

1단계 — 프롬프트 엔지니어링 제약 추가: 평가용 프롬프트에 '답변의 길이에 휘둘리지 말 것. 불필요하게 서론과 결론을 반복하거나 말을 늘린 답변에 감점을 주고, 핵심 요구사항을 빠르고 정확히 명시한 답변에 가산점을 부여하라'는 구체적인 정성 평가 헌법 원칙(Constitution)을 추가합니다.\n2단계 — 대칭 평가 및 통제: 평가하려는 두 답변 쌍의 순서를 변경하여 각각 평가한 후 통합 점수를 얻는 방식(Position-swap Cross Evaluation)을 채택하고, 답변의 토큰 수 차이가 일정 수준(예: 30% 이상) 발생할 경우 정규화 점수 필터를 거쳐 길이 요인을 보정하도록 파이프라인을 구축합니다.\n3단계 — 데이터 정제 및 후처리: GPT-4가 선호 데이터셋을 형성할 때, 두 텍스트의 길이를 인위적으로 비슷한 범위로 요약 가공하여 제공한 뒤 본질적인 논리와 정보 일치도만으로 선호도를 가려내게 합니다.

**답: 프롬프트 상에 길이 편향 금지 헌법적 가이드라인을 강제 부여하고, 두 답변의 물리적 토큰 차이를 정형화하거나 길이에 대한 가중 감점 모델을 피드백 산출 공식에 삽입하여 AI 평가기의 다변 편향을 구조적으로 차단합니다.**

## 7. 유제 (면접 예상 질문)

1. DPO(Direct Preference Optimization) 모델은 기존 PPO 기반 강화학습에 비해 어떤 수학적, 아키텍처적 변형을 통해 리워드 모델의 명시적 탑재 없이 정렬을 완수할 수 있는 것인가요? *(힌트: SFT 정답 분포에 대한 상대적인 로그 우도 비율(Log Likelihood Ratio)을 변형하여, 리워드 값 자체를 정책 파라미터 함수식으로 치환해 대입하는 수학적 전개 방식을 고민해 보세요.)*
2. RLAIF 시스템을 구동할 때 발생할 수 있는 '자기 강화 편향(Self-Enhancement Bias, 예: 자기 패밀리군 모델의 답변을 더 선호하는 현상)'은 정렬 루프의 객관성을 해칩니다. 이를 계측하고 정량화할 수 있는 실험 설계 방안은 무엇인가요? *(힌트: 서로 다른 베이스 아키텍처를 지닌 다수의 모델이 작성한 답변 쌍을 동일하게 섞어 블라인드 테스트 방식으로 AI 평가기에 투입한 뒤, 각 에이전트 소속 브랜드별 채택 비율의 오차 행렬을 도출해 봅니다.)*
3. PPO 기반 학습 과정 중 Actor 네트워크와 Critic 네트워크의 업데이트 주기와 학습 속도(Learning Rate) 불균형이 초래하는 '정책 붕괴(Policy Collapse)'를 감지하기 위해 실시간 대시보드에서 추적해야 하는 핵심 지표 두 가지는 무엇인가요? *(힌트: 액터의 변화량을 측정하는 평균 KL 발산 추이 수치와, 크리틱의 예측 정확도를 의미하는 Value Loss의 수렴 여부를 주목하십시오.)*

## 8. 다음 챕터와의 연결
