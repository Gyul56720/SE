# MEAL: Stable and Active Learning for Few-Shot Prompting (2022)

> 앙상블과 능동 학습을 통해 퓨샷 프롬프팅의 변동성을 극복하고 안정적인 성능 향상을 이끈 MEAL 프레임워크

## 개요 (Overview)
본 논문은 퓨샷 프롬프팅의 높은 변동성 문제를 해결하기 위해 다중 프롬프트 파인튜닝 및 예측 앙상블과 프롬프트 기반 학습에 맞춤화된 능동 학습(Active Learning) 기준을 결합한 MEAL 방법론을 제안합니다. 이를 통해 모델 실행 간 편차를 줄이고, 효율적인 데이터 선택을 통해 퓨샷 분류 성능의 안정성과 정확도를 대폭 향상시킵니다.

**문제 정의(선행 연구 대비 확장점):** 기존의 단순 무작위 데이터 선택 및 단일 프롬프트 파인튜닝 방식에서, 프롬프트 기반 학습에 특화된 능동 학습 데이터 선택 기준과 다중 프롬프트 예측 앙상블 기법으로 확장하였습니다.

## 주요 특징 (Features)
- 2.3 points
- 5개

## 결과/성과 (Results/Performance)
초록 내에 직접적인 한계점이 언급되어 있지 않으나, 다중 프롬프트 학습 및 예측 앙상블을 수행하는 과정에서 가중되는 계산 비용과 능동 학습을 위한 추가적인 데이터 선택 과정의 오버헤드가 한계가 될 수 있습니다.
