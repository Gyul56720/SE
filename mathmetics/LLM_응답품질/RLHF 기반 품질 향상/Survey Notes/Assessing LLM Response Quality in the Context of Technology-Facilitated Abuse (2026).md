# Assessing LLM Response Quality in the Context of Technology-Facilitated Abuse (2026)

> 기술 매개 학대(TFA) 대응을 위한 LLM 답변의 효과성을 전문가와 생존자 관점에서 최초로 평가하고 개선 방향을 제시한 연구

## 개요 (Overview)
본 논문은 기술 매개 학대(TFA) 맥락에서 범용 및 도메인 특화 LLM 4종의 답변 품질을 최초로 전문가 직접 평가와 생존자 대상 사용자 연구를 통해 다각적으로 검증했습니다. 이를 통해 안전 중심 프롬프트를 적용한 제로샷 단일 회기 답변의 실질적인 유용성을 분석하고 향후 생존자 지원용 모델 개발을 위한 구체적인 지침을 제공합니다.

**문제 정의(선행 연구 대비 확장점):** 기존의 기술 클리닉 지원 및 단순 온라인 정보 탐색 방식의 한계를 넘어, 실제 문헌 및 포럼 기반 질문 데이터셋과 안전 중심 프롬프트를 설계하여 범용 비추론 모델 및 IPV 특화 모델의 성능을 전문가-사용자 연계 다면 평가 프레임워크로 확장하여 분석했습니다.

## 주요 특징 (Features)
- 4개의 대형언어모델(LLM)
- 2개의 범용 비추론 모델
- 2개의 IPV 도메인 특화 모델

## 결과/성과 (Results/Performance)
본 연구는 제로샷 단일 회기(zero-shot single-turn) 답변 평가에 국한되어 있어, 실제 생존자들이 겪을 수 있는 복잡한 다중 턴 대화 시나리오에서의 LLM 한계를 완전히 대변하지 못할 수 있습니다.
