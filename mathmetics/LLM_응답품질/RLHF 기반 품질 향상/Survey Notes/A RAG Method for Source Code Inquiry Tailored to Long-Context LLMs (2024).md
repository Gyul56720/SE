# A RAG Method for Source Code Inquiry Tailored to Long-Context LLMs (2024)

> 실행 흐름을 RAG에 통합하여 개발자 질의에 대한 LLM의 코드 분석 답변 품질을 개선하는 방법론

## 개요 (Overview)
본 논문은 소스 코드 질의 성능을 높이기 위해 프로그램의 실행 흐름(execution traces)을 검색 증강 생성(RAG) 기술에 통합하는 방법을 제안합니다. 이를 통해 컨텍스트 길이 제한 문제를 완화하고 소프트웨어 개발 환경에서 LLM의 응답 품질을 향상시키고자 합니다.

**문제 정의(선행 연구 대비 확장점):** 소스 코드 분석을 위한 기존의 표준 RAG 프레임워크에 프로그램의 동적 실행 흐름(execution traces) 데이터를 연동하는 형태로 확장함.
