# cut -- 절단평면 판정기 (VNE 논문의 최소 시작점)

**기능 하나가 결정 하나다.** 발견기는 여기 없다 -- 부등식이 어디서 왔든 묻지 않고 판정만 한다.

| 결정 | 무엇을 묻나 | 값 |
|---|---|---|
| `유효판정` | `max{a·z : z ∈ X_VNE} ≤ b` (MIP, 최적까지) | 유효 / **무효** / 못잼 |
| `자름판정` | `max{a·z : z ∈ P_LP} > b` (LP 한 번) | 자름 / 안자름 / 못잼 |
| `분리판정` | `a·z* > b` (산수) | 분리함 / 못함 / 못잼 |
| `조임판정` | LP 경계가 올랐나 | 조임 / 안조임 / 못잼 |
| `채택판정` | 넷을 차례로 | ACCEPT / **REJECT** |

**기본은 전부 '아니오'다.** 못 재면 못잼이고 못잼은 통과가 아니다.

## 왜 이 자리의 거짓 초록이 유난히 비싼가

유효하지 않은 cut 을 유효라 부르면 solver 가 **터지지 않는다.** 크래시도 infeasible 도
아니고 **조용히 다른 최적해**를 낸다. 아무도 모르고, 그 위의 모든 수가 근거처럼 보인다.

## 연산자 연산자 (증명을 붙일 수 있는 것만)

| 연산자 | 부등식 | 증명 근거 | CG-1 폐포(기초 행) |
|---|---|---|---|
| `노드덮개` | `Σ_{v∈T}Σ_{u∈S} x ≤ |T|−1` | CPU 제약 | **폐포안** 30/30 |
| `링크덮개` | `Σ_{e∈T}(y_uw+y_wu) ≤ |T|−1` | 대역 제약 | 폐포안 22/26 · 폐포밖 4 |
| `최소홉` | `−Σ_arc y[e] ≤ −1` | 일대일 + 배치 + 흐름보존 | **폐포밖 11/11** — 아래 참고 |
| `노드고정` | `x[r,u] ≤ 0` (d_r > cap(u)) | CPU 제약 | 폐포안 21/21 |
| `링크고정` | `y[e,(u,w)]+y[e,(w,u)] ≤ 0` | 대역 제약 | 폐포안 13/13 |
| `짝배제` | `x[r,u]+x[s,u] ≤ 1` | 일대일 — **대조군**(전부 안자름이어야 한다) | 폐포안 40/40 |
| `분리유도` | 노드덮개와 같은 꼴, LP 로 T·S 를 고른다 | (노드덮개와 동일) | 폐포안 19/19 |

**일곱에서 멈췄다.** 연산자 하나하나에 "모든 인스턴스에서 성립한다" 는 논증이 붙어야
family 로 올릴 수 있다. 수보다 증명이 먼저다.

**CG-1 폐포**(`cut/증명.py:cg폐포판정`)는 f_i 가 기초 행 넷(배치·일대일·CPU·대역, 그리고
흐름보존)의 rank-1 선형결합인지를 LP 탐색 + 유리수 재검증으로 **산수 확정**한 결과다
(5씨앗). 여섯은 정말로 그 결합이다 — "다른 연산자에 함의된다"(독립판정, 아래 참고)는
느슨한 경험적 관찰이 아니라, 기초 행만으로 만든 확정이다.

**최소홉만 다르다 — 이유가 있다.** x 를 바탕 노드에 고르게 쪼개면(예: 6노드에 1/6씩)
배치 등식은 그대로 서고 흐름보존 우변이 0 이 돼 **y=0 이 그대로 LP 가능해다**(실측:
등식 잔차 0.0 · 부등식 만족 · Σy(e)=0.0). 최소홉의 결론(Σy≥1)을 이 점이 정면으로 어긴다
— 즉 **LP 완화 위에서 이 부등식은 애초에 안 선다.** 정수해에서만 성립하고, 그 성립 근거는
"일대일+배치가 강제하는 서로 다른 자리"라는 **정수성 논증**이지 선형결합이 아니다.
그래서 다른 여섯과 종류가 다른 **유일한** 후보다(rank-1 CG 로는 원리상 표현이 안 된다 —
반복 CG는 안 쟀다).

## 후보를 어떻게 만드나

| 연산자 | 어떻게 | 비고 |
|---|---|---|
| 여섯 손수 연산자 | T·S 를 **전수 열거** | 증명이 붙어 있다 |
| `분리유도` | **LP 해의 쪼개진 자리**에서 짓는다 | 적게 훑고 같은 수를 찾는다 |

`분리유도` 가 v3 의 **모델 없는 꼴**이다 — *fractional solution → feature extraction →
candidate → verifier*. 여기서 feature 는 쪼개진 받침(fractional support)이고, 뽑는 데
회귀도 LLM 도 안 쓴다. **유효성 증명은 그대로다** — 덮개 부등식의 증명은 T·S 를 어떻게
골랐는지에 안 기댄다.

## 일반화 (`cut/일반화.py`) — 안 본 인스턴스에서 잰다

```bash
python3 -c "
from vne import topo as T; from cut import 일반화 as G
짓기 = lambda s: (T.바탕망(씨앗=s, 노드수=6, 꼴='random', p=0.7, cpu범위=(4,6)),
                T.요청망(씨앗=100+s, 노드범위=(3,4), cpu범위=(3,6), 대역범위=(1,5)))
print(G.보고(G.검증('최소홉', range(0,6), range(6,12), 짓기)))"
```

연산자의 **유효성**은 이미 모든 인스턴스에 대해 증명돼 있다 — 물을 것이 없다. 무는 것은
**자르나 · 조이나** 이고 그것은 인스턴스마다 다르다.

```
지켜짐   검증군에서도 생산적이다
무너짐   발견군에서만 생산적이었다 -> **그 인스턴스군의 성질이었다**
못잼     후보가 안 나왔거나 표본이 모자라다
```

실측 (씨앗 0–5 발견 / 6–11 검증):

```
최소홉     지켜짐   발견 1.0   -> 검증 1.0    (Δ 3.25 -> 2.78)
분리유도   무너짐   발견 0.125 -> 검증 0.0
짝배제     못잼     추측조차 못 세움 (대조군)
```

**분리유도가 무너진 것이 이 장치의 값이다.** 발견군에서만 재면 "전수열거보다 낫다" 가
나오는데, 그 발견군이 바로 고르는 데 쓴 인스턴스다.

## 증서 (`cut/증서.py`)

판정을 JSON 으로 내보내고 **판정기가 그것을 다시 읽어 독립으로 재판정한다.**

```bash
python3 -c "from cut import 증서 as C; print(C.다시판정모두())"
```

세 값이다 — `맞다` / `어긋난다`(증서가 거짓) / `못잼`(바탕이 바뀌어 더 못 견준다).

**바탕은 불변이다.** `cut/ff.py` 와 `vne/topo.py` 의 지문이 증서마다 박힌다. 주석 한 줄만
바뀌어도 지문이 달라지고, 그러면 옛 증서가 전부 `못잼` 이 된다 — *틀렸다*가 아니라
*이 증서로는 더 못 견준다*. 그 둘은 다르다.

## 독립판정 (`cut/판정.py:독립판정`) — "새로운가"의 잴 수 있는 꼴

`자름판정`은 FF 자신의 제약에 함의되는지만 본다 -- 새로움의 필요조건이지 근처도 아니다.
`독립판정`은 **다른 연산자들의 부등식을 LP 에 얹고도 자르는가**를 묻는다.

```
max{a·z : z ∈ P_LP ∩ 알려진}  >  b   ->  독립
                              <= b   ->  함의됨
```

실측(5씨앗, 한 연산자를 빼고 나머지 여섯을 얹었다): **노드덮개 100% 함의됨 · 분리유도
100% 함의됨 · 노드고정 100% 독립 · 최소홉 10/11 독립.** 지금 일곱 안에서 비자명하게
독립인 건 최소홉뿐이고, 그것도 새롭지 않다(홉 하한은 표준).

## 증명 (`cut/증명.py`) — solver 도 이 저장소도 없이 검증되는 항

`유효판정`(MIP)은 그 인스턴스에서만 증명이고 scipy·이 저장소가 있어야 확인된다 --
**재현**이지 독립이 아니다. `증명.py`는 CG-1 증서를 내보내 **산수만으로**(Fraction,
곱하고 더하고 견주기) 검증되게 한다.

```
확인(증서)        산수가 맞나            -- 이 파일 말고 아무것도 안 쓴다
줄대조(p, 증서)   인용한 줄이 진짜 모델의 줄인가 -- 여기서만 FF 를 본다
cg폐포판정(p,a,b) 기초 행만으로 λ 를 LP 로 찾고 Fraction 으로 되돌려 확인한다
```

거짓 증서(음수 배수·b 낮추기·a 키우기·우변 줄이기·없는 줄 지어내기)를 심어 각각
`확인`/`줄대조` 중 어느 쪽이 잡는지 `tests/test_cut.py` 가 붙든다.

## 로드맵 -- 다음 세션은 여기서부터 (대화를 안 읽어도 된다)

**Phase 0 (끝났다).** 일곱 연산자를 baseline 으로 고정. CG-1 폐포·독립판정으로 각각의
자리를 확정했다(위 표). 결론: **지금 있는 건 새 부등식이 아니라 검증 장치다.**
"발견했다"는 거짓(전부 손으로 적었다), "독립 검증"은 참(산수 증서 + 자동 CG-1 판정).

**Phase 1 (다음) -- flow/cut 계열 템플릿 추가.** 최소홉이 유일하게 흐름보존(y)을 건드려
다르다는 게 힌트다. 후보: **컷셋(cut-set)** -- 가상 링크의 수요 합이 그 컷을 지나는
바탕 용량 합을 넘으면 그 컷 양쪽에 걸친 배치는 제한된다. 기존 넷과 다른 기초 행(흐름
보존 + 대역을 함께 쓴다)을 쓰므로 CG-1 폐포 밖일 가능성이 노드덮개류보다 높다.
새 연산자는 `cut/찾기.py`의 규율을 그대로 따른다 -- 모든 인스턴스 증명이 있어야 하고,
`cg폐포판정`·`독립판정`·`대조군`(안자름/무효 0)을 통과해야 한다.

**Phase 3 (Phase 1과 병행) -- 인스턴스 확장.** 지금은 6노드/3노드뿐이다. `n=6→10→20→50`
으로 키우며 LP gap·독립판정 결과가 달라지는지 본다(2.3 절의 LP 약점은 큰 인스턴스에서
드러난다 -- 지금 규모에서는 "독립"의 뜻 자체가 약할 수 있다).

**Phase 2, 4는 나중이다.** Phase 2(자기변형 red/green 검증 루프)는 Phase 1이 새 템플릿을
내놓은 뒤에나 뜻이 있고, Phase 4(진짜 separation oracle)는 "새로운 부등식"의 정의부터
확정해야 하는 별도 연구 단계다(2차).

## 한계 -- 이름으로 적어 둔다

- `유효판정` 은 **그 인스턴스 하나에 대한 증명**이다(표본이 아니다). 모든 인스턴스에
  대한 유효성(inequality *family*)은 여기서 안 나온다 -- 그것은 증명 의무다.
- FF 변수는 `|V_R||V_S| + |E_R|·2|E_S|`. 49노드/155링크 바탕에 10노드 요청이면 만 개가
  넘는다. 여기 행렬은 **빽빽한(dense) 판**이라 작은 인스턴스용이다.
- `vne/`(재는 자)와 따로 둔다. 저쪽은 수용률·매출비를 재고, 이쪽은 부등식을 판정한다.
