# cut -- 절단평면 판정기 (VNE 논문의 최소 시작점)

**기능 하나가 결정 하나다.** 발견기는 여기 없다 -- 부등식이 어디서 왔든 묻지 않고 판정만 한다.

| 결정 | 무엇을 묻나 | 값 |
|---|---|---|
| `유효판정` | `max{a·z : z ∈ X_VNE} ≤ b` (MIP, 최적까지) | 유효 / **무효** / 못잼 |
| `자름판정` | `max{a·z : z ∈ P_LP} > b` (LP 한 번) | 자름 / 안자름 / 못잼 |
| `분리판정` | `a·z* > b` (산수) | 분리함 / 못함 / 못잼 |
| `조임판정` | LP 경계가 올랐나 | 조임 / 안조임 / 못잼 |
| `채택판정` | 넷을 차례로 | ACCEPT / **REJECT** |

**기본은 전부 '아니오'다.** 못 재면 못잼이고 못잼은 통과가 아니다.

## 왜 이 자리의 거짓 초록이 유난히 비싼가

유효하지 않은 cut 을 유효라 부르면 solver 가 **터지지 않는다.** 크래시도 infeasible 도
아니고 **조용히 다른 최적해**를 낸다. 아무도 모르고, 그 위의 모든 수가 근거처럼 보인다.

## 연산자 연산자 (증명을 붙일 수 있는 것만)

| 연산자 | 부등식 | 증명 근거 |
|---|---|---|
| `노드덮개` | `Σ_{v∈T}Σ_{u∈S} x ≤ |T|−1` | CPU 제약 |
| `링크덮개` | `Σ_{e∈T}(y_uw+y_wu) ≤ |T|−1` | 대역 제약 |
| `최소홉` | `−Σ_arc y[e] ≤ −1` | 일대일 + 흐름 보존 |
| `노드고정` | `x[r,u] ≤ 0` (d_r > cap(u)) | CPU 제약 |
| `링크고정` | `y[e,(u,w)]+y[e,(w,u)] ≤ 0` | 대역 제약 |
| `짝배제` | `x[r,u]+x[s,u] ≤ 1` | 일대일 — **대조군**(전부 안자름이어야 한다) |

**여섯에서 멈췄다.** 연산자 하나하나에 "모든 인스턴스에서 성립한다" 는 논증이 붙어야
family 로 올릴 수 있다. 수보다 증명이 먼저다.

## 후보를 어떻게 만드나

| 연산자 | 어떻게 | 비고 |
|---|---|---|
| 여섯 손수 연산자 | T·S 를 **전수 열거** | 증명이 붙어 있다 |
| `분리유도` | **LP 해의 쪼개진 자리**에서 짓는다 | 적게 훑고 같은 수를 찾는다 |

`분리유도` 가 v3 의 **모델 없는 꼴**이다 — *fractional solution → feature extraction →
candidate → verifier*. 여기서 feature 는 쪼개진 받침(fractional support)이고, 뽑는 데
회귀도 LLM 도 안 쓴다. **유효성 증명은 그대로다** — 덮개 부등식의 증명은 T·S 를 어떻게
골랐는지에 안 기댄다.

## 일반화 (`cut/일반화.py`) — 안 본 인스턴스에서 잰다

```bash
python3 -c "
from vne import topo as T; from cut import 일반화 as G
짓기 = lambda s: (T.바탕망(씨앗=s, 노드수=6, 꼴='random', p=0.7, cpu범위=(4,6)),
                T.요청망(씨앗=100+s, 노드범위=(3,4), cpu범위=(3,6), 대역범위=(1,5)))
print(G.보고(G.검증('최소홉', range(0,6), range(6,12), 짓기)))"
```

연산자의 **유효성**은 이미 모든 인스턴스에 대해 증명돼 있다 — 물을 것이 없다. 무는 것은
**자르나 · 조이나** 이고 그것은 인스턴스마다 다르다.

```
지켜짐   검증군에서도 생산적이다
무너짐   발견군에서만 생산적이었다 -> **그 인스턴스군의 성질이었다**
못잼     후보가 안 나왔거나 표본이 모자라다
```

실측 (씨앗 0–5 발견 / 6–11 검증):

```
최소홉     지켜짐   발견 1.0   -> 검증 1.0    (Δ 3.25 -> 2.78)
분리유도   무너짐   발견 0.125 -> 검증 0.0
짝배제     못잼     추측조차 못 세움 (대조군)
```

**분리유도가 무너진 것이 이 장치의 값이다.** 발견군에서만 재면 "전수열거보다 낫다" 가
나오는데, 그 발견군이 바로 고르는 데 쓴 인스턴스다.

## 증서 (`cut/증서.py`)

판정을 JSON 으로 내보내고 **판정기가 그것을 다시 읽어 독립으로 재판정한다.**

```bash
python3 -c "from cut import 증서 as C; print(C.다시판정모두())"
```

세 값이다 — `맞다` / `어긋난다`(증서가 거짓) / `못잼`(바탕이 바뀌어 더 못 견준다).

**바탕은 불변이다.** `cut/ff.py` 와 `vne/topo.py` 의 지문이 증서마다 박힌다. 주석 한 줄만
바뀌어도 지문이 달라지고, 그러면 옛 증서가 전부 `못잼` 이 된다 — *틀렸다*가 아니라
*이 증서로는 더 못 견준다*. 그 둘은 다르다.

## 한계 -- 이름으로 적어 둔다

- `유효판정` 은 **그 인스턴스 하나에 대한 증명**이다(표본이 아니다). 모든 인스턴스에
  대한 유효성(inequality *family*)은 여기서 안 나온다 -- 그것은 증명 의무다.
- FF 변수는 `|V_R||V_S| + |E_R|·2|E_S|`. 49노드/155링크 바탕에 10노드 요청이면 만 개가
  넘는다. 여기 행렬은 **빽빽한(dense) 판**이라 작은 인스턴스용이다.
- `vne/`(재는 자)와 따로 둔다. 저쪽은 수용률·매출비를 재고, 이쪽은 부등식을 판정한다.
