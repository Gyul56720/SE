# nv2 -- 라이트노벨 양산기 (다시 지음)

사용자: "Novel 오케스트레이션으로 재미있는 라이트노벨을 24시간 동안 가공하면서 양산해야해.
액션씬 전투씬 스킬 직함 세계관 설정 더 자세히. 복수극도 좋고. **거지가 왕궁 들어가서
권력 탈취하는 것도 좋고(예시야 하드코딩하지마)** 이런 문법들을 더 모으라고. 중간에
주인공을 구해주는 잘생긴 히로인도 없고 너무 도파민 요소가 없어."

## 앞 판(`novel/`)은 왜 죽었나

내용이 모자라서가 아니다. **실측 2026-09-09: 사용자가 시킨 열여섯 가지가 전부
프롬프트에 실려 있었는데 원고는 한 줄도 안 지켰다.**

    프롬프트 8,455자 · 지시 줄 81개 · 굵은 글씨 88군데      (출력은 3,200자)
    "여기만 고쳐라" 가 앉은 자리: 8,238자 = 97% 지점

그리고 같은 병이 다섯 번 났다 -- **적어 두고 안 부친 규칙.**

| 무엇 | 어디서 끊겼나 |
|---|---|
| `--persona` | 기본 경로가 문장론 함수를 안 부른다 |
| 첫회차 규율 열넷 | 디렉터 카드에만 실렸다 -- 쓰는 쪽은 못 봤다 |
| `echo.check` | 복사를 잡고 "원고는 그대로 쓴다" 로 흘려보냈다 |
| `GENRE` 빈 값 | 도착지도 카드도 안 선다 -- 이야기 층이 통째로 꺼진다 |
| `[고정]` 블록 | 옛 경로에만 있었다 -- 시점이 한 번도 안 갔다 |

**다섯 번 다 원고는 멀쩡히 나왔다.** 그래서 아무도 못 알아챘다.

## 그래서 nv2 는 이 셋을 **구조로** 막는다

### 1. 규칙은 셋을 다 갖춰야 들어온다 -- 잰다 · 부친다 · 고친다

`rules.py` 에 등록되지 않은 규칙은 프롬프트에 실릴 수 없다. 등록하려면

    잰다   text -> 수          (없으면 규칙이 아니라 **본보기**다)
    부친다 어긋났을 때 할 말
    고친다 무손실 수리 함수, 또는 `되먹임만` 이라고 **명시**

셋 중 하나가 없으면 `tests/test_nv2_rules.py` 가 빨간불을 낸다. "적어 두고 안 부친
규칙" 은 이 관문을 통과할 수 없다.

### 2. 프롬프트는 예산이다 -- 넘으면 **버리고, 버렸다고 말한다**

`prompt.py` 는 지시 예산(기본 2,400자)을 갖는다. 넘으면 우선순위가 낮은 것부터
떨어뜨리고 **무엇을 떨어뜨렸는지 로그에 적는다.** 조용히 다 싣지 않는다.

자리도 정해져 있다:

    1. [반드시]   잰 어긋남 셋까지          <- 맨 앞. 여기만 굵은 글씨를 쓴다
    2. [이번 회차] 카드 -- 무엇이 벌어지나
    3. [세계]     원장 -- 어긋나면 안 되는 것
    4. [본보기]   돌려 뽑은 문법 몇 개       <- 지키라는 말이 아니다
    5. [이어서]   앞 회차의 꼬리

### 3. 생성 단위는 **회차**다

앞 판은 3,200자 덩어리로 썼고 회차 비트와 계속 어긋났다 -- 회차가 일찍 끝나면
슬랙이 다음 회차에 얹혀 7,244자 / 11,502자로 벌어졌고, 걸친 비트는 같은 장면을
다시 열었다. nv2 는 **회차를 한 번에 쓴다.**

## 문법과 값을 가른다

    문법: "[색] + [직함] 꼴의 이명"      <- 여기 적는다
    값:   "은빛 기사"                    <- 절대 안 적는다

값을 코드에 박으면 **모든 원고에 그 값이 돌아온다.** 앞 판이 실제로 그랬다 --
기본 첫 문장에 박아 둔 지명이 새 원고마다 되살아났다(사용자: "이건 처음에 썻던
건데 왜 이게 다시 나오지?").

사용자가 든 예(거지 · 왕궁 · 흑마왕 · 강아지)도 **꼴로만** 들어온다.
`tests/test_nv2_bank.py` 가 그 낱말이 은행에 없는지 본다.

## 무엇이 켜졌는지 늘 찍는다

    python3 -m nv2.probe

기본값이 기능을 끄고 있으면 **그렇다고 말한다.** 앞 판은 갈래가 비면 이야기 층이
통째로 꺼지는데 아무 말도 안 했다.
