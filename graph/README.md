# graph -- 압축 '색인'이지 압축 '보관'이 아니다 (night_mode)

```
쌓인 기록(md) ──night.py(밤일)──> 원장 ledger.jsonl: {깃발, 요약, 출처, 해시}
                                        │
물음 ──ask.py──> 깃발로 찾는다 ──> 요약 ──--원문──> 출처 파일 (해시 대조)
```

## 왜 색인인가 -- 보관이 아니라

사람이 잘 때 기억이 굳는 것처럼, 쌓인 기록을 밤에 간추려 두었다가 깃발만 보고 쏙
뽑아 쓰자는 것이 출발이다. 그런데 **압축해서 원본 대신 보관하면 버린 것을 아무도 못
되찾는다** -- `dig/README.md` 가 정확히 그 병을 적어 두었고, 이 저장소에서 원본
저장은 git 이 이미 한다. 그래서 여기서 만드는 것은 보관이 아니라 **찾는 길**이다:

| | |
|---|---|
| 원본 | git 에 그대로. 여기서 안 만지고 안 지운다 |
| 원장 노드 | 깃발(꼬리표) + 요약 + 출처 경로 + **원본 해시** |
| 조회 | 깃발로 찾고, `--원문` 으로 출처를 연다. **해시가 어긋나면 "원본이 그때와 다르다" 고 말한다** |

append-only JSONL 이고 git 이 버전이다. 원본이 바뀌면 새 해시로 새 줄이 쌓이고
조회는 출처별 최신만 본다 -- 역사는 남는다.

## 거절 규칙 (원장 대조 규율)

- 깃발 없는 노드 거절 -- 깃발 없는 기억은 못 되찾는다.
- 출처가 실재하지 않으면 거절 · 저장소 밖 경로 거절(G014 규율).
- 같은 (출처, 해시) 는 다시 안 적는다 -- 밤마다 돌려도 원장이 안 부푼다.

## 모델은 제안하고 코드가 판정한다

기본 요약·깃발은 코드가 뽑는다(파일 이름 조각 · topic · 본문 잦은 낱말 · 연월).
`--모델` 이면 Gemini 가 더 나은 요약·깃발을 **제안**하는데, 채택은
`graph/verify.py`(brain 의 **대조 꼴**: 요약의 수치·깃발·낱말이 원문에 글자 그대로
서 있는가)를 통과한 것만이다. 퇴짜면 코드 요약으로 물러서고 사유가 보고에 남는다.
채택된 노드에는 `지은이: 모델(대조통과)` 가 남는다 -- 검증 안 된 모델 요약이 이
원장에 들어오는 길은 없다. 프롬프트에는 검사 내용을 한 글자도 안 적는다(알려 주면
검사가 사양서가 된다 -- law/write 규율).

## 다섯 꼴 간선 (`graph/link.py`)

brain 의 닫힌 다섯 꼴을 기억 도메인에 그대로 옮겼다. 간선을 새로 발명하지 않는다.

| 꼴 | 여기서 묻는 것 | 판정 |
|---|---|---|
| 대조 | 요약·깃발이 원문에 서 있는가 | 맞음/어긋남/미검증 |
| 재계산 | 해시·글자수를 다시 세면 같은가 | 같음/다름/못셈 |
| 기준선 | 깃발이 원장 분포에서 이례인가 | 이례/평범/못잼 |
| 뒤집기 | 깃발 몇 갈래로 저를 되찾는가 | 굳음/약함/못잼 |
| 연역 | 전제에서 따라 나오는가 | **관할 밖** -- reason/ 이 판정기다 |

간선은 판정 사건의 기록이다(edges.jsonl, append-only). 어긋남도 안 지운다 --
어긋남은 지우는 것이 아니라 보는 것이다. 같은 판정이 이어지면 다시 안 적는다.

## 요지문 -- '읽힐 텍스트' 는 판정이 정한다 (`graph/digest.py`)

/intent+/evolve 의 축소판이다: 진화란 가중치가 아니라 **읽힐 텍스트**를 고치는
것이고, 무엇이 읽히는가를 말이 아니라 간선이 정한다. `graph/digest.md` 는 원장에서
밤마다 다시 지어지는 파생 문서다 -- 대조=어긋남·재계산=다름인 기억은 경고 절로
**강등**되고, 기준선=이례에 검증 통과한 기억만 새 갈래로 **승격**된다. 손으로
고치지 마라: 다음 밤일이 덮는다. 진실은 원장 두 개에 있다.

## 쓰기

```bash
python3 graph/night.py               # 간추린다 (이미 있는 것은 건너뛴다)
python3 graph/night.py --모델        # Gemini 제안 + 대조 검증 (키 없으면 안 돌린다)
python3 graph/ask.py --말 "코인 실측"  # 깃발(3점)·요약(1점)에서 찾는다 + 최근 판정
python3 graph/ask.py --말 촉매 --원문  # 출처 발췌 + 해시 대조
python3 graph/link.py --전부          # 다섯 꼴 판정, 간선 적기 (어긋남이면 끝값 1)
python3 graph/digest.py              # 요지문 다시 짓기
bash scripts/night.sh                # 밤 한 바퀴: 간추리기->판정->요지->게이트->커밋->밀기
python3 tests/test_graph.py tests/test_graph_판정.py  # 배선 검사
```

디스코드: `!기억 <말>` · `!기억 요지` (공개 채널도 됨, 읽기만) · `!기억 밤` ·
`!기억 판정 <말>` (관리 채널만). 에이전트의 search_memory 는 깃발 색인을 먼저
보여주고 노트 전문 검색을 잇는다.

## 옆방과의 분업

| | |
|---|---|
| `memory_hygiene.py` | **잊기** -- 코드와 모순된 노트를 지운다 |

| `agent_memory.py` | **적기/전문 검색** -- 노트 자체 |

셋은 다른 일이라 두 벌이 아니다.
