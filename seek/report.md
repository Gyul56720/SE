# seek 결과

문제 2개 · 답이 있는 것 2개

**이 파일은 만들어진 것이다.** 고치지 마라 -- `python3 seek/report.py --쓰기` 가 덮어쓴다.
원장(`seek/ledger.json`)은 무시 목록에 있다. 이것이 그 파생물이다.

## 감사 -- 판정기가 무엇을 거르나

```
id     등급           적중    터짐  물음
P1     막힘        0/200     0  5선 정렬망을 비교기 9개로 만들 수 있는가 (크기)
P2     문제        1/200     0  5선에서 비교기 몇 개로 2^5 중 31개 이상을 정렬하는가 (하나까지 틀려도 좋다)

문제 2개 -- 막힘 1개 · 문제 1개
막힘 1개는 **버리지 않는다** -- 어려운 것이 여기 섞여 있다 (P1 이 그렇다: 22,991개를 봐야 하나가 걸린다)
```

## 대조군 -- 그 자가 계보를 재기는 하나

```
                  도약       재작성      딴 문제        모름      걸음
진짜 짝               1         0         0         0       1
무작위 짝              0         0         0         0       0

도약 비율 -- 진짜 100.0% · 무작위 0.0%
무작위 짝은 훨씬 덜 낸다 -- **이 자는 계보를 본다.** 진짜 짝의 도약은 우연이 아니다.

(이 파일은 아무것도 기각하지 않는다. 숫자를 만들 뿐이다)
```

## 셈 -- 어느 연산자가 냈나

```
연산자            걸음      도약     재작성    딴 문제      모름     도약률     무작위
경계화             1       1       0       0       0   100%      0%  <- 잰 것이 적어 못 읽는다

  도약률은 **잰 것 중에서**다 (모름을 뺀 분모). 모름은 판정이 아니라 아직 못 잰 것이다.

깊이             걸음      도약     재작성    딴 문제      모름
1               1       1       0       0       0
```

## 도약으로 판정된 걸음

### P1 -> P2  (경계화)

- 부모: 5선 정렬망을 비교기 9개로 만들 수 있는가 (크기)
- 자식: 5선에서 비교기 몇 개로 2^5 중 31개 이상을 정렬하는가 (하나까지 틀려도 좋다)
