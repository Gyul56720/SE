# SSM Selective-Scan 가속기 -- System 설계 (2026-09-25)

**노선**: 갈래 B(Mamba/SSM 선형어텐션), 서사 ⓑ 무인체계 제어 정책. 코어는 **selective-scan
유닛 하나**. 순차 스캔(스트리밍 디코드)부터. LIG AI-HW co-design 취업 포트폴리오.

**방침(이 저장소 규율)**: **자원부터 잰다**(AIM 은 안 재서 죽었다). 완성도 아니라 "중급
FPGA 에 들어가는가 · 무엇이 LUT/DSP/BRAM 로 가는가" 를 먼저 본다. 골든 대조 + 변이 검사 +
독립 대조로 거짓 초록을 막는다.

## 1. selective-scan 이 무엇을 계산하나 (한 채널, 상태차원 N)

한 타임스텝 $t$, 채널당:
```
이산화:   Abar[n] = exp(delta * A[n])          # n=0..N-1, A[n]<0 (안정) -> Abar in (0,1] 감쇠게이트
          Bbar[n] = delta * B[n]               # (1차 근사; 정식은 (Abar-1)/A * B)
상태갱신:  h[n]   = Abar[n]*h[n-1prev] + Bbar[n]*x    # N MAC
출력:      y      = sum_n C[n]*h[n]  (+ D*x)    # N MAC + 리덕션
```
- **입력 의존(selective)**: delta,B,C 가 매 스텝 바뀐다 -> 컨볼루션으로 못 편다.
- **순차 스캔**: 스트리밍 추론(디코드)은 한 표본씩 들어오니 자연히 순차. 상태 h[N] 만 유지.

## 2. 하드웨어 급소 = 측정 타깃 (재서 보이는 수)

| 급소 | 무엇 | 어디로 가나(가설) | 어떻게 재나 |
|---|---|---|---|
| **exp(delta*A)** | 이산화 감쇠게이트 | LUT(로직) or 다항식(DSP) or BRAM | 근사식별 자원·정확도 파레토 (갈래 A 재사용) |
| **상태갱신 MAC** | Abar*h + Bbar*x | **DSP48** (곱-덧, FFT 나비처럼) | N 별 DSP 수 |
| **출력 리덕션** | sum C*h | DSP + 가산트리 | 지연·DSP |
| **상태 메모리** | h[N] (+ 큰 모델은 DDR) | 소형은 레지스터/BRAM | N·비트폭 |

**첫 측정(이 문서 이후 바로)**: exp 근사가 LUT 로 가는가, 자원 얼마인가. 근사 차수 <->
LUT/DSP <-> 정확도 를 **곡선으로** 낸다. 남들은 한 점만 낸다 -- 이게 우리 차별점.

## 3. 고정소수 포맷 (초안, 측정으로 조정)
- `delta*A` = z: 음수, 대략 [-8, 0]. **Q4.12**(부호+3정수+12소수, 16b)로 시작.
- `Abar`: (0,1]. **Q0.16** 무부호 16b (1.0 은 0xFFFF 로 근사, 포화).
- `x, B, C, h`: **Q1.15** 16b 부호 (Mamba FPGA 선행이 INT8~16 씀; 우리는 16b 로 상한).
- 곱 누산: 32b. 출력 재정규화.

## 4. 측정 계획 (파레토)
exp 근사 후보:
- **직접 LUT**: z 를 K 구간으로 양자화 -> Abar 표. K=8/16/32/64. BRAM vs 분산LUT.
- **base-2 시프트(Softermax류)**: 2^(z*log2 e) = 2^int * 2^frac, int=시프트, frac=소형LUT/선형.
- **1차 선형 근사(FastMamba류)**: 구간선형(PWL).
각 후보로 (최대절대오차, LUT, DSP, BRAM, Fmax) 를 잰다. yosys `synth_xilinx -family xc7`
로 FPGA 매핑, `synth`(nsw10)로 ASIC 셀. 골든은 numpy exp.

## 5. 독립 대조 (거짓 초록 방지, CLAUDE.md '수를 말하기 전 넷')
- exp 근사 오차: RTL 출력 vs numpy exp 를 **비트 정확히** 대조(골든 벡터).
- 자원: yosys stat 의 셀/LUT/DSP 를 **두 백엔드**(xc7, nsw10)로 교차 확인.
- 변이 검사: 근사표 한 칸·시프트량을 흔들어 검사가 무는지(aim/rtl검사.sh 방식).
- 사소한 설명 배제: exp 가 상수(전부 1.0)로 퇴화하지 않는지 -- z 범위를 실제로 흔든다.

## 6. 완제품 경로 (다섯 직무 흐름)
scan 유닛 -> SSM 블록 -> RTL(house/rtl) · 검증(house/dv 황금+변이) · 합성(house/syn) ·
DFT · 배치. 파이썬 노트북 아니라 사인오프까지. house/designs.py 에 설계 등록.

## 7. 아직 안 정한 것
- N(상태차원): Mamba 는 보통 16. 측정으로 자원 확인 후 확정.
- 채널 병렬도: 1채널부터, 자원 여유 보고 늘린다.
- Bbar 정식 vs 1차근사: 정확도-자원으로 결정.
