# CUAS 마이크로 도플러 분류기 -- System 설계 메모

## 물리에서 나온 파라미터 (cuas/model/param.py 가 계산)

    대역        X-band 10 GHz (λ=30mm) 를 기준으로 잡는다
    최대 마이크로 도플러  ±12.6 kHz (15000 rpm 날개 끝)
    표본율      fs = 40 kHz (여유 있게 2배 초과)
    STFT        N=256, 홉=64, 창 Hann.  창길이 6.4 ms, 분해능 156 Hz
    관측        20 ms = 날개 한 바퀴.  관측당 홉 ~9개
    스펙트로그램 프레임  256(주파수) x ~9(시간)  -> 분류기 입력

## 데이터흐름 (탐지 -> 스펙트로그램 -> 분류)

    IQ (fs=40kHz, 복소)
      │
      ▼  ① 이동 창 버퍼 (N=256, 홉=64)          RAM 한 벌
      ▼  ② Hann 창 곱                            상수 곱 256개
      ▼  ③ FFT-256 복소                          ← **자원의 급소**. 여기부터 잰다
      ▼  ④ |·|² 크기제곱 -> 로그                  DSP 곱 + LUT
      ▼  ⑤ 스펙트로그램 프레임 조립 (256 x T)     BRAM
      ▼  ⑥ 특징/분류기                            ← 나중. CNN or 가벼운 특징
      ▼
    판정 {드론 / 새 / 잡음}

## AIM 의 교훈 -- 자원부터

AIM 은 곱이 DSP 를 못 써서 S-box 하나가 20~32K LUT 였고 전체의 3% 였다.
여기서는 **FFT 가 DSP 를 쓴다**(복소 곱 = 정수 곱). 그래서 자원 자리가 다르다.
**그래도 재기 전에는 모른다.** 순서: FFT 부터 합성해 LUT/DSP/BRAM 을 재고,
중급 FPGA(Zynq ZU) 한 장에 들어가는지 본다.

## 검증 -- 정답을 무엇이 내나

합성 도플러를 python 모델(cuas/model/)이 낸다. numpy 로 STFT 를 돌려 **황금 스펙트로그램**을
만들고, RTL 이 낸 것과 대조한다. **RTL 이 스스로 정답을 짓지 않는다.**

## 자원 실측 1 (2026-09-25) -- **들어간다. AIM 과 정반대.**

FFT-256 나비 하나를 Zynq(xc7)로 합성:

    나비 1개 = DSP48E1 **4개** + LUT2 95 + CARRY4 24

**복소곱이 DSP 를 쓴다.** AIM 의 GF(2^128) 곱은 DSP 를 못 써서 순수 LUT 로 폭발했는데
(S-box 하나 20~32K LUT), 여기 정수 곱은 DSP 슬라이스로 간다. **자리가 통째로 다르다.**

### FFT-256 예산 (세 설계)

| 설계 | DSP | 사이클/FFT | 비고 |
|---|---|---|---|
| (A) 완전 펼침 | 4,096 | 1 | 상한 확인용. 어느 FPGA 도 못 담음 |
| (B) 나비 1개 재사용 | **4** | 1,024 | 면적 최소 |
| (C) 단당 1개 파이프 | **32** | ~128 | 균형 |

### 보드 대조 -- **예산 안의 모든 보드에 들어간다**

    Zynq-7020(Pynq-Z2)  DSP 220   -> 재사용·파이프 둘 다 OK
    ZU3EG(Ultra96)      DSP 360   -> 둘 다 OK
    ZU7EV(ZCU104)       DSP 1728  -> 둘 다 OK

### 처리량 -- **여유가 압도적**

    필요:  홉마다 FFT 하나 = 625 FFT/s (fs=40kHz, 홉=64)
    가능:  clk 100 MHz 에서 FFT 하나에 160,000 사이클 여유
           재사용(B)의 1,024 사이클도 **156배 여유**

**즉 FFT 는 이 시스템의 병목이 아니다.** DSP 도, 처리량도 남는다.
남는 자원을 **분류기(CNN or 특징 추출)** 에 쓸 수 있다는 뜻이다.

## 그래서 진짜 물음이 바뀐다

AIM 은 "들어가나?" 가 물음이었다. 여기서는 **들어간다**. 그러니 물음은:
1. **분류기가 얼마나 드나** -- 스펙트로그램(256 x 9)을 드론/새/잡음으로. 이게 진짜 자원 급소.
2. **드론 vs 새 오경보** -- 선행조사가 짚은 열린 문제. 여기가 연구 자리.

다음: 분류기 자원을 잰다. 가벼운 특징(에너지·측대역 간격·HERM 선폭) vs 작은 CNN.

## 아직 못 믿는 것
- 나비 자원은 **조합 한 개**다. 파이프라인·트위들 ROM·비트reversal·RAM 이 아직 없다.
- Q1.15 고정소수의 정밀도(스펙트로그램이 분류에 쓸 만한가)를 아직 안 쟀다.
- **황금 모델의 도플러가 단순 합성**이다. 실제 드론 마이크로 도플러와 얼마나 닮았는지 모른다.
