# 폐기논문 -- 주장이 서지 못한 원고

여기 있는 것은 **철회한 원고**다. 지우지 않고 남기는 이유는 두 가지다. 무엇을 잘못했는지
다시 보려고, 그리고 `tests/test_gates_on_incidents.py` 가 이 트리(`ff31763`)에 대고 게이트의
RED 를 매번 다시 증명하기 때문이다.

| 원고 | 왜 철회했나 |
|---|---|
| `recurrence_hls_IEEE` | 표제가 "1/59 면적" 인데, **내가 직접 잰 것이 그 주장을 이미 무너뜨렸다.** (1) 타이밍 병목은 언롤링이 이미 푼다 -- 고리경로 25단 -> 1단. 남는 것은 비용뿐인데 표제는 병목 해결처럼 읽힌다. (2) 실제 동작점(30 dB)에서 W(1e-3) > 16 이라 제거형이 크게 진다. 1/59 는 유리한 구석에서 나온 수다. (3) 참고문헌 28개 중 18개가 `[verify]` 표시를 단 채였다 -- 안 읽고 인용했다는 뜻이다. |
| `multiplier_free_lookup_eq_IEEE` | 참고문헌 25개 중 21개가 `[verify]`. 핵심 주장(주소폭이 아니라 점유가 비용을 정한다)은 **ReducedLUT**(FPGA'25, arXiv:2412.18579)가 이미 한 것이다. 선행조사를 짓고 나서가 아니라 짓고 **난 뒤에** 했다. |
| `serdes_afe_transistor` | 폐기한 SerDes 등화 갈래의 산물. 지터 민감도를 펄스 정점(기울기가 정의상 0인 자리)에서 잰 오류가 이 갈래에서 났다. |
| `serdes_nn_eq` | 같은 갈래. 사용자 지시로 버린 주제다. |

## 공통된 병

네 편 다 **재고 나서 그 수가 사소하게 나올 수 있는 길을 막지 않았다.** 그리고 참고문헌은
읽지 않은 채 목록이 되었다. 그래서 `G022` · `G023` · `G024` 가 생겼다 -- 원장 없이는 인용도
표제 숫자도 `paper/` 에 못 들어간다.
