# attic -- 얼린 것

**여기 있는 것은 돌지 않는다.** 검사도 안 돌고(`scripts/tests.sh` 는 `tests/` 만 본다),
디스코드에서도 못 부르고, 봇이 임포트하지도 않는다.

**지우지 않는 까닭:** 판정 원장은 append-only 다(G020). 얼리는 것은 자리를 옮기는 것이지
역사를 지우는 것이 아니다. `attic/vne/측정.jsonl` 은 여전히 G020 의 보호 목록에 있다.

## 2026-09-14 -- VNE / cut

사용자 판단으로 얼렸다. 무엇이었나:

- `attic/vne/` -- Virtual Network Embedding 인스턴스 생성 · 배치 · 측정
- `attic/cut/` -- VNE 흐름 공식화(FF)의 유효 부등식과 그 CG 증서
- `attic/test_cut.py` · `attic/test_vne.py` -- 딸린 검사

**왜 얼렸나.** 연구 주장은 "새로운 수학적 객체를 발견하고 독립 증서로 검증했다" 였는데,
재 보니 세 조각으로 갈라졌다.

| 주장 | 재 본 결과 |
|---|---|
| 발견했다 | **아니다.** 일곱 연산자 전부 손으로 적은 것이다 |
| 새롭다 | **거의 아니다.** 일곱 중 다섯이 바탕 네 행의 rank-1 CG 조합임이 증명됐다. 구조가 다른 것은 최소홉 하나인데 그것은 표준 hop bound 다 |
| 독립 검증 | **맞다.** solver 도 이 저장소도 없이 산수만으로 확인되는 CG 증서다 |

덧붙여, 이 물건은 **볼 창구가 없었다** -- `cut/*.py` 에 `__main__` 이 없고, 디스코드 명령도
없고, `cut/증서.py` 가 쓰기로 한 `cut/증서/` 디렉터리는 **한 번도 만들어진 적이 없다**.
증서가 한 장도 안 나왔다는 뜻이다.

**되살리려면** `attic/` 밖으로 옮기고, `tests/` 로 검사를 돌려놓고, G020 의 원장 자리를
되돌리면 된다. `requirements.txt` 의 `scipy` 는 그대로 있다(`orchestrator/problems/` 도 쓴다).
