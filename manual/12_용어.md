# 12. 용어 — 이 매뉴얼에 나오는 말

> 전자공학 학부 수준에서 안 배웠을 만한 것만 모았다.
> AND/OR, 플립플롭, 셋업/홀드 같은 것은 안 적었다.

---

## 검증

**골든모델 (golden model)**
정답을 계산하는 독립 구현. 보통 C++. **RTL 을 보고 쓰면 안 된다** —
자기 자신과 비교하는 것이 되어 아무것도 검증하지 않는다.

**자극 (stimulus)**
DUT 에 넣는 입력. "벡터" 라고도 한다.

**DUT (Device Under Test)**
검사 대상 블록. 테스트벤치가 감싸는 그것.

**테스트벤치 (testbench)**
DUT 에 자극을 넣고 출력을 정답과 비교하는 합성 안 되는 코드.

**회귀 (regression)**
고칠 때마다 다시 돌리는 검사 묶음. "전에 되던 게 깨졌나" 를 본다.

**자해검사**
*정답을 일부러 망가뜨려, 검사가 반드시 빨개지는지 보는 것.*
이 매뉴얼의 핵심 절차. 이것 없이는 `틀림 0` 이 "맞다"인지
"검사가 안 돈다"인지 모른다.

**변이 점수 (mutation score)**
RTL 을 조금씩 망가뜨려(`&`→`|` 등) 검사가 몇 %를 잡는지 센 수.
"검사가 통과하나" 가 아니라 **"검사가 무나"** 에 답한다.

**등가 변이 (equivalent mutant)**
바꿔도 같은 함수가 되는 변이. 못 잡는 게 맞다. 조용히 빼지 말고
**증명해서 기록**한다.

**전수 확인 (exhaustive)**
입력 공간 전부를 훑는 것. 표본이 아니다. 입력이 2³² 이하면 C++ 로
30초에 가능하다.

**커버리지 (coverage)**
"볼 것을 다 봤나". 어서션은 "틀린 게 없나", 변이 점수는 "검사가 무나".
셋이 서로를 대신하지 못한다.

## 하드웨어

**RTL (Register Transfer Level)**
레지스터 사이의 데이터 이동으로 회로를 적는 수준. Verilog/SystemVerilog.

**lint**
합성·시뮬 전에 문법과 폭을 보는 정적 검사. 1초. **가장 싸고 가장 많이 잡는다.**

**합성 (synthesis)**
RTL → 게이트 넷리스트. `yosys`.

**넷리스트 (netlist)**
게이트와 배선의 목록. 합성의 결과물.

**배치·배선 (P&R, place and route)**
넷리스트를 실제 소자의 자원에 놓고 잇는 것. `nextpnr`. 여기서 진짜
주파수가 나온다.

**LUT (Look-Up Table)**
FPGA 의 기본 논리 자원. 4입력 LUT 하나가 임의의 4입력 함수 하나.
**FPGA 에서 "면적" 은 보통 LUT 수다.**

**캐리 체인 (carry chain)**
FPGA 가 덧셈을 위해 따로 둔 빠른 전용 배선. 일반 LUT 보다 훨씬 빠르다.

**F_max**
설계가 돌 수 있는 최대 클럭 주파수. **레지스터-레지스터 경로**로 정해진다.

**타이밍 껍데기 (timing shell)**
입력과 출력을 레지스터로 감싼 껍데기 모듈. **이것 없이 잰 F_max 는
대개 거짓이다** — 도구가 레지스터 사이 경로만 재기 때문.

**임계 경로 (critical path)**
가장 느린 레지스터-레지스터 경로. F_max 를 정하는 그것.

**파이프라인 (pipeline)**
긴 조합 경로를 레지스터로 끊어 주파수를 올리는 것. 대가는 **지연 증가**.

**지연 (latency) / 처리량 (throughput)**
지연 = 한 입력이 나오기까지 클럭 수. 처리량 = 클럭당 몇 개.
**둘은 독립이다.** 지연 10, 처리량 1/clk 인 설계가 흔하다.

**back-pressure**
받는 쪽이 "지금은 못 받는다"고 알리는 것 (`ready` 를 내린다).
없으면 보내는 쪽이 매 클럭 보낼 수 있다.

**skid buffer**
back-pressure 를 쓸 때 조합 고리를 막기 위해 끼우는 레지스터 한 단.

**CDC (Clock Domain Crossing)**
다른 클럭 영역으로 신호를 넘기는 것. **시뮬에서 통과하고 실리콘에서
실패하는 버그의 최대 원천.** 직접 만들지 말고 검증된 것을 쓴다.

**래치 (latch)**
클럭 없이 값을 유지하는 소자. 조합 블록이 갈래를 안 채우면 **사고로**
생긴다. 거의 항상 실수다.

**포화 (saturate) / 자름 (wrap)**
넘칠 때 한계값으로 붙잡느냐(포화), 감아 도느냐(wrap).
wrap 은 **큰 양수를 큰 음수로 뒤집는다.**

**고정소수점 Q 표기**
`Q1.7` = 부호 1비트 + 정수 1비트 + 소수 7비트. 하드웨어는 소수점을
모른다 — 소수점은 **우리 머릿속에만** 있고 비트는 그냥 정수다.

## 흐름과 사업

**front-end / back-end** — **두 가지 뜻이 있다**
* *신호 사슬*: 앞단(아날로그) / 뒷단(디지털)
* *설계 흐름*: 앞단(RTL·검증) / 뒷단(배치배선·타이밍·GDSII)
누가 말하면 **어느 쪽인지 물어본다.**

**HLS (High-Level Synthesis)**
C/C++ → RTL 자동 생성. 이 매뉴얼은 08단계까지 안 쓴다.

**IP (Intellectual Property)**
재사용하도록 만든 회로 블록. 파는 물건.

**넷리스트 납품 / 소스 납품**
합성된 것만 주느냐, RTL 소스를 주느냐.

**NRE (Non-Recurring Engineering)**
한 번 드는 개발비. 용역 대금이 대개 이것.

**로열티**
고객 제품 출하량에 비례해 받는 돈.

**DFT / 스캔 (scan)**
제조 후 칩을 시험하기 위한 회로. 대개 통합하는 쪽이 넣지만,
**스캔에 친화적인 RTL** 을 써야 한다 (래치 금지, 내가 만든 게이티드 클럭 금지).

**IP-XACT**
IP 의 인터페이스·레지스터를 기계가 읽는 XML 규격. 통합 자동화에 쓰인다.

**사인오프 (sign-off)**
"이제 만들어도 된다" 고 최종 확인하는 것. ASIC 은 상용 도구가 필요하다.
