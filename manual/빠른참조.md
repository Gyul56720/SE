## 나와야 하는 것

| 단계 | 통과 |
|---|---|
| 모델 | `출력이 여러 가지인가: 예` |
| lint | 경고 **0** |
| 회귀 | `틀림 0` |
| **자해검사** | **`틀림 1` 이상** ← 없으면 위 줄 무의미 |
| 합성 | 플립플롭 수가 **세어서 맞음** |
| 주파수 | 껍데기 씌우고 잰 값, 씨앗 3개 |
| 문서 | `grep -c TODO` = **0** |

## 다섯 함정 (전부 실측)

| 증상 | 원인 |
|---|---|
| 스크립트가 한 줄도 안 돈다 | 셸 변수명에 한글 |
| 전부 틀리거나 전부 안 나온다 | **리셋 극성** |
| **첫 줄만** 틀린다 | 리셋 해제 후 여유 클럭 부족 |
| 음수에서만 틀린다 | `signed` 누락, `{}` 는 unsigned |
| 주파수가 10배 높다 | 타이밍 껍데기 없음 |

## 절대 규칙 셋

1. **자해검사 없는 `틀림 0` 은 정보가 아니다**
2. **껍데기 없이 잰 주파수는 적지 않는다**
3. **"확인하지 못한 것" 절이 비면 문서가 거짓말이다**
