## 무엇을 깔고, 각각 왜 필요한가

이 다섯이 전부다. **전부 무료이고 라이선스 서버가 없다.**
1인 하우스가 상용 EDA 를 못 사는 것이 문제가 아니라, 상용 EDA 없이도
여기까지 간다는 것이 요점이다.

| 도구 | 하는 일 | 언제 쓰나 | 없으면 |
|---|---|---|---|
| **verilator** | lint (문법·폭·미사용 신호) | RTL 고칠 때마다, 1초 | 폭 오류를 시뮬에서 찾게 된다 (100배 느리다) |
| **iverilog** | 시뮬레이션 | 검증할 때마다 | 검증을 못 한다 |
| **yosys** | 합성 (RTL → 게이트) | 면적 잴 때 | 면적을 모른다 |
| **nextpnr-ice40** | 배치·배선, 진짜 Fmax | 주파수 잴 때 | 주파수를 모른다 |
| **g++** | C++ 골든모델 | 모델 만들 때 | 독립 정답이 없다 |

> 위 두 줄은 이 컨테이너에서 실제로 돌려 확인한 값이다. `SB_DFF` 는
> `y` 레지스터 하나, `SB_LUT4` 는 `a & b` 하나다. 수가 다르면 뭔가 다른
> 것을 합성한 것이다.

`bambu` (HLS, C++ → RTL) 는 **선택**이다. 08단계까지 한 번도 안 쓴다.
쓰고 싶어지면 그때 [10_막힐때.md](10_막힐때.md) 의 HLS 절을 본다.

## 2. 깔렸는지 **확인**한다

깔았다고 믿지 않는다. 버전을 찍어 본다.

```bash
for t in verilator iverilog yosys nextpnr-ice40 g++ python3; do
  printf '%-16s ' "$t"
  command -v "$t" >/dev/null 2>&1 && ($t --version 2>&1 | head -1) || echo "없음"
done
```

이렇게 나오면 된다 (버전 숫자는 달라도 된다):

```
verilator        Verilator 5.020 2024-01-01
iverilog         (iverilog 는 -V 를 쓴다 -- 아래 참고)
yosys            Yosys 0.33
nextpnr-ice40    "nextpnr-ice40" -- Version 0.6
g++              g++ (Debian 13.x)
python3          Python 3.11.x
```

> **함정**: `iverilog --version` 은 `invalid option` 을 낸다. `iverilog -V` 가 맞다.
> 도구마다 버전 플래그가 다르다. "없음"이 뜨면 플래그부터 의심한다.

## 3. 진짜로 도는지 확인한다 — 버전이 찍히는 것과 도는 것은 다르다

설치 확인의 고전적 실패는 **버전만 보고 넘어가는 것**이다.
아주 작은 회로를 실제로 통과시켜 본다. 30초 걸린다.

```bash
mkdir -p /tmp/설치확인 && cd /tmp/설치확인

cat > t.v <<'EOF'
module t (input clk, input a, input b, output reg y);
    always @(posedge clk) y <= a & b;
endmodule
EOF

cat > t_tb.v <<'EOF'
`timescale 1ns/1ps
module tb;
    reg clk=0, a=0, b=0; wire y;
    t dut(.clk(clk), .a(a), .b(b), .y(y));
    always #5 clk = ~clk;
    integer i, bad;
    initial begin
        bad = 0;
        for (i = 0; i < 4; i = i + 1) begin
            @(negedge clk); a = i[1]; b = i[0];
            @(posedge clk); #1;
            if (y !== (a & b)) bad = bad + 1;
        end
        $display("잰것 4  틀림 %0d", bad);
        $finish;
    end
endmodule
EOF

echo "--- 1. lint ---"
verilator --lint-only -Wall --top-module t t.v && echo "lint 통과 (경고 없음)"

echo "--- 2. 시뮬 ---"
iverilog -g2012 -o a.out t_tb.v t.v && vvp a.out

echo "--- 3. 합성 ---"
yosys -p "read_verilog -sv t.v; synth_ice40 -top t -json t.json; stat" 2>&1 \
  | awk '/=== t ===/{g=1} g' | grep -E "Number of cells|SB_" | head -4

echo "--- 4. 배치배선 ---"
nextpnr-ice40 --hx8k --package ct256 --json t.json \
              --pcf-allow-unconstrained --placer heap --freq 100 2>&1 \
  | grep -E "ICESTORM_LC: +[0-9]"

echo "--- 5. C++ ---"
printf '#include <stdio.h>\nint main(){printf("c++ ok\\n");return 0;}\n' > t.cpp
g++ -O2 -o tc t.cpp && ./tc
```

## 통과 기준

위를 돌렸을 때 **이 다섯 줄이 다 나와야** 한다.

| 단계 | 나와야 하는 것 |
|---|---|
| 1. lint | `lint 통과 (경고 없음)` |
| 2. 시뮬 | `잰것 4  틀림 0` |
| 3. 합성 | `SB_DFF 1` 과 `SB_LUT4 1` (정확히 이 두 줄) |
| 4. 배치배선 | `ICESTORM_LC:     3/ 7680     0%` |
| 5. C++ | `c++ ok` |

그리고:

```bash
cd /home/user/SE && bash manual/지금어디.sh
```

→ **0단계가 전부 `[o]`**.

## 막히면

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| `nextpnr-ice40: command not found` | 배포판에 패키지가 없다 | OSS CAD Suite 를 쓴다 (위 1절) |
| `ERROR: Unable to find a placement location` | 핀이 모자라다 | `--hx8k --package ct256` 을 쓴다. `--up5k --package sg48` 은 I/O 가 39개뿐이다 |
| `syntax error` in `always_ff` | SystemVerilog 가 꺼져 있다 | `iverilog` 에 **`-g2012`** 를 붙인다 |
| `Max frequency` 줄이 안 나온다 | **레지스터-레지스터 경로가 없다** | 이 확인용 회로에서는 **정상이고 나오지 않는 것이 맞다**. 플립플롭이 하나뿐이라 그 사이를 잇는 경로가 없기 때문이다. nextpnr 은 레지스터 사이 경로만 잰다. 그래서 07단계에서 **타이밍 껍데기**를 씌운다 |
| yosys 가 아무 수도 안 찍는다 | `-q` 를 붙였다 | **`-q` 를 빼라.** `stat` 출력까지 삼킨다 |
| `sudo` 가 없다 | 권한이 없는 기계다 | OSS CAD Suite (권한 불필요) |
