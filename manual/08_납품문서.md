## 문서가 RTL 만큼 중요한 이유

고객이 IP 를 평가할 때 **RTL 을 먼저 읽지 않는다.** 데이터시트를 읽고,
자기 칩에 들어가는지 판단하고, 그 다음에 코드를 본다.

그리고 1인 하우스에는 실질적인 이유가 하나 더 있다:

> **전화 한 통이 이익을 먹는다.**
>
> 100만원짜리 IP 를 팔았는데 고객이 "리셋을 몇 클럭 넣나요" 로 세 번
> 연락하면, 그 시간에 다음 제품을 못 만든다. 대기업은 지원 인력이 있고
> 1인 하우스는 없다. **문서가 곧 지원 인력이다.**

---

## 문서 셋과, 각각이 막는 질문

| 문서 | 답하는 질문 | 없으면 |
|---|---|---|
| **DATASHEET.md** | 이게 뭐고, 얼마나 크고 빠른가? | 값을 못 매긴다 |
| **INTEGRATION.md** | 내 칩에 어떻게 붙이나? | 전화가 온다 |
| **KNOWN_ISSUES.md** | 뭐가 안 되나? | 고객이 **스스로** 발견한다 |

### 세 번째를 빠뜨리고 싶어진다 — 그것이 정확히 실수다

안 되는 것을 적으면 안 팔릴 것 같다. 반대다.

* 내가 적으면: "범위를 아는 사람이구나"
* 고객이 발견하면: "숨겼구나" → **그 뒤로 안 산다**

그리고 1인 하우스는 신뢰가 유일한 자산이다. 영업사원도, 브랜드도,
레퍼런스 고객도 없다. **한 번 걸리면 끝이다.**

### 2. **잰 수만** 옮겨 적는다

데이터시트의 모든 수는 `work/합성결과.txt` 와 `work/검증결과.txt` 에서 온다.
**짐작한 수를 적지 않는다.** 한 줄이라도 거짓이면 문서 전체를 못 믿는다.

각 수에 **조건**을 같이 적는다. 조건 없는 수는 쓸 수 없다.

### 3. **확인 수준**을 갈라 적는다

이것이 신뢰를 만드는 절이다. 확인한 것과 못 한 것을 나란히 적는다.

```markdown
## 확인 수준

**전수로 확인한 것**
- 입력 공간 2^32 가지 전부에서 골든모델과 비트까지 일치 (29.7초)
- 단일 비트 오류 180가지 전부 정정

**표본으로 확인한 것**
- 무작위 벡터 2000개, 씨앗 1·7·99

**확인하지 못한 것**
- IEEE 802.3 Clause 36 정규 표와 바이트까지 같은가
  → 문서를 못 구했다. 상호운용 시험 전에 대조할 것.
     바꿀 곳은 `block.v` 의 case 문 두 개뿐이다.
- 온도·전압 변화에 따른 타이밍 (상용 STA 도구가 필요)
```

**"확인하지 못한 것" 절이 비어 있으면 그 문서는 거짓말이다.**
확인 못 한 것은 언제나 있다.

### 4. 통합 가이드는 **복사해 붙일 코드**를 넣는다

설명이 아니라 코드다. 고객이 읽고 해석해야 하면 전화가 온다.

````markdown
## 붙이는 법

```verilog
my_block #(.IN_W(8)) u_blk (
    .clk       (sys_clk),      // 50 MHz 이하
    .rst       (sys_rst),      // 동기, active HIGH, 최소 4클럭
    .in_valid  (adc_valid),
    .in_data   (adc_data),     // signed [7:0]
    .out_valid (eq_valid),
    .out_data  (eq_data)
);
```

리셋 시퀀스:
```verilog
initial begin
    sys_rst = 1'b1;
    repeat (4) @(posedge sys_clk);   // 최소 4클럭
    sys_rst = 1'b0;
end
```
````

### 6. **빈 디렉터리에서 풀어 돌려 본다**

가장 흔한 납품 사고는 **커밋/복사 안 된 파일**이다. 내 작업 디렉터리에는
있으니 검사가 통과하는데, 고객이 받는 것은 묶음뿐이다.

```bash
cd /tmp && rm -rf 납품시험 && mkdir 납품시험 && cd 납품시험
tar xzf /home/user/SE/work/<블록이름>_v0.1.tar.gz && cd 납품
g++ -O2 -o golden model/golden.cpp && ./golden vec 400 1 > tb/vec.txt
cd tb && iverilog -g2012 -o s.out *_tb.v ../rtl/*.v && vvp s.out
```

**여기서 돌지 않으면 납품물이 아니다.** 이 단계가 "내 기계에서는 되는데요"
를 원천에서 막는다.

## 통과 기준

| 확인 | 기준 |
|---|---|
| TODO 개수 | 세 문서 모두 **0** |
| 데이터시트의 수 | 전부 `합성결과.txt`/`검증결과.txt` 에서 왔다 |
| 확인 수준 절 | "확인하지 못한 것" 이 **비어 있지 않다** |
| 통합 가이드 | 복사해 붙일 인스턴스 코드가 있다 |
| 알려진 문제 | 스펙 12절(범위 밖)이 전부 옮겨졌다 |
| **묶음 시험** | 빈 디렉터리에서 풀어 `틀림 0` |

```bash
grep -c TODO work/DATASHEET.md work/INTEGRATION.md work/KNOWN_ISSUES.md
cd /home/user/SE && bash manual/지금어디.sh   # 7단계 전부 [o]
```
