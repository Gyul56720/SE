# eval -- 흩어진 면역계를 한 러너로, 후퇴를 원장으로

```
게이트 · 답 회귀 · lol기준선 (빠름)   ──┐
검사전부 · 래칫 (느림, --전부)        ──┼──> ledger.jsonl ──> 직전과 견줌 ──> **후퇴**
                                      ──┘      (판정 원장)      초록→빨강이 제일 큰 소식
```

## 왜 있나

면역계가 흩어져 있으면 어느 것이 언제 빨간불이 됐는지 아무도 모른다 -- 낡은 메모가
"mathdrift 가 빨갛다" 고 가리키는 동안 진짜 빨간 것은 law_hwp 였다(CLAUDE.md 실측
2026-09-09). 그래서 결과를 원장에 쌓고 **직전과 견줘** 말한다: 후퇴(초록→빨강) ·
회복 · 여전. capability_ratchet 이 탐색 능력에 하는 일을 갈래 전체로 넓힌 것이다
(래칫 자신도 한 갈래로 들어와 있다 -- 두 벌이 아니라 포함이다).

## 판정 규칙 -- 끝값 관례 그대로

| 끝값 | 판정 | |
|---|---|---|
| 0 | 초록 | |
| 3 | **못돌림** | 재료·키·의존성이 없어 **안 잰 것**. 초록이 아니다 -- 검사하지 않은 초록불이 검사한 빨간불보다 나쁘다 |
| 그 외 | 빨강 | 꼬리(로그 끝)를 원장에 같이 적는다. 기억으로 적지 않는다 |

## 답 회귀 (`answers.py` + `questions.jsonl`) -- 새로 지은 하나

에이전트 답의 **약속된(결정적) 표면**을 잰다: 고정 명령은 같은 말에 같은 일 ·
모르는 말은 에이전트로 · 주입은 거절 · 간추린 기억은 계속 찾힘. 이 표면은
dispatch/graph 를 고치다 소리 없이 깨지고, 화면에서는 '봇이 멍청해졌다' 로만 보인다.
(물음, 기대) 쌍은 원장이라 회귀가 생길 때마다 행 하나로 는다. 기대 꼴은 셋으로
닫혀 있다(고정명령 · 에이전트로 · 색인). 모델이 짓는 부분은 여기서 안 잰다 --
그 심판(lol/score · law/bench · verify.대조)을 두 벌 만들지 않는다.

## 쓰기

```bash
python3 eval/run.py               # 빠른 갈래 (게이트 · 답 · lol기준선)
python3 eval/run.py --전부        # + 검사전부(6분+) · 래칫
python3 eval/run.py --보고만      # 갈래별 마지막 판정
python3 eval/answers.py           # 답 회귀만
python3 tests/test_eval.py        # 배선 검사 (가짜 갈래로 후퇴/회복까지)
```

디스코드: `!평가` (빠른 갈래) · `!평가 전부` (백그라운드, pgrep 로 확인 뒤에만
"시작했다" 고 말한다) · `!평가 상태`. 밤에 돌리려면 CLAUDE.md 의 setsid 패턴으로
`python3 eval/run.py --전부` 를 걸면 된다.
