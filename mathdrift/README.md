# mathdrift — 후보가 아니라 **탐색공간**을 낳는다

목표: 행렬곱 복잡도(b=3, m=22)의 **새 형식화**를 찾는다. 답을 찾는 것이 아니라
**답을 찾을 수 있는 공간**을 찾는다.

```
씨앗 공간 ──> 연산자 하나 ──> 새 공간 ──> 원장
     ↑                                      │
     └──────────  다음 세대의 부모  ─────────┘
```

## 왜 한 층 올렸나

b=3 m=22 는 같은 공간(실수 CP 분해)을 CP-ALS · 무작위 재시작 · 강화학습 · flip graph 로
여러 번 훑어 소진됐다. **고정된 공간 안의 탐색은 정의상 최적화이고, 최적화는 자기가 받은
형식화를 떠나지 못한다.**

역사적으로 이 문제를 움직인 것은 전부 공간을 갈아탄 것이었다:

| 누가 | 무엇에서 무엇으로 |
|---|---|
| Strassen 1969 | 산술회로 → 텐서 랭크 |
| Schönhage 1981 | 랭크 → **경계 랭크** (ε 허용) |
| Coppersmith–Winograd | 정확 분해 → 점근 퇴화 |
| Cohn–Umans 2003 | 텐서 → **군대수 매장** (연속 탐색이 이산 군론 문제가 됨) |

넷 다 사람이 냈다. **기계가 형식화를 낸 사례는 아직 없다** — FunSearch도 AlphaTensor도
주어진 공간 **안에서** 찾았다. 그래서 이건 미답 영역이고, 실패해도 이상하지 않다.

## 공간은 틀릴 수 없다 — 쓸모없을 뿐이다

| 틀렸을 때 | |
|---|---|
| 틀린 **정리** | 독이다. 원장에 들어가면 그 뒤가 전부 오염된다 |
| 틀린 **공간** | 그냥 빈 공간. 탐색해봐야 아무것도 안 나올 뿐 |

그래서 **발산 단계에는 게이트를 안 건다.** 엄밀성은 나중에 요구한다. `novel/DRIFT.md` 의
첫 규칙 그대로 — *과잉 기각은 글 자체를 없앤다.*

## 인과성은 검사하지 않는다 — 구성으로 보장한다

`mathgen` 의 거꾸로 만들기와 같은 수다(거기서는 답 F 를 먼저 골라 f = F' 를 문제로 내니
정답이 구성상 확실했다).

```
새 공간 = 연산자(원장에 이미 있는 공간)
```

모델에게 "공간을 발명하라" 고 묻지 않는다. **"여기 공간 S 가 있다, 여기 *경계화* 를 걸어라,
무엇이 되나"** 라고 묻는다. 부모는 항상 원장에 있고 연산자는 고정 목록에서 나오므로
계보 칸은 비거나 지어낼 수가 없다. `space.add()` 가 원장에 없는 부모를 거절한다 —
내용을 판정해서가 아니라 **계보가 끊긴 것을 원장이 못 받게** 하는 것이다.

한 번에 연산자 **하나**만 건다 (`mathgen` 이 Evol-Instruct 에서 가져온 규칙). 멀리 있는
공간에는 여러 세대를 거쳐서만 간다.

## "완전히 다르면 안 된다" 를 재는 법

`novel/diffusion.py` 의 두 계수를 공간 층으로 옮겼다.

| | 0 이면 |
|---|---|
| **새것** (부모에 없던 구조) | 이름만 바꾼 것 |
| **물려받음** (부모에서 그대로 온 것) | 인과성 없음 — 남의 공간 |

둘 다 있어야 확산이다. 그리고 원문의 규율 그대로 — **재서 숫자를 돌려주되 죽이지 않는다.**

한 낱말 겹친 것은 물려받은 것이 아니다(실측: 아무 상관 없는 "날씨/기압" 도 "연속" 하나로
확산으로 셌다). 그래서 바닥을 둘 뒀다 — 겹친 낱말 2개 이상, 자식 어휘의 15% 이상.

## 칸

전부 비어도 받는다. 빈 칸은 나중에 채울 것이지 탈락 사유가 아니다.

| 칸 | 묻는 것 |
|---|---|
| `이름` | 이 공간을 한 마디로 |
| `점` | 이 공간의 한 점은 무엇인가 |
| `표기` | 점을 어떻게 적나 |
| `되사상` | 점이 원래의 행렬곱 스킴으로 어떻게 돌아가나 |
| `크기` | 유한/이산/연속. 대략 얼마나 큰가 |
| `왜` | 왜 그럴듯한가 (사람이 읽는 칸. 확산 계산에서는 뺀다) |

`되사상` 만 특별하다 — 비면 나중에 검증이 불가능하므로 **기각은 안 하되 등급을
`검증불가` 로 적어 둔다.** 다음 세대의 부모로는 여전히 쓴다.

## 왜 산문이 아니라 칸인가

만 개를 자유 산문으로 뽑아 두면 검증할 때 만 번을 다시 파싱해야 한다 — 생성 비용만큼이
다시 든다. `novel/flow.py` 와 같은 배치다: **모델은 자유롭게 쓰고, 받는 것은 칸이다.**

## 쓰는 법

```bash
python3 mathdrift/spread.py --n 300         # Gemini 로 300개 낳는다
python3 mathdrift/spread.py --n 3 --dry     # 호출 없이 프롬프트만 본다
python3 mathdrift/spread.py --show          # 원장 · 확산 몫 · 연산자 쓰임새
python3 mathdrift/spread.py --lineage S17   # 씨앗까지의 사슬
python3 tests/test_mathdrift.py             # 배선 검사 (LLM·네트워크 불필요)
```

모델 배치는 `CLAUDE.md` 그대로. 발산은 호출 수가 전부이므로 **Gemini** 다.
에이전트 세션에서 직접 공간을 지어내 원장에 넣지 않는다 — 파이프라인이 만든 것이
아니면 발산율도 계보도 거짓이 된다.

## 지금 상태

씨앗 하나(`S1` 텐서 랭크)뿐이다. **발산은 아직 0회** — `GEMINI_API_KEY` 가 있는 곳에서
돌려야 한다. 배선은 가짜 모델로 확인했다(`tests/test_mathdrift.py`, 21개 항목 통과).

## 아직 없는 것 — 4축 심판

다음 커밋이다. 발산과 **별도의 배치**로 돌린다.

| 축 | 묻는 것 | 있는 것 |
|---|---|---|
| ① 재현 | 새 형식화가 Strassen(7)·Laderman(23)을 표현하는가 | `mathmetics/matrix_exponent/benchmarks.json` 래칫이 그대로 이 축이다 |
| ② 비자명성 | 옛 공간과 동형이 아닌가 | 없음 |
| ③ 압축 | 탐색공간이 줄었나 (연속 → 이산이면 큰 승리) | 없음 |
| ④ 실행 가능 | 이 안의 후보를 채점할 수 있는가 | `verifier.py` 에 `verify_approx` 와 유한체 검산이 이미 있다 |

**심판을 먼저 짜지 않은 이유**: 모델이 실제로 어떤 종류의 공간을 내는지 봐야 4축을
어떻게 짜야 하는지 알 수 있다. 반대 순서로는 못 안다.

첫 시금석은 "새 형식화를 내라" 가 아니라 **"알려진 갈아타기 넷(경계화 · 매장 · 점근화 ·
표수 이동)을 파이프라인이 재발견하는가"** 다. 사람이 낸 답이 있으니 도달했는지 볼 수
있고, 재발견도 못 하면 새 것은 당연히 못 낸다. `novel/world_probe.py` 와 같은 자리다.

## 정직하게 남기는 한계

- **확산 두 계수는 대리값이다.** 낱말 집합으로 재므로, 같은 구조를 다른 낱말로 쓰면
  물려받음을 못 보고 그 반대도 있다. 제대로 재려면 두 공간 사이의 사상을 실제로 만들어야
  하고 그건 검증 단계의 일이다
- **통과한 형식화가 답을 주지 않는다.** 나오는 것은 새 미해결 문제다
- **밀레니엄급은 이 경로로 안 된다.** 형식적 증명이 필요하고 그건 다른 규모의 공사다
- 이 파이프라인이 낼 수 있는 최선은 *새 구성 · 새 하한 · 게재된 추측의 반례* 크기다
