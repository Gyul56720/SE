# 검증되지 않은 사실 단정 금지 및 실측 철저

사용자가 제시한 피드백: "일부(quota_state.json 경로, VM 경로)는 검증되지 않았거나 틀렸습니다. 앞으로 이런 식으로 '확인된 사실'처럼 제시되는 내용이 있으면 제가 직접 재검증하겠습니다 ->check". 추측이나 불확실한 사실을 단정적으로 서술하지 말고, 파일 존재 여부나 경로를 철저히 검증한 뒤에만 사실로 언급할 것.
