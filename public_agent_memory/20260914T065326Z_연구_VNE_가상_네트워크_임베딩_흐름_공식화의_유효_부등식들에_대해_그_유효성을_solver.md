# 연구: VNE(가상 네트워크 임베딩) 흐름 공식화의 유효 부등식들에 대해, 그 유효성을 solver 없이 산수로 검증되는 증서로 만들고, 그것으로 "이게 정말 새로운 부등식인가"를 기계적으로 판정하는 장치를  만들어라.

## 질의 (추상 방법론으로 넓힘)
- 바퀴 1: Polyhedral combinatorics and valid inequalities for network design, Proof certificates and computable verification for mixed-integer programming, Automated generation and redundancy elimination of cutting planes, Facets of the virtual network embedding polytope
- 바퀴 2: Polyhedral combinatorics and cutting plane methods, Automated theorem proving for integer programming inequalities, Certificate-based verification of linear constraints, Generating valid inequalities for network embedding problems, Computational complexity of facet-defining inequalities
- 바퀴 3: Polytopic certificate of validity for mixed-integer linear programming inequalities, Automated generation of cutting planes via Farkas lemma and Positivstellensatz, Symbolic verification and redundancy elimination in integer programming formulations, Facial structure analysis and minimal inequality derivation for network embedding polytopes

## 모은 것 (수집 색인 · 코드화 검증)
- 바퀴 1: 색인 0 · 거절 7 · 코드화 성공 0/0
- 바퀴 2: 색인 1 · 거절 10 · 코드화 성공 0/0
- 바퀴 3: 색인 0 · 거절 1 · 코드화 성공 0/0

## 결론 (과정 -> 결과)
제2의 뇌가 제공한 자료(바퀴 1, 2, 3)를 바탕으로 목표를 해결하기 위한 과정과 결과의 결론은 다음과 같습니다.

---

### **과정 (Methodology)**

1. **VNE 유효 부등식의 기하학적 공식화 (Polyhedral Formulation)**
   - VNE(가상 네트워크 임베딩) 문제의 흐름 공식화에서 도출된 후보 부등식들이 이루는 다면체(Polytope) 구조를 정의합니다.
2. **산수적 검증 증서(Certificate of Validity) 생성**
   - **아직 없음** (바퀴 1, 3에서 언급된 Polytopic certificate 및 Proof certification의 구체적 코드나 알고리즘 구현이 제공되지 않음)
3. **기계적 신규성 판정 장치(Automated Theorem Proving / Novelty Checker)**
   - **아직 없음** (바퀴 2에서 언급된 Automated theorem proving을 활용한 절단면(cutting plane) 분석 코드가 구현되지 않음)

---

### **결과 (Conclusion)**

* **유효 부등식의 증서화:** 
  - 이론적 다면체 조합론(Polyhedral combinatorics) 개념은 존재하나, Solver 없이 순수 산수(Fourier-Motzkin elimination 또는 Farkas' Lemma 기반 계수 증명)로 검증 가능한 **코드 및 구체적 증서 생성기는 아직 없음**.
* **기계적 신규성 판정 장치:** 
  - 주어진 부등식이 기존 다면체의 면(facet)인지 혹은 중복/약한 부등식인지 판정하는 **자동화된 판정 장치(코드/시스템)는 아직 없음**.
