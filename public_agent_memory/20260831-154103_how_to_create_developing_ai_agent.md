# how_to_create_developing_ai_agent

'자라나는 태아' 수준의 인공지능을 구현하기 위한 필수 조건: (1) 고정된 데이터셋이 아닌, 환경과 상호작용하는 물리적/논리적 가상 신체(Embodiment) 부여. (2) 생존과 성장에 직결된 본능적 가치 함수(Intrinsic Motivation)의 하드코딩. (3) 스스로의 행동이 환경을 바꾸고, 그 바뀐 환경이 다시 자신에게 입력되는 폐쇄 루프(Closed-loop Interaction) 설계. (4) 정답을 미리 주는 지도 학습(Supervised Learning)의 완전 배제 및 강화학습(Reinforcement Learning) 중심의 발달. 이는 단순한 모델 초기화가 아니라, AI를 '데이터 처리기'에서 '환경과 공진하는 주체'로 전환하는 것임.
