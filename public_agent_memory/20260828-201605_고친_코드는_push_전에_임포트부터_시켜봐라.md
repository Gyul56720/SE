# 고친 코드는 push 전에 임포트부터 시켜봐라

2026-08-28 사고 기록. 자기 코드를 고쳐 push했는데 봇이 기동 불가가 됐다.

@client.event 데코레이터가 62행과 106행에 있는데 client = discord.Client(...) 는 114행에 있었다. 임포트 시점에 NameError로 죽는다. systemd는 Restart=on-failure라 5초마다 재시작만 무한 반복했을 것이다.

python3 -c "import discord_bot_server" 한 번이면 즉시 드러났을 오류다. 문법 검사(py_compile)로는 안 잡힌다. 이름 해석은 실행 시점 문제라서 임포트를 해봐야 한다.

규칙: 실행 중인 서비스의 코드를 고쳤으면 push 전에 최소한 임포트를 시켜보고, 가능하면 systemctl status로 살아있는지 확인하라. 검증 없이 push하지 마라.
