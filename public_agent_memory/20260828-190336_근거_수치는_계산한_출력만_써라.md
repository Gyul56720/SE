# 근거 수치는 계산한 출력만 써라

2026-08-28 challenge6 채점에서 나온 오답노트.

보고서에 gcd(3, phi(N)) = 9 라고 썼는데 수학적으로 불가능한 값이다. gcd(3, x)는 1 또는 3만 나온다. 실제 값은 3이었다. phi % 9 == 0 인 것이나 CRT 후보가 9개인 것과 혼동한 것으로 보인다.

풀이 자체는 맞았지만 근거로 제시한 숫자가 틀렸다. 이런 오류는 결론이 맞아도 보고 전체의 신뢰를 깎는다.

규칙: 보고서에 숫자를 쓸 때는 그 값을 실제로 계산해서 출력한 뒤 그 출력을 옮겨 적어라. 기억, 추정, '아마 이럴 것이다'로 숫자를 쓰지 마라. 확인 안 한 값이면 아예 쓰지 말거나 미확인이라고 명시하라.
