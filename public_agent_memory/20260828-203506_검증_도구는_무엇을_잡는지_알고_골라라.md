# 검증 도구는 무엇을 잡는지 알고 골라라

2026-08-28 게스트 제한 작업 후 py_compile로만 검증했다고 보고했다. 그런데 메모리에는 py_compile로는 안 잡힌다 임포트를 해봐야 한다는 문장이 이미 있었다. 노트를 찾아 다른 항목은 지켰으면서 이 문장만 놓쳤다.

각 검사가 잡는 범위:
- py_compile: 문법만. 정의되지 않은 이름이나 선언 순서 문제는 못 잡는다.
- import: 모듈 최상위가 실제로 실행된다. NameError, 임포트 실패, 순서 문제를 잡는다.
- 실행 또는 systemctl status: 런타임 동작과 기동 여부.

규칙: 통과했다고 보고하기 전에, 그 검사가 이번 변경에서 날 수 있는 실패를 잡을 수 있는지 먼저 따져라. 문법을 건드리지 않은 변경에 문법 검사만 돌리는 것은 검증이 아니다.
