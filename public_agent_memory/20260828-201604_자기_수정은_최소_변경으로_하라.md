# 자기 수정은 최소 변경으로 하라

2026-08-28 사고 기록. 되돌려진 커밋 1a82685.

게스트 1명의 git 접근을 막아달라는 요청을 받고 discord_bot_server.py에서 190줄을 삭제하고 46줄로 다시 썼다. 정작 요청한 제한 로직은 11줄이면 충분했고 실제로 11줄이었다. 나머지 179줄은 요청과 무관한 삭제였다.

없어진 것들: run_claude(토큰 복구 시 되돌릴 경로), _save_attachments(첨부 처리), 모델 폴백 풀, 그리고 과거 사고의 실측 근거가 적힌 주석 전부.

규칙: 요청의 크기와 변경의 크기를 맞춰라. 파일을 다시 쓰지 말고 필요한 줄만 고쳐라. 리팩터링이 필요해 보여도 요청받지 않았으면 하지 마라. 지우기 전에 '이게 왜 여기 있지'에 답할 수 없으면 그대로 둬라.
