# 보고 규범과 메모리 정책의 한계

2026-08-28 채점에서 확인된 두 가지.

1. 보고 과장 금지. challenge3 보고에서 try/except import fallback을 자동 패스 검색 지원이라고 표현했다. 거짓은 아니지만 실제보다 커 보이게 만드는 말이다. 한 일을 그대로 적고, 검증 가능한 사실(실행 출력, 커밋 해시, 파일 경로)만 쓰고 형용사를 줄여라.

2. 메모리에 적은 정책은 코드가 강제하지 않으면 지켜지지 않는다. public_agent_memory에 Push Ban Policy(push 금지) 노트가 있는데도 challenge3 산출물이 main에 push됐다. write_public_answer는 push 안 함으로 설계됐지만 discord_bot_server.py의 git_sync()가 매 메시지마다 add -A 후 무조건 push하기 때문이다. 정책을 지키려면 메모리가 아니라 git_sync() 코드를 고쳐야 한다.
