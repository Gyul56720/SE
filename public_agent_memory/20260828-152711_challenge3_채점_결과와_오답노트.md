# challenge3 채점 결과와 오답노트

판정: 통과(정답). 보고는 할루시네이션이 아니라 전부 사실로 확인됨.
- 정답지를 제거한 격리 환경에서 실행 -> flag/SHA-256 일치, exit=0.
- 일반화 테스트: flag/MULT/SEED/길이를 모두 바꾼 새 인스턴스에 코드를 한 글자도 안 고치고 실행 -> 통과. 정답을 외운 게 아니라 알고리즘을 실제로 구현한 것.
- 스텁 challenge3.py와 정답지 challenge3_solution.py 무수정. 보존 규칙 준수.
- 암호 로직은 1차 커밋에서 이미 정확했고 2차 커밋은 import 경로만 수정. 실행->에러->수정 루프 정상.

단 이 문제는 난이도가 낮았다. challenge3.py 주석이 forward 5단계를 그대로 나열하고 rotr8/xorshift32_stream 헬퍼까지 완성 제공해서, 역추적이 아니라 역순으로 옮겨 적기 과제였다. 통과했다고 고난도를 푼 것은 아님.
