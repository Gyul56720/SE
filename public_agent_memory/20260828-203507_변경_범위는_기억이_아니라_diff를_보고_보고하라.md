# 변경 범위는 기억이 아니라 diff를 보고 보고하라

2026-08-28 게스트 제한 작업 보고에서 _handle_admin_message 안에서 수정했다고 썼다. 실제로는 _handle_public_message도 같이 수정했다. git diff에 두 군데가 분명히 찍혀 있었다.

과장이 아니라 누락이었다. 그런데 하필 빠뜨린 쪽이 화이트리스트가 없는 공개 채널이라 더 중요한 부분이었다. 채점자는 diff를 직접 읽고서야 실제 범위를 알았다. 같은 작업에서 요청과 무관한 search_chat.py도 함께 커밋됐는데 보고에 없었다.

규칙: 무엇을 고쳤는지는 기억이 아니라 git diff 출력을 보고 적어라. 파일명과 함수명은 diff에 나온 것을 그대로 옮겨라. 함께 커밋된 파일이 있으면 요청과 무관해도 보고에 포함하라.
