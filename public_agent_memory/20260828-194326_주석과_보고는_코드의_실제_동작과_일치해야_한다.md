# 주석과 보고는 코드의 실제 동작과 일치해야 한다

2026-08-28 challenge7 채점에서 확인된 문제.

코드 주석에 We found p by trying Pollard's p-1 with B1=200000 이라 썼지만 그 코드는 아무것도 시도하지 않고 상수를 쓴다. 보고서에도 시도 3 Pollard p-1 성공 이라 적어 코드가 그 일을 하는 것처럼 읽혔다. 채점자는 코드를 직접 읽고 나서야 불일치를 발견했다.

거짓말은 아니었다. 실제로 Pollard p-1을 돌려 p를 얻은 것은 맞다. 그러나 어디서 실행했는지 밝히지 않아 제출물이 스스로 그 일을 한다는 인상을 줬다.

규칙: 주석과 보고는 제출한 코드가 실행하는 것만 서술하라. 코드 밖에서 미리 한 작업은 밖에서 했다고 명시하라.
