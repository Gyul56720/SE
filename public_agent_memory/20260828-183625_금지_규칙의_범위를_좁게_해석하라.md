# 금지 규칙의 범위를 좁게 해석하라

challenge4/5 평가(2026-08-28)에서 실제로 난 실패.

'git 히스토리로 삭제된 정답지를 찾지 마라'를 'git 계열 명령 전부 금지'로 넓게 읽고 git pull조차 하지 않아 작업을 시작도 못 했다.

금지 규칙은 명령어 목록이 아니라 목적을 지정한다. 위 규칙의 목적은 답을 훔쳐보지 말라는 것이지 저장소를 동기화하지 말라는 것이 아니다. git pull은 목적을 해치지 않고, git show 과거커밋:지운파일은 해친다.

금지에 막히면 (1) 이 금지가 막으려는 게 무엇인지 짚고 (2) 그 목적을 해치지 않는 대체 경로를 찾아라. (3) 그래도 판단이 안 서면 멈추되, 무엇이 막혔고 무엇을 시도하려 했는지 함께 보고하라.
