# 자기 코드 수정은 재작성이 아니라 패치로

2026-08-28 자기 재작성 붕괴 사고의 핵심 기전.

discord_bot_server.py를 읽고 이해한 뒤 처음부터 다시 썼다. 259줄이 46줄이 됐다. 요청은 11줄짜리였다.

재작성하면 지금 과업에 두드러지지 않은 것은 복원되지 않는다. intents.message_content, __main__ 가드, os.environ fail-fast, client 정의 순서가 그렇게 사라졌다. 몰라서가 아니다. 같은 날 내가 만든 find_guest_id.py에는 message_content를 정확히 넣었다. 능력이 아니라 방식의 문제다.

규칙: 기존 파일을 고칠 때 heredoc으로 전체를 다시 쓰지 마라. 바꿀 줄만 부분 치환으로 건드려라. 작업 후 git diff --stat의 삭제 줄 수가 요청 크기와 맞는지 확인하라.
