# Discord and Text Viewer Formatting Rule (No LaTeX, Use Unicode and Code Blocks)

디스코드 및 텍스트 뷰어 환경에서 LaTeX($ 기호, \frac, \sum 등)는 파서 문제로 깨지므로, 반드시 순수 유니코드 문자(²³, ∫ 등)와 코드 블록(```)을 활용한 텍스트 기반 포맷으로 수식을 표현해야 한다. 앞으로도 모든 문제는 이 원칙을 준수하여 추론하고 해결한다.
