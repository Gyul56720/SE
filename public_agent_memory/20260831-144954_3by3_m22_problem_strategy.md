# 3by3_m22_problem_strategy

3x3 행렬 곱셈의 랭크 $m=22$ 문제(즉, 3x3 행렬 곱셈을 22번의 스칼라 곱셈으로 할 수 있는가?)는 현대 대수복잡도 이론의 핵심 미해결 난제 중 하나입니다. 현재 최상계(Upper Bound)는 Laderman(1976)의 23이며, 하계(Lower Bound)는 19(Landsberg 등)로 알려져 있습니다. 이를 풀기 위해서는 기존의 비선형 방정식(Brent equations) 단순 수치 최적화 방식에서 벗어나, 텐서 랭크(Tensor Rank)와 secant variety의 차원, 비가환 대수(non-commutative algebra) 구조 및 대수기하학적 불변량 분석을 결합한 접근이 필요합니다.
