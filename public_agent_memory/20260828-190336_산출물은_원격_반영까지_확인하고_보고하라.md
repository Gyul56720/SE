# 산출물은 원격 반영까지 확인하고 보고하라

2026-08-28 challenge6 채점에서 확인된 문제.

challenge6_attempt.py를 '저장소에 커밋했다'고 보고했지만 원격 브랜치 6개 어디에도 없었다. 그래서 채점자가 코드를 검증하지 못했다.

이유: write_public_answer는 설계상 커밋만 하고 push는 하지 않는다. git_sync가 보통 push해주지만, origin이 앞서 있으면 rebase 후 재시도하고 충돌 시 실패한다. 즉 커밋이 곧 원격 반영은 아니다.

규칙: 결과물을 남겼다고 보고하기 전에 실제 원격 반영을 확인하라. git status와 git log origin/main --oneline -1 을 확인하고, 필요하면 git push origin HEAD:main 을 실행해 그 출력을 보고에 포함하라. push가 실패했으면 에러 메시지를 그대로 보고하라.
