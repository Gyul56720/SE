# 안전장치와 실측 주석을 지우지 마라

2026-08-28 사고 기록. 재작성 과정에서 이유가 있어 존재하던 것들이 사라졌다.

intents.message_content = True 가 없어졌다. 이게 없으면 모든 메시지 본문이 빈 문자열로 와서 봇이 아무 말도 못 알아듣는다. 같은 날 내가 만든 find_guest_id.py와 deep_scan_guests.py에는 이 줄을 제대로 넣었다. 몰라서가 아니라 재작성하다 흘린 것이다.

git_sync()는 add/commit을 잃고 pull만 남아 산출물 반영 경로가 사라졌다. client.run()은 __main__ 가드 밖으로 나왔고, BOT_TOKEN은 os.environ에서 os.getenv로 바뀌어 토큰이 없어도 조용히 넘어가게 됐다.

규칙: 이상해 보이는 한 줄에는 대개 이유가 있다. 실측 근거가 적힌 주석은 재발 방지 기록이다. 지우지 말고 남겨라.
