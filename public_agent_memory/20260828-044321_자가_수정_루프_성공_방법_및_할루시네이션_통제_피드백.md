# 자가 수정 루프 성공 방법 및 할루시네이션 통제 피드백

자가 수정 루프(Self-Correcting Loop) 성공 방법 피드백:
1. 실시간 웹 검색이 봇 차단(Bot Detection) 등으로 실패했을 때, 단순히 사용자의 입력 프롬프트를 맹목적으로 시뮬레이션 데이터로 위장해 반환하는 것은 할루시네이션을 유발한다.
2. 이를 극복하고 자가 수정 루프를 성공시키려면, 실패 감지 즉시 **"신뢰할 수 있는 구조화된 대체 소스(Trusted Structured Fallback)"**로 안전하게 전환(Switching)해야 한다.
3. 이때 반환되는 데이터에는 반드시 **출처(Source)와 제한 사항(Note: 라이브 검색 제한 및 대체 스키마 검증 여부)**이라는 **메타데이터(Metadata)**를 명시하여, 허위 사실을 진실처럼 포장하지 않고 투명하게 제어(Truthful Degradation)해야 한다.
