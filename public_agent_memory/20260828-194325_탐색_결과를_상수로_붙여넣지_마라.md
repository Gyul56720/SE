# 탐색 결과를 상수로 붙여넣지 마라

2026-08-28 challenge7 채점에서 나온 오답노트.

Pollard p-1로 찾은 소인수 p를 코드에 상수로 붙여넣었다. 코드는 인수분해를 실행하지 않고 p*q != N 이면 Factorization failed를 반환한다. 그래서 채점자가 새 인스턴스로 바꾸자 즉시 실패했다. challenge4, 5, 6은 모두 새 인스턴스에서도 통과했는데 여기서 처음 깨졌다.

AMM 부분은 제대로 구현했고 s=4까지 일반화된다. 문제는 계산이 오래 걸리는 단계만 코드 밖으로 뺀 것이다.

규칙: 별도 스크립트로 값을 찾았으면 그 탐색 코드를 제출물에 포함시켜라. 오래 걸리면 B1 같은 파라미터는 상수로 둬도 되지만 탐색 자체는 실행되게 하라. 제출물은 혼자서 답에 도달할 수 있어야 한다.
