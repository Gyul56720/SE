# 조문 원장 -- 심판이 대조하는 자리

여기에 조문 원문이 없으면 인용 관문(L001·L002·L003)은 아무것도 검사하지 못한다.
그때 보고서는 통과라고 하지 않고 **미검증 N건**이라고 적는다. 그 숫자가 지금 이 시스템이
못 보고 있는 양이다.

## 받아서 넣는 법 (권장)

    export LAW_API_OC=발급받은키        # 또는 .env 에 LAW_API_OC=
    python3 law/fetch.py 형법 민법
    python3 law/fetch.py 형법 --list    # 무엇이 검색되는지 먼저 본다

`law/fetch.py` 가 법제처 국가법령정보 공동활용 OPEN API 로 받아 이 디렉터리에 저장한다.
받은 것에 조문 머리(`제N조`)가 하나도 없으면 **저장하지 않는다** -- 오류 XML 이나 로그인
페이지가 원장에 들어가면 심판이 그것을 정답으로 삼는다. 저장한 뒤에는 원장으로 다시 읽어
조문이 몇 개 잡히는지 보고한다(받는 것과 파싱되는 것은 다른 일이다).

인증키(OC)는 open.law.go.kr 에서 무료로 발급받는다: 로그인 -> 왼쪽 'OPEN API 신청' ->
'API인증키관리' -> 현재 API인증키(OC).

## 손으로 넣는 법

파일 하나가 법령 하나다. 파일 이름(확장자 뗀 것)이 곧 법령명이 된다.

    law/corpus/형법.txt
    law/corpus/민법.txt
    law/corpus/도시 및 주거환경정비법.txt

내용은 [국가법령정보센터](https://www.law.go.kr)에서 조문을 복사해 붙이면 된다.
가공하지 않아도 된다 -- `제N조` 가 나오는 자리에서 알아서 끊는다.

    # 형법 (시행 2026-01-01)          <- '#' 로 시작하는 줄은 버린다
    제355조(횡령, 배임) ①타인의 재물을 보관하는 자가 ...
    ②전항의 방법으로 ...
    제356조(업무상의 횡령과 배임) 업무상의 임무에 위배하여 전조의 죄를 범한 자는
    10년 이하의 징역 또는 3천만원 이하의 벌금에 처한다.

넣고 나서 확인:

    python3 law/corpus.py            # 담긴 법령과 조문 수
    python3 law/gate.py 법이론서      # 미검증이 줄어드는 만큼이 검사된 양이다

문서가 `도시정비법` 처럼 줄여 부르면 `law/corpus.py` 의 `ALIASES` 에 한 줄 넣는다.

## 여기 넣으면 안 되는 것

- **LLM 이 기억으로 적어준 조문.** 여기는 정답 자리다. 여기가 틀리면 심판이 틀린 것을
  기준으로 멀쩡한 문서를 기각하고, 틀린 문서를 통과시킨다. 반드시 원문에서 복사한다.
- **판례.** 대조할 공개 원장이 없어서 아직 다루지 않는다. 그래서 L004 가 사건번호 인용
  자체를 막는다.

## 왜 이 디렉터리가 비어 있나

조문 원문은 각자 필요한 법령이 다르고, 개정되면 갱신해야 한다. 저장소에 박아두면 낡은
조문이 정답 자리에 남는다. 필요한 법령을 그때그때 넣는 쪽이 맞다.
검사용 가상 법령은 `tests/fixtures/law_corpus/` 에 따로 있다.
