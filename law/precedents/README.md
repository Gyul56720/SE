# 판례 원장 -- L004 가 대조하는 자리

여기가 비어 있으면 `law/gate.py` 의 L004 는 **사건번호 인용 자체를 금지**한다. 대조할 수
없는 인용을 통과시키면 그대로 환각이 되기 때문이다. 원장이 차면 L004 는 금지에서
**대조**로 바뀐다 -- 원장에 있으면 통과, 없으면 기각.

    원장이 비어 있다      -> 금지 (hard). "대조할 수 없다" 고 적는다.
    원장에 있다          -> 통과.
    원장에 없다          -> 기각 (hard). "지어냈다" 고 본다.

**비어 있는 것과 없는 것은 다르다.** 앞은 대조를 못 한 것이고 뒤는 대조해서 없던 것이다.
섞으면 원장을 채운 보람이 안 보인다.

## 받아서 넣는 법

    export LAW_API_OC=발급받은키        # 또는 .env 에 LAW_API_OC=
    python3 law/fetch.py --판례 2018다287522        # 사건번호로
    python3 law/fetch.py --판례 공유물분할 --건수 50  # 사건명·주제어로
    python3 law/fetch.py --판례 공유물분할 --list    # 무엇이 검색되는지 먼저 본다

`law/fetch.py` 가 법제처 국가법령정보 공동활용 OPEN API(`target=prec`)로 받아 여기에
`<사건번호>.txt` 로 저장한다. **사건번호가 안 실린 것은 저장하지 않는다** -- 첫 줄이 곧
원장의 색인이라, 사건번호가 없으면 그 파일은 원장에 안 잡히고 있으나 마나가 된다.

파일 첫 줄 꼴(이 줄만 `corpus.load_cases()` 가 읽는다):

    # 2018다287522 · 대법원 · 20200521 · 건물인도

## 분당 한도

**분당 호출 한도가 따로 있다.** 판례는 검색 1회 + 본문 N회를 몰아 부르므로
(`--건수 20` 이면 21회) 몇 주제만 돌려도 걸린다. 세 가지로 다룬다.

| | |
|---|---|
| `LAW_API_RPM` (기본 20) | 구르는 1분 창으로 센다. 창이 안 찼으면 안 쉰다 |
| `LAW_API_SLEEP` (기본 0.5초) | 순간 간격의 바닥. 줄이지 마라 |
| 제한에 걸리면 | **되풀이하지 않고 멈춘다.** 되풀이는 더 세게 두드리는 것이다 |

**이어할 수 있다.** 목록 응답에 사건번호가 실려 오므로, 원장에 이미 있는 건은 본문
호출을 아예 안 한다. 그래서 중간에 끊겨도 같은 명령을 다시 부르면 **안 받은 것부터**
이어간다. 걸렸으면 몇 분 쉬었다가 그대로 다시 부르면 된다.

한 번에 다 받지 마라. 주제 몇 개씩 끊어 가면서 `python3 law/gate.py 법이론서` 로
hard 가 안 늘었는지 보는 편이 안전하다.

## 지금 담고 있는 것은 사건의 실재뿐이다

L004 가 묻는 것은 "이 사건번호가 실재하는가" 다. **판시사항이 답안의 주장과 맞는지는
아직 아무도 안 본다** -- 그건 낱말 대조로 될 일이 아니고, 다음 층이다. 그때까지
`판례 원장에 있음` 은 "지어내지는 않았다" 는 뜻이지 "맞다" 는 뜻이 아니다.
