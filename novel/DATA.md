# 학습하며 모으는 것 -- 무엇을 어디에 쌓는가

**원문은 어디에도 안 들어간다.** 표본은 `profile.py` 에서 수로 바뀌고 거기서 끝난다.
프롬프트에도, 장부에도, 튜너에게도 원문 조각은 안 간다 -- 원문이 새면 원고가 그것으로
도배된다(이 저장소에서 다섯 번 겪었다).

## 1. 표본에서 (한 번, LLM 호출 0회)

| 무엇 | 어디에 | 누가 쓴다 |
|---|---|---|
| 작품을 화 단위로 자른 것 | `novel/corpus/<작품>/부-장-화.txt` | `corpus.py --write` |
| 자른 목록(번호 · 길이) | `novel/corpus/<작품>/manifest.json` | 〃 |
| 축별 분포(작품마다 · 전체) | `novel/corpus.profile.json` | `profile.py --json` |
| **목표값**(축마다 10~90% 폭) | `novel/targets.json` | `scripts/targets_update.py` |

## 2. 쓰는 동안 (덩어리마다, 호출 0회로 적는다)

| 무엇 | 어디에 | 왜 |
|---|---|---|
| 원고 덩어리 | `novel/drift.json` `chunks` | 이어 쓰기의 재료 |
| 세계 원장(인물·장소·사물·규칙·미결) | 〃 `ledger` | 모순 판정 · 다음 프롬프트 |
| **배정된 설정과 그 결과** | 〃 `arms` (`{n, arm, gap}`) | 어떤 설정이 값을 움직였나 |
| 손질 성공/시도(갈래별) | 〃 `mend` | 안 고쳐지는 갈래를 초고로 옮기려고 |
| 못 고친 것 | `novel/drift.debt.jsonl` | 폐기 대신 기록 |
| 갚을 것(거듭 놓친 갈래) | 〃 `owed` | 다음 덩어리에 한 건만 얹는다 |

## 3. 학습이 남기는 것

| 무엇 | 어디에 | 왜 |
|---|---|---|
| 축별 지시문(모자랄 때 · 넘칠 때 · 초고용) | `novel/directives.json` | **프롬프트의 본체.** 튜너가 여기를 고친다 |
| 시도 장부(축 · 이전 · 이후 · 점수 전후) | `novel/tune.jsonl` | 되돌릴 수 있어야 최적화다 |
| 챔피언(제일 좋았던 한 벌) | `novel/tune.best.json` | 나빠지면 여기로 돌아온다 |
| 이긴 설정 | `novel/arm.json` | 몇 개 실을지 · 문턱 |
| 바퀴마다의 원고 백업 | `logs/tune/drift.<바퀴>.json` | 어디서 나빠졌는지 되짚으려고 |
| 로그 | `logs/tune_loop.log` · `logs/run_all.log` | 끊긴 자리를 찾으려고 |

## 4. 재는 축 (지금 열아홉)

문면층 열넷: 문장 길이와 들쭉날쭉함 · 긴 문장 · 짧은 문장 · 짧은 '-다' · 말끝 고름 ·
절 잇는 밀도 · 점층 · 대사 몫 · 긴 대사 · 주고받기 · 문단 길이 · 되풀이 · 밖(외현).

서사층 대용 다섯: 도는 이름 수 · 한 번 쓰고 버리는 이름 몫 · 자리·때가 옮겨 가는 자국 ·
시한이 걸린 문장 몫 · 묻는 줄 몫. **의미를 안 읽고 결만 잰다.**

TAXONOMY.md 의 빈칸(인과 사슬 깊이 · 시점 구간 · 속도 · 기대의 갚음)은 아직 못 잰다.
못 재는 것은 프롬프트에도 안 쓴다 -- 재지 않는 요구는 지켜졌는지 알 수 없고, 알 수 없는
것은 고칠 수도 없다.
